# Business

## 결론 세 줄

`[실측]`·`[외부]` 근거는 각 문서에

1. 사람이 문의 1건 처리하는 데 **4,100~4,846원**이 든다. 급여는 그중 67%뿐이고 나머지는 보험·퇴직금·좌석·이직·관리다.
2. A-COP을 넣으면 건당 **1,132원**이 된다. 그중 LLM 비용은 **3.03원**, 전체의 0.27%다.
3. **비용의 99.7%는 여전히 사람이다.** LLM 단가를 깎는 최적화는 의미가 없고, **사람 시간을 줄이거나 오류를 줄이는 것**만 의미가 있다.

## 팔지 말아야 할 논거

**절감액으로 팔면 자기모순이다.** [../product/positioning.md](../product/positioning.md)에서 자동화율을 앞세우지 않기로 했는데, 절감액은 자동화율에서 나온다.

그리고 실제로 인원이 줄지 않는다. `[실측]` 골든셋에서 39%가 승인·입력 대기로 사람에게 돌아오고 5%는 구조적으로 사람 몫이다.

**주력 논거는 오류 비용이다.**

| 축 | 산식 | 우리 축인가 |
|---|---|---|
| 처리 비용 | 건당 처리시간 × 인건비 | 보조 |
| **오류 비용** | **오류율 × 건당 오류 손실** | **★ 주력** |
| 도입·운영 비용 | LLM + 승인 대기 인건비 + 인프라 | 우리가 받는 값 |

## ★ 이 모델을 깨는 것

**심사에서 먼저 물어보기 전에 우리가 적어야 신뢰를 얻는다.**

### 확정된 제약 — 바뀌지 않는다

| 리스크 | 내용 |
|---|---|
| **12GB VRAM 천장** | 4070 SUPER에서 우리 워크로드(10,670토큰)가 학습 기준으로 안 돌았다. **원가 이전의 문제**이고 gPUteer로도 안 풀린다 |
| **지연 p95 32~37초** | chat 채널 32%에 못 쓴다. 제품이 "실시간 자동응답"이 아니라 **"상담원 보조"**로 좁혀진다 |
| **Windows WDDM 느린 실패** | 장애가 25분 걸려 드러난다. 자체호스팅 제품이면 Linux 전제 |
| **클라우드 GPU가 API보다 14배 비쌈** | 원가 절감으로 팔면 반박당한다 |
| **처리 비용 절감을 약속하면 안 됨** | 39%가 사람에게 돌아온다 |

### 아직 안 잰 것 — 결론을 흔들 수 있다

| 리스크 | 무엇이 흔들리나 |
|---|---|
| **건당 2.36분이 추정** | **72% 절감이 통째로 여기 달려 있다.** 검토 2분·승인 3분을 아무도 안 쟀다 |
| 오류율 3개 입력이 전부 추정 | 연 2,646만원 절감 결론이 흔들린다 |
| 4070 SUPER 추론 가능 여부 | 배치 10은 KV 캐시 계산이지 측정이 아니다 |
| 4-bit 양자화 대가 | **원가와 정확도가 같은 손잡이에 달려 있다** |
| 좌석·채용·관리 오버헤드 | 건당 4,100원의 21%가 이 세 줄 |
| 음성 채널 미산정 | phone 12.5%인데 트래픽·STT·TTS 계산 없음 |
| 시장 수치 1차 출처 미확인 | 9.88조·19.4만명이 검증 안 됨 |

### 가장 위험한 것

**사업 논거를 인원 감축으로 세우면 안 된다.** 도입 후 39%가 그대로 남아 있을 때 신뢰를 잃는다.

**처음부터 오류 비용으로 세우면 이 함정을 피한다.**
