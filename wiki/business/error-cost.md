# 오류 1건이 분쟁까지 가면 얼마인가

`[실측]` 2026-09-03. 원본은 `datasets/voc/ecmc_dispute_casebook_2024/` — **KISA 전자문서·전자거래분쟁조정위원회 2024 사례집.**

## 왜 쟀나

**사업 논거를 인건비 절감이 아니라 오류 비용으로 세우기로 했다.** → [../product/pitch-questions.md](../product/pitch-questions.md)

그런데 **"오류 1건이 얼마"에 숫자가 없었다.** `[미확보]` 로 남아 있던 자리다.

**지어내지 않고 실제 조정 사례로 잰다.**

## 실측 — 8건

| 사례 | 거래액 | 조정 환급 |
|---|---:|---:|
| 모니터 하자 | 200,000 | 50,000 — `[정정 2026-09-10]` **환급이 아니다.** 조정결정은 구매자가 물건을 돌려주고 **판매자에게** 50,000원을 입금하는 것이다(방향이 반대) |
| 중고 바지 하자 | 169,000 | **159,000** |
| 아이폰 사용 불가 | 420,000 | 40,000 |
| 캠핑용품 손상 | 270,000 | **210,000** |
| 반려견 산소호흡기 | 120,000 | 30,000 |
| **지폐교환기 하자·분실** | **1,526,000** | **1,526,000** |
| 여행상품 예약 취소 | 400,000 | **260,000** — `[정정 2026-09-10]` 조정결정문에 「예약금 잔금 260,000원 전액을 환급」이 있다. `[미확보]` 로 적혀 있었다 |
| 피규어 파손 | 270,000 | **270,000** — `[정정 2026-09-10]` 0 이 아니다. 물건 인도와 동시에 **중고거래 플랫폼 페이로부터 270,000원을 환급받기로** 조정했다 |

### 집계 (7건)

`[정정 2026-09-10]` **아래 집계는 틀린 값 위에 섰다** — 모니터(방향이 반대) · 여행(260,000 이 있다) · 피규어(0 이 아니라 270,000)를 `datasets/voc/ecmc_dispute_casebook_2024/processed/all_cases.jsonl` 의 결정문과 대조해 고쳤다. 모니터를 빼고 나머지 일곱을 표의 값대로 세면 중앙값은 **210,000원**이다 — 다른 행의 값은 이번에 대조하지 않았다. 무엇을 「환급」으로 셀지부터 정해야 해서 아래 표는 고치지 않고 둔다.

| | 값 |
|---|---:|
| **중앙값** | **50,000원** |
| 평균 | 287,857원 |
| 최대값 제외 평균 (6건) | **81,500원** |
| 최소 · 최대 | 0 · 1,526,000원 |

**중앙값과 평균이 5.8배 벌어진다.** 지폐교환기 한 건이 끌어올린다.

> **평균을 쓰면 안 된다.** 분포가 한쪽으로 길다.

## ★ 이건 "오류 1건당 비용"이 아니다

**세 가지가 빠져 있다.**

| 빠진 것 | 왜 중요한가 |
|---|---|
| **분쟁까지 안 간 건** | 대부분의 오류는 여기서 끝난다. **분모가 아니다** |
| 처리 인건비 | 조정까지 가면 담당자 시간이 든다 |
| **신뢰 손실** | 재구매·평판. **금액이 안 나온다** |

> **이 숫자는 "분쟁까지 갔을 때의 환급액"이지 "오류 1건의 비용"이 아니다.**

**상한을 말할 때만 쓴다.** "오류 하나가 최대 152만원까지 간다"는 맞고, "오류 하나가 평균 28만원이다"는 틀리다.

## 그래도 값이 있는 이유

`[실측]` **지연배상 조항이 나온다.**

> 금원 지급 지체 시 피신청인은 신청인에게 **지연배상으로 연 12%** 의 비율에 의한 금원을 지급해야 한다.

**환급을 미루면 이자가 붙는다.** → [../research/legal-basis.md](../research/legal-basis.md) 의 **연 15%**(시행령)와 별개로, 조정에서는 **연 12%** 가 나왔다.

`[미확보]` **둘의 관계를 확인 못 했다.** 조정 재량인지 다른 근거인지 모른다.

### 환급이 0인 건도 있다

**피규어 파손 건은 물건 반환으로 끝났다.** 판매자가 돈을 안 냈다.

**"분쟁 = 무조건 손실"이 아니다.** 근거가 있으면 안 물어준다 — 그게 이 제품이 파는 것이다.
