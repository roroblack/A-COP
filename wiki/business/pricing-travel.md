# 여행 판 가격 — 팀당 49,000원

`[결정 2026-09-10 — 팀장 위임, 계획 담당이 Codex 와 정했다]` 정본은 계획서 v11 §11-A 와
`program/plan/A-COP_비용과_수익구조.md` §4-A. 여기는 **한 장 요약**이다.

| | |
|---|---|
| **가격** | **팀당 49,000원(VAT 포함) — 서울·최대 7일·4인.** 인당 12,250원 |
| **왜 내렸나** | 앞 판 59,000원은 **2도시 값**이다. 도시 간 연결을 관리하는 가치가 빠졌다. **도시 수로 나누지는 않는다** — 기간 중 검증·조정·현지 대응은 그대로다 |
| **기여이익** | 팀당 **14,249원** `[추정 — 예산 시나리오]`. ★**고정비를 안 뺐다 — 순이익이 아니다** |
| **운영 상한** | 기계 10,000원 · 사람 검토 1건·15분 · 같은 실패 재시도 1회 · 고객 추가 여행비 기본 0원. ★**기본 관리를 못 지키면 전액 환불 선택권** |

## 원가를 모르는데 왜 정할 수 있나

★**가격은 정할 수 있고, 수익이 난다고 확정할 수는 없다.** 그래서 **상한**으로 손실을
막고 **바꾸는 기준**으로 파일럿이 값을 판정하게 했다.

## 바꾸는 기준

| 지표 | 올린다 | 내린다 |
|---|---|---|
| 유료 전환율 | 10% 이상 → 59,000원 검증 | 5% 미만 + 가격 거절 → 39,000원 검증 |
| 팀당 실현 절감 가치(중앙값) | 80,000원 이상 | 39,000원 미만 |
| 평균 기여이익 | 12,000원 미달 | 20,000원 이상 여유 |
| 상한 때문에 못 끝낸 여행 | 10% 초과 → 재설계 | 5% 이하 |

★**MVP 에는 결제가 없어 유료 전환율을 못 잰다.** 나머지는 대리지표나 시험 입력으로 잰다.

## ★2분 폴링은 무료 소스에만

단가는 사업 검토서 v3 §7 에 있다 `[외부]` — Place Details $20/1,000건 · Route Matrix
$5/1,000요소. **Places 를 2분마다 부르면 장소 한 곳에 7일 5,040회, 약 151,200원 —
상품가의 3.1배다.** 지금 감시는 무료 TourAPI 로 돈다 `[실측]`. **유료 소스는 저빈도·
캐시로만 부른다.**
