# 환경 기동 절차 (실측 2026-08-12)

★**이 기계에는 Docker 가 없다.** v5 §16 의 `docker/compose.yml` 전제는 성립하지 않는다.
PostgreSQL 은 **conda env `pgv` 에서 뜬 프로세스**이고 Windows 서비스가 아니다 —
**재부팅하면 안 떠 있을 수 있다.**

## 1. PostgreSQL 확인

```powershell
Get-NetTCPConnection -State Listen -LocalPort 5433 | Select-Object LocalAddress,LocalPort
Get-Process postgres -ErrorAction SilentlyContinue | Select-Object Id,Path
```

기대: `127.0.0.1:5433` LISTEN, 경로 `...\anaconda3\envs\pgv\Library\bin\postgres.exe`

### ★안 떠 있을 때 — 기동 절차 (2026-08-13 실측)

```powershell
$bin  = "$env:USERPROFILE\anaconda3\envs\pgv\Library\bin"
$data = "C:\Users\playdata2\Documents\llm_workspace\_unified_mall_3\data\pgdata"

& "$bin\pg_ctl.exe" -D $data status
& "$bin\pg_ctl.exe" -D $data -o "-p 5433" -l "$data\server_5433.log" start
```

★**`-o "-p 5433"` 를 빠뜨리지 마라.** `postgresql.conf` 에 `port` 설정이 **없어서**
그냥 띄우면 기본값 **5432** 로 뜬다. 우리 `.env` 와 모든 문서·테스트는 **5433** 을 쓴다.
2026-08-13 에 이걸 몰라 5432 로 띄웠다가 여전히 "connection refused" 를 봤다.

★**데이터 디렉터리가 이 저장소 밖에 있다** — `_unified_mall_3/data/pgdata` 다.
`acop` DB 는 그 클러스터 안에 있고, 다른 프로젝트 DB(`insurance_*`, `mall_vec`)와
**같은 서버를 공유**한다. 그래서 이 서버를 내리면 옆 프로젝트도 멈춘다.

### 죽었을 때 무슨 일이 일어나나 (2026-08-13 실측)

서버가 비정상 종료되면 기동 시 자동 복구가 돈다:

```
LOG:  database system was not properly shut down; automatic recovery in progress
LOG:  redo starts at 5/41CBC4C8 ... redo done
LOG:  database system is ready to accept connections
```

복구 후 데이터는 그대로였다 — `tenants=1 · demo_customers=10 · knowledge_chunks=300 ·
knowledge_documents=25 · payments=30`. **기동 후 이 건수를 반드시 대조하고 작업을 재개한다.**

fsync 동기화에 **40초 이상** 걸릴 수 있으니 `pg_ctl start` 가 느려도 기다린다.

## 2. psql — PATH 에 없다

```powershell
$psql = "$env:USERPROFILE\anaconda3\envs\pgv\Library\bin\psql.exe"
& $psql -h 127.0.0.1 -p 5433 -U postgres -d acop
```

★**이 서버에는 다른 프로젝트 DB 가 함께 있다** — `insurance_agent`, `insurance_demo`,
`insurance_real`, `mall_vec`. **A-COP 는 `acop` 만 쓴다. 나머지를 건드리지 않는다.**

## 3. A-COP DB (최초 1회 — 2026-08-12 완료)

```powershell
& $psql -h 127.0.0.1 -p 5433 -U postgres -c "CREATE DATABASE acop"
```

extension(`vector`, `pgcrypto`)은 **마이그레이션이 생성**한다(P2, S-DB 소유).
`CREATE EXTENSION` 을 손으로 치지 않는다 — 마이그레이션이 유일한 경로여야 재현된다.

## 4. 파이썬 의존성

★**anaconda base 환경을 다른 프로젝트와 공유한다.** 버전을 강제로 올리면 옆 프로젝트가 깨진다.
설치 전에 이미 있는 버전을 확인하고, 충돌하면 리포트에 적는다.

```powershell
python -m pip install -r requirements.txt
```

2026-08-12 실측: `pydantic 2.13.4` / `psycopg 3.3.4` / `tiktoken` 설치 확인.
`faster-whisper` 가 `onnxruntime` 미설치를 경고하는데 **이 프로젝트와 무관한 옆 프로젝트 의존성**이다.

## 5. `.env`

`.env.example` 를 복사해 채운다.

★**BOM 없이 저장한다.** PowerShell 의 `Set-Content -Encoding UTF8` 은 BOM 을 붙이고,
그러면 **첫 줄 키가 `﻿ACOP_DATABASE_URL` 이 되어 인식되지 않는다**(2026-08-12 실제로 겪음).

```powershell
[System.IO.File]::WriteAllText("$PWD\.env", $text, (New-Object System.Text.UTF8Encoding($false)))
```
