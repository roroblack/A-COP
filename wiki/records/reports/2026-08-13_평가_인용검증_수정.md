# 평가 인용 검증 수정 리포트

작성일: 2026-08-13

## 변경 파일

- `eval/runners/common.py`
  - `knowledge_chunks`의 `(document_id, chunk_no)` 집합을 프로세스당 1회 캐시한다.
  - `^doc_\d+#c\d+$` 형식과 실제 chunk 존재 여부를 모두 검증한다.
  - 모든 결과 행에 `citations.claimed`, `citations.valid`, `citations.invalid`를 기록한다.
  - 유효 인용이 0개이면 LLM judge 결과를 덮어 `policy_grounding=0`으로 만들고 total/pass를 재계산한다.
  - 무효 인용은 judge `reasons`에 환각 인용으로 기록한다.
  - arm B는 검색된 근거 문장과 `source_id`를 프롬프트에 넣고, 검색 source ID를 후보 출력에 그대로 반영한다. 0건/실패는 `degraded=true`로 표시한다.
  - arm A의 mock 및 입력은 정책 인용을 만들지 않도록 수정했다.
  - Proposed는 `ContextPack.evidence`의 policy `source_id`를 그대로 사용한다.
- `prompts/judge/judge_v1.txt`: citation 검증 결과를 grounding의 권위 있는 입력으로 지정했다.
- `prompts/judge/arms/baseline_a_v1.txt`: RAG/정책 인용을 요구하지 않도록 수정했다.
- `prompts/judge/arms/baseline_b_v1.txt`: 검색 근거 문장과 source ID를 사용·복사하도록 수정했다.
- `prompts/judge/arms/proposed_v1.txt`: ContextPack source ID를 그대로 복사하도록 수정했다.

## 자체 검증

문법 검사:

```text
python -m py_compile eval/runners/common.py
통과
```

지정된 arm A 실행은 3행을 생성했지만, 현재 환경의 OpenAI 호출이 모두 다음 오류로 실패했다.

```text
python -m eval.runners.baseline_a --dataset eval/datasets/golden.jsonl --repeats 1 --seed 7 --provider openai --limit 3 --concurrency 3 --output eval/reports/chk_a.jsonl
APIConnectionError: Connection error.  (3 cases)
```

지정된 arm B 실행은 120초 제한에 도달해 종료되었고 `eval/reports/chk_b.jsonl`은 생성되지 않았다.

```text
python -m eval.runners.baseline_b --dataset eval/datasets/golden.jsonl --repeats 1 --seed 7 --provider openai --limit 3 --concurrency 3 --output eval/reports/chk_b.jsonl
command timed out after 120514 milliseconds
```

따라서 실제 OpenAI 응답을 이용한 A/B 기대 출력(`A: valid=[]`, `B: valid!=[]`)은 이 네트워크 제한 환경에서 확인할 수 없다. mock 실행이나 전량 실행으로 대체하지 않았다. 생성된 A 확인 파일은 `eval/reports/chk_a.jsonl`이다.

요청한 요약 명령도 A 행에 judge가 없는 호출 실패 행 때문에 `KeyError: 'judge'`로 종료되었다. 이는 평가 결과를 성공으로 위장하지 않기 위해 러너가 API 실패 행에 judge를 생성하지 않기 때문이다.

## 채점 규칙 변경

judge LLM 채점 전에 후보의 `policy_evidence`를 검증한다. 형식이 `doc_NN#cM`이 아니거나 캐시된 실제 `knowledge_chunks` 집합에 없는 항목은 `invalid`다. `valid`가 하나도 없으면 LLM이 반환한 grounding 점수와 관계없이 0으로 덮어쓰고 total/pass를 다시 계산한다. 무효 항목이 있으면 `reasons`에 남긴다.
