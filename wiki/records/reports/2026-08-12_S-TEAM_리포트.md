# S-TEAM 구현 리포트

## 1. 작업 목표

Billing/Subscription Team과 Technical Entitlement Team을 TeamTask/TeamResult 계약에 맞춰 구현하고, customer-scoped named read tools, versioned prompts, prompt hash 등록 및 시나리오 테스트를 추가했다.

## 2. 구현 파일

- `app/modules/customer_ops/billing.py` — `BillingSubscriptionTeam`
- `app/modules/customer_ops/technical.py` — `TechnicalEntitlementTeam`
- `app/tools/read_tools.py` — 6개 named read tool, allowlist, scope, loop guard, prompt/LLM 기록 보조
- `app/modules/customer_ops/__init__.py` — 두 Team export
- `tests/contract/test_team_contract.py`, `tests/contract/test_core_isolation.py`
- `tests/unit/teams/test_team_scenarios.py`

Team은 환불이나 권한 변경을 실행하지 않고 proposal/안내만 반환한다. ContextPack이 degraded이면 확정 답변 없이 escalate하며, policy evidence가 없으면 `policy_not_found`로 escalate한다.

## 4. Prompt 목록

Billing: `classify_billing.v1.md`, `explain_billing.v1.md`, `propose_refund.v1.md`  
Technical: `classify_entitlement.v1.md`, `diagnose_entitlement.v1.md`, `propose_support_action.v1.md`

`register_prompt_files()`/`register_prompts()`가 파일 SHA-256을 계산해 기존 `create_prompt()`로 등록한다. `record_llm_call()`은 등록된 `prompt_id`를 FK로 전달한다.

## 5. 검증 실제 출력

집중 테스트:

```text
python -m pytest tests/unit/teams tests/contract -q
...............................................                          [100%]
47 passed, 1 warning in 2.45s
```

전체 테스트:

```text
python -m pytest tests -q
89 collected; 86 passed, 3 failed, 0 skipped
```

실패 3건은 `tests/integration/rag/test_rag_integration.py`의 기존 RAG 검색 테스트이며, `search_policy()`가 OpenAI embedding 네트워크 호출 중 `[WinError 10013]`을 받았다. S-TEAM 파일/계약 테스트는 통과했다. 이번 작업 범위 밖인 RAG/Core는 수정하지 않았다.

DB 확인:

```text
psql -h 127.0.0.1 -p 5433 -U postgres -d acop -tAc "select 'tenants='||count(*) from tenants"
tenants=1
```

## 6. 미해결 사항

전체 테스트의 RAG 3건은 실행 환경의 외부 embedding 네트워크 차단으로 남았다. 테스트 skipped는 0건이며, `demo` tenant는 삭제하지 않았다.
