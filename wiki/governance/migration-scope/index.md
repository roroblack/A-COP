# 이관 범위 목록

`[실측]` 2026-09-01

```bash
python program/scripts/migration_scope.py
```

전체 목록은 `program/scripts/_migration_scope.tsv`에 있다. **재생성 가능하다.**

## 결과

★**이 표의 숫자는 그날의 스냅샷이다.** 세션이 `program/` 아래에 문서를 하나
쓸 때마다 분모가 움직인다. 실제로 747 → 760 으로 늘면서 판정필요가
79 → 68 로 바뀌었다. **박아 둔 값을 믿지 말고 위 명령을 다시 돌린다.**

| 판정 | 2026-09-01 | **2026-09-07** | 뜻 |
|---|---:|---:|---|
| **유지** | 124 | **130** | 그대로 옮긴다 |
| **판정필요** | 79 | **68** | 사람이 본다 |
| 선별 | 153 | 129 | `final_project_sample`. 계약 선검증분만 |
| 제외 | 391 | 433 | 옮기지 않는다 |
| **합계** | 747 | **760** | |

```
이관 대상 (유지 + 판정필요)   198건
그중 사람 판정 필요            68건 = 34%
```

★**이 「판정필요」와 [status.md](status.md) 의 「판정 완료 198/198」은 다른 것을
센다.** 여기 숫자는 **스크립트의 초안 판정**이고(사람이 확정해야 한다고 스크립트
스스로 마지막 줄에 찍는다), status 쪽은 **사람이 실제로 내린 판정**이다. 사람
판정은 2026-09-03 에 끝났고, 남은 일은 판정이 아니라 **대조 38건**이다 —
"옮기기로 정했다"와 "옮겼다"는 다르다.

### [2026-09-01] 6차 검증으로 기준을 고쳤다

`[실측]` 자동 `유지` 판정을 표본 15건으로 확인했더니 **type 일치 60%**였다. → [type-verification/round-6.md](../type-verification/round-6.md)

**실패 패턴이 둘이었다.**

| 패턴 | 예 |
|---|---|
| **폴더로 type 추정** | `datasets/` 아래 영문 작업 로그를 `dataset`으로 |
| **짧은 문서** | 25줄짜리 "일회성 스크립트" 폐기 기록을 `guide`로 |

**길이 하한 40줄을 넣었다.** 그 아래는 `판정필요`로 넘긴다.

```
판정필요  36건  →  79건
```

**늘어난 게 맞다.** 이전 36건은 실제 위험을 과소평가한 값이었다.

### [2026-09-01] 7·8차로 두 번 더 고쳤다

| 회차 | 무엇 | 결과 |
|---|---|---|
| [7차](../type-verification/round-7.md) | **`program/research/` 는 type 을 찍지 않는다** — 26건 중 24건 틀렸다 | 그 층이 `?` 로 |
| [8차](../type-verification/round-8.md) | **`_raw/` 는 인용 여부로 가른다** — 24건 중 11건만 인용된다 | 판정필요 76 → **60** |

```
유지      139건
판정필요   60건   ← 39% → 30%
선별      129건
제외      417건
```

**8차가 판정필요를 줄인 유일한 회차다.** 사람이 봐야 하던 자리를 **셀 수 있는 규칙**으로 바꿨기 때문이다.

```python
if "/evidence/_raw/" in n:
    verdict = "유지" if base in cited else "제외"
```

**나머지 회차는 다 늘렸다.** 규칙이 좋아진다고 사람 몫이 항상 주는 건 아니다.

## 휴리스틱의 한계

**이 목록은 초안이다.**

`[실측]` blind 검증에서 **사람 둘도 일치율 86.2%였다.** 정규식이 그보다 잘할 수 없다.

| 무엇을 | 어떻게 |
|---|---|
| 폴더로 추정 | `docs/evidence/` → `evidence` |
| 파일명으로 추정 | `_결정.md` → `decision` |
| 본문 신호로 추정 | `## 재현 명령` 있으면 `evidence` |
| **분할 여부** | **자동으로 단정하지 않는다.** 신호 3종 + 100줄 이상이면 사람에게 넘긴다 |

**마지막 줄이 중요하다.** 처음엔 자동으로 "분할"이라고 찍었는데 40%가 나왔다. 신호를 헐겁게 잡으면 다 걸린다. **판정을 사람에게 넘기는 쪽으로 바꿨다.**
