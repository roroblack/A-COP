# 3차 — 독립 판정자 투입

`[실측]` 2026-09-01. 두 번째 판정자로 **codex**를 붙였다. **내 판정은 주지 않았다.**

## ★ 먼저 — 프로세스 결함 하나를 실토한다

**표본이 1·2차와 다르다.**

1차는 즉석 스크립트로 뽑았고, 그 뒤 `sample_docs.py`로 스크립트화하면서 **수집 함수에 정렬을 넣었다.** 모집단 순서가 바뀌자 **같은 seed인데 다른 표본**이 나왔다.

```
1차·2차 표본   즉석 스크립트 (비정렬)
3차 표본       sample_docs.py (정렬)   ← 다르다
```

`[실측]` 45건 중 최소 10건이 다른 문서다.

**seed 고정만으로는 재현이 안 된다.** 모집단이 바뀌면 표본도 바뀐다.

### 조치

**표본 목록 자체를 얼렸다.**

```
program/scripts/sample_frozen.txt
```

이 파일이 있으면 `sample_docs.py`가 다시 뽑지 않고 그대로 쓴다. 파일이 사라졌으면 경고한다.

## 결과 — 격차가 크다

| 판정자 | 표본 | 애매 |
|---|---|---|
| 나 (1차, 규칙 수정 전) | 즉석 | 25.0% |
| 나 (2차, 규칙 수정 후) | 즉석 | **4.5%** |
| **codex (독립)** | 얼린 표본 | **28.9%** |

**6배 차이다.**

표본이 달라 엄밀한 대조는 아니다. 다만 같은 모집단·같은 층화이므로 **이 정도 격차가 표본 변동만으로 나오기는 어렵다.**

### 2차의 4.5%는 믿을 수 없다

2차에 스스로 적었던 경고가 그대로 맞았다.

> 혼자 했다. 그리고 **규칙을 내가 방금 썼다.** 규칙을 만든 사람이 적용하면 맞을 수밖에 없다.

**확증 편향이 실재했고 컸다.** 독립 판정자를 안 붙였으면 4.5%를 믿고 이관을 시작했을 것이다.

## ★ 새 패턴 — `dataset` vs `report`

**내가 못 본 것이다.** 나는 datasets REPORT 4건을 전부 `dataset` 확실로 봤다.

codex는 **3건을 애매**로 봤다. 이유가 정확하다.

```
데이터가 무엇인가        → dataset  (안 변한다)
지금 전처리가 어디까지인가 → report   (계속 변한다)
```

**한 파일에 둘이 섞여 있다.** 변경 주기가 다르므로 [document-standard.md](../document-standard.md)의 분할 트리거에 걸린다.

`[실측]` `datasets/README.md`에도 "VOC 전처리 현황 (2026-08-31 실측)" 절이 있다. **같은 구조다.**

## 남은 10건의 공통점

38·39·41을 빼면 **전부 "결정 + 계획"이 한 문서에 있는 것**이다. 2차에서 이미 본 패턴이고, codex가 훨씬 많이 잡았다.

**type 문제가 아니라 문서 설계 문제다.** 그런데 그게 **13건 중 10건**이면 이관 대상 250~380건에서 **55~85건이 분할 대상**이라는 뜻이다. `[추정]`

2차에서 낸 "10~17건" 추정은 **크게 과소평가였다.**
