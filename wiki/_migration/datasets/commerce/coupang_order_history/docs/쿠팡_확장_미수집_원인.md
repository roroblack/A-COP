# 쿠팡 확장 미수집 원인 (실측 HTML 기반)

사용자가 제공한 "다음 페이지" 주문 카드 HTML 분석 결과.

## 원인 1 — 취소완료 주문에는 상품 링크에 href가 없다

현재 확장의 주문 카드 탐색 기준:
`a[href*="MyCoupang_my_orders_list_product_title"]`

그런데 취소완료 주문의 상품 링크는 **href가 아예 없다**:

```html
<a class="sc-5a139ee-12 sc-243c9af9-0 dNRFWT ihxwGs">
  <span class="sc-5c217829-1 sc-243c9af9-1 kgcOMO iIfQoU">헤이맨 아이패드 프로 M1 ...</span>
</a>
```

이미지 링크도 마찬가지로 href가 없다:
```html
<a class="sc-408af0a8-0 hjrnzM">
  <img alt="헤이맨 아이패드 프로 M1 ..." src="...">
</a>
```

배송완료 주문은 href가 있지만(`/ssr/sdp/link?vendorItemId=...`), 취소완료는 상품 페이지
링크 자체가 사라진다. 따라서 href 기반 탐색은 취소 주문을 전부 놓친다.

### 새 탐색 기준

주문 카드의 안정적 앵커는 **`주문 상세보기` 헤더 블록**이다. 모든 주문에 있다.

```html
<div class="sc-2dee486c-0 cXKQoM">          <!-- 주문 카드 루트 -->
  <div class="sc-f52eb281-0 gtEXxx">        <!-- 헤더 -->
    <div class="sc-f52eb281-1 dybnQZ">2021. 8. 27 주문</div>
    <div class="sc-f52eb281-2 gjhiiX">
      <span class="sc-f52eb281-3 dBmYzE">주문 상세보기</span>
    </div>
  </div>
  <div class="sc-5a139ee-0 gCjDaW"> ... 상품 테이블 ... </div>
</div>
```

카드 탐색: 텍스트가 `주문상세보기`인 요소를 찾고, 그 조상 중 **주문일 텍스트
(`YYYY. M. D 주문`)를 함께 포함하는 가장 가까운 블록**을 카드 루트로 잡는다.

이러면 취소완료·배송완료 모두 잡힌다. 그리고 **주문일을 목록에서 바로 얻을 수 있다**
(현재는 상세 진입해야만 얻는데 목록 헤더에 있다).

상품명은 카드 안에서 다음 순서로 찾는다:
1. `img[alt]` 중 뱃지가 아닌 값 (취소 주문도 이미지 alt는 있다)
2. 금액 span 근처의 텍스트 span

## 원인 2 — 마지막 페이지인데 "다음"을 눌렀다

사용자가 준 페이지네이션 HTML:

```html
<button ... disabled=""><svg .../> <!-- -->이전</button>
<button ... disabled="">다음<!-- --> <svg .../></button>
```

**둘 다 `disabled`다.** 즉 이 페이지는 처음이자 마지막 페이지다.

그런데 확장은 "다음 페이지 클릭 후 10초 동안 주문 카드가 바뀌지 않아 중단"이라는
경고를 냈다. `disabled` 판정이 동작하지 않았다는 뜻이다.

원인 후보: 버튼 텍스트에 HTML 주석(`<!-- -->`)이 끼어 있다. `textContent`로는 주석이
제외되지만, 만약 `innerHTML` 기반으로 비교하거나 자식 노드를 순회하면 어긋날 수 있다.
또한 `이전` 버튼의 텍스트는 `<svg/> 이전` 순서라 SVG가 앞에 온다.

### 수정

- `disabled` 확인을 **클릭 전에** 반드시 수행하고, disabled면 즉시 정상 종료로 처리해라.
  "10초 대기 후 중단" 경고를 내지 말고 "마지막 페이지"로 로그를 남겨라.
- 버튼 판정은 `textContent`(주석 자동 제외)를 공백·제로폭 제거 후 비교한다.

## 확인된 추가 정보 — 연도 필터

목록 상단에 연도 탭이 있다.

```html
<div class="sc-6441a31c-1 hdwxWS">최근 6개월</div>
<div class="sc-6441a31c-1 gUoxrz">2026</div>
<div class="sc-6441a31c-1 gUoxrz">2025</div>
... 2024, 2023, 2022, 2021
```

**기본값이 `최근 6개월`이다.** 그래서 3건만 나온 것이다. 전체를 수집하려면 연도 탭을
순회해야 한다. 2021~2026 6개 연도를 각각 클릭하고 그 안에서 페이지네이션을 돌면 된다.

이것이 수집량이 적었던 진짜 이유다.
