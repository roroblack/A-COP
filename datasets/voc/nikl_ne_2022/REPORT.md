# 모두의말뭉치 — 개체명 분석 말뭉치 2022 (NIKL_NE)

## 출처

- 국립국어원 언어정보나눔터(모두의말뭉치), 신청 승인 후 사용자가 직접 다운로드
- 다운로드일: 2026-08-23 (내가 인지한 건 2026-08-24 — 신청·다운로드는 사용자가 직접 했고
  나는 사후에 폴더 정리만 했다)
- 요청 당시 지정한 대상: **"개체명 분석 말뭉치"**(NE) — "개체명 분석 **및 개체 연결**
  말뭉치"(NEL, 위키피디아 지식베이스 연결 포함)가 아니다. 실제로 받은 파일명도
  `NIKL_NE_2022_*`로 NE가 맞다 — 의도한 것과 일치함.

## 받은 것

- `raw/NIKL_NE_2022_CSV.zip` (42.9MB) — 내부에 `NIKL_NE_2022_CSV_개체명 분석/`
  폴더, `CSV파일 사용법에 대한 설명.pdf` + CSV 3종(`MXNE...`, `NXNE...`, `SXNE...`,
  압축 해제 시 합계 약 428MB)
- `raw/NIKL_NE_2022_v1.1_JSON.zip` (100.7MB) — 내부에 `NIKL_NE_2022_v1.1/` 폴더,
  안내 PDF(국문+영문) + JSON 3종(`SDNE...`, `NLNE...`, `MDNE...`, 압축 해제 시
  합계 약 1.5GB)
- 압축 해제 안 함(원본 그대로 zip 상태로 `raw/`에 보관) — CSV/JSON 둘 다 같은
  말뭉치의 다른 포맷으로 보인다(내용 대조는 아직 안 함).

## 선택 이유

`datasets/voc/sources_catalog/PLAN.md` 참고. REV(응답 검증)의 PII 필터가
지금 손으로 짠 정규식만으로 돌아가는데, 흔치 않은 성씨·외국인 이름 등을
놓칠 수 있다는 게 실측 없는 추정이었다 — 이 말뭉치로 정규식의 실제 recall을
재고 개선하는 근거로 쓴다. "개체 연결"(엔티티가 누구인지 지식베이스와
연결하는 것) 없이 "이게 사람 이름인가"만 필요해서 NE만 받았다(NEL 아님).

## 아직 안 한 것

- 압축 해제
- CSV/JSON 두 포맷 중 실제로 어느 쪽을 쓸지 결정(CSV가 더 가볍고 다루기
  쉬워 보이나 실제 스키마·라벨 체계 확인 전이라 단정 못 함)
- 기존 REV PII 정규식의 recall 측정 스크립트 작성·실행 — 이게 이 데이터를
  받은 원래 목적인데 아직 착수 안 함(`PLAN.md`에서 "실측 근거 없어 우선순위
  낮음"으로 보류해뒀던 항목 — 데이터가 이제 있으니 재우선순위화 필요할 수 있음)
