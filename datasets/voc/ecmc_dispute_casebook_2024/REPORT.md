# 2024 전자거래분쟁조정사례집 추출 데이터

## 출처와 이용조건

- 원본: `raw/2024_전자거래분쟁조정사례집.pdf`
- 발행처: 한국인터넷진흥원(KISA) 전자문서·전자거래분쟁조정위원회 사무국
- 원본 발행: 2024년 12월
- 원본 확인: `usr.ecmc.or.kr` 공개 게시물에서 2026-08-21 확보
- 공개 게시물 외 별도 이용조건은 확보 과정에서 확인하지 못했다. 다만 PDF 마지막 면에는 판권이 KISA에 있으며 허가 없는 무단 전재·복사를 금한다는 문구가 있다. 이 추출물은 원문 검토·내부 분석을 위한 것으로, 원본의 출처와 해당 고지를 함께 기록한다.

## 추출 방법

PyMuPDF(`fitz`)로 67개 PDF 페이지를 페이지 단위 추출했다. `pypdf`와 비교 확인한 결과 이 PDF에서는 `fitz`가 한글 텍스트와 줄바꿈을 더 안정적으로 보존했다. 실제 사례 본문은 목차와 본문 전후 설명을 제외하고 PDF 44–59페이지에서 8건으로 식별했다. 각 JSONL 레코드는 문서에 표시된 사건번호와 제목, 원본 PDF 시작 페이지(`page`), 종료 페이지(`page_end`), 그리고 해당 사례 페이지의 추출 원문 전체(`raw_text`)만 담는다. 요약·의역 필드는 추가하지 않았다.

## 결과 건수

- 전체 실제 분쟁조정 사례: 8건
- Return & Refund / Fulfillment & Logistics 및 B2C 쇼핑몰-고객 범위: 2건
  - 5번 반려견 산소호흡기 대여: 온라인 오픈마켓
  - 7번 여행상품: 예약 취소·환불
- 키워드상 환불·반품·배송과 관련되지만 B2C 범위에서 제외: 6건
  - 중고 개인간 거래: 1–4번, 8번, 5건
  - 사업자 거래로 보이는 지폐교환기: 6번, 1건

사례집 앞부분의 거래형태 통계는 2024년 조정사건 중 C2C가 11건, B2C가 3건, B2B가 1건이라고 설명한다. 이 통계만으로 분류하지 않고, 각 사례의 본문에서 중고 플랫폼·직거래·온라인 오픈마켓·사업자 거래 맥락을 직접 확인했다. 또한 앞부분에는 개인간거래 분쟁예방 리플릿이 별도로 수록되어 있어 C2C 사례가 문서에 포함됨을 확인했다.
