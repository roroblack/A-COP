# 쿠팡 페이지 실측 자료

사용자가 실제 쿠팡 화면에서 복사해 준 HTML을 분석한 결과다.

확장의 선택자는 전부 이 자료에서 나왔다. 페이지 구조가 바뀌어 파서가 깨지면 여기부터 본다.

| 파일 | 내용 |
|---|---|
| `실제HTML_주문카드.md` | 주문목록 카드, 상품명·금액·수량·주문상태 |
| `실제HTML_주문상세_배송조회.md` | 주문상세 결제정보, 배송조회 표(상품준비중·배송중·배송완료 3종) |
| `실제HTML_페이지네이션.md` | 이전/다음 버튼, 마지막 페이지 disabled 처리 |

원본은 `.tmp/`에 있었다. `.tmp/`는 git에서 제외되므로 여기로 옮겼다.
