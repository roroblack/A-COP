# 차단된 접근 시도

쿠팡을 Playwright로 열어 로그인하려 한 스크립트다. **모두 실패했다.**

| 파일 | 시도한 방식 | 결과 |
|---|---|---|
| `save_session.py` | 전용 프로필로 로그인 창을 열기 | Access Denied (Akamai 봇 차단) |
| `open_with_real_profile.py` | 사용자의 기존 Chrome 프로필 재사용 | "자동화 제어 중" 표시, 차단 |

로그인 페이지 직접 접근, QR 코드 로그인도 같은 지점에서 막혔다.

원인은 하나다. Playwright가 띄운 브라우저는 어떤 프로필을 쓰든 자동화로 식별되고,
쿠팡은 그것을 차단한다. 이 표시를 지우는 것은 탐지 우회이므로 하지 않는다.

현행 방식은 `../extension/`의 Chrome 확장 프로그램이다. 사용자의 실제 브라우저 안에서
확장 API로 동작하므로 이 차단과 무관하다.
