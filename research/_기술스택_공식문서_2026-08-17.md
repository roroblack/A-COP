## 링크를 걸지 않은 항목과 이유

| 항목 | 이유 |
|---|---|
| RAG · GraphRAG | 특정 제품이 아니라 검색 증강 방식의 이름이다. 공식 사이트가 없다. |
| API Key + Scope | 우리 Gateway의 권한 설계다. 외부 표준이 아니다. |
| golden / holdout harness | 우리가 만든 평가 하네스다. `final_project_sample/eval/` 에 있다. |
| bootstrap · McNemar | 통계 검정 방법이다. 제품이 아니다. |
| Registry · Adapter | 우리 설계의 구성 요소 이름이다. v7 §21 계약을 따른다. |

프로토콜 자체의 근거 자료는 `_출처검증_2026-08-17.md` 의 H 그룹(H1 A2A, H2 AP2, H3·H4 UCP, H5 MCP)에 따로 있다.
이 파일은 "어디서 문서를 보는가"를 위한 링크이고, H 그룹은 "무엇이 사실인가"를 위한 근거다.
