# scripts/

팀원 개인 폴더(`team_branch/<이니셜>/`)에 흩어지기 쉬운 **재사용 가능한
작업 스크립트**(테스트/디버그/벤치마크 도구)를 모아두는 곳이다.
`datasets/`가 데이터, `program/research/`가 조사 문서라면 여기는 **코드**다.

## 구조 규칙

```
scripts/<주제>/
  ...스크립트들
```

- 개인 실험이라도 팀이 다시 돌릴 수 있으면 여기로 옮긴다. 한 번 쓰고
  버릴 디버그 코드는 각자 폴더에 둬도 되지만, 재사용 목적의 도구는
  여기로 이동한다.
- 하드코딩된 절대경로는 옮긴 위치 기준으로 고친다(원본 데이터 경로는
  데이터가 실제로 있는 곳을 그대로 가리켜도 된다 — 데이터까지 옮길
  필요는 없다).
