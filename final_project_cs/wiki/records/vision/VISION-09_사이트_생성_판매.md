# VISION-09 — 사이트 생성·판매 (프론트 빌더 포함)

상태: 보류. 사이트 하나는 10주 검증 쇼핑몰로 만들지만, 생성·판매 제품은 vision이다.

## 3. 도입 트리거 (이 조건이 만족되면 재검토한다)

다음 중 하나가 4주 연속 관측되면 도입을 재검토한다.

- 동일한 사이트 생성·수정 요청이 유료 또는 내부 검증 고객 5곳 이상에서 발생한다.
- 수작업 템플릿·프론트 구성 요청이 월 10건 이상이고, 요청의 70% 이상이 공통 페이지·상품·운영 설정으로 분류된다.
- 검증 쇼핑몰의 제한 운영에서 사이트 생성 이후 수정·배포 대기 시간이 월 20시간 이상으로 측정된다.

## 2. 지금 하지 않는 이유

프론트 생성·템플릿·빌더는 A-COP Core의 Case·승인·감사 Runtime과 별개 기술이다. 10주에는 사이트 제품의 1호 사례를 통해 Runtime과 소비자/운영자 양면을 보여주면 충분하며, 빌더를 추가하면 UI·배포·테마·권한·콘텐츠 품질 검증이 새 제품 범위가 된다. 배포 모듈화 문서의 Docker·환경·백업 범위도 별도 확인이 필요하다.

## 4. 도입 시 예상 비용

| 구분 | 실소요 일수 | 내용 |
|---|---:|---|
| 생성 | 10~15일 | 템플릿·페이지 모델·상품 연결·미리보기·프론트 빌더·배포 흐름 |
| 검증·통합 | 6~10일 | 반응형·권한·콘텐츠 회귀·Commerce MCP·CS MCP·배포·rollback 검증 |
| 대기 | 2~5일 | 콘텐츠·도메인·호스팅·운영자 승인·배포 환경 준비 |

병목은 디자인/콘텐츠 요구의 변동과 배포 환경 승인이다. 실제 비용은 판매 대상과 호스팅 범위 확인 필요.

## 6. 폐기 조건 (이 조건이면 이 비전을 버린다)

12개월 동안 위 트리거가 한 번도 발생하지 않고 사이트 생성 요청이 검증 쇼핑몰 1곳에만 머물면, 빌더 제품은 폐기하고 정적 템플릿·수동 배포 문서만 유지한다.
