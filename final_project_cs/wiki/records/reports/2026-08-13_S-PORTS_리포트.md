# S-PORTS 구현 리포트

## 범위

기존 파일 이동 없이 A2A/Graph Port와 Adapter를 신설했다. `TeamTask`와 `TeamResult` 계약은 변경하지 않았고 `/v1/*` 경로도 추가하지 않았다.

## 만든 파일

- `app/core/remote_team/executor.py`: `TeamExecutorPort`, `LocalTeamExecutor`
- `app/core/remote_team/a2a_executor.py`: 주입 transport 기반 `A2ATeamExecutor`, 원격 4상태의 Case 결과 매핑
- `app/presentation/a2a/agent_card.py`: Registry manifest 기반 Agent Card
- `app/core/graph_retrieval/port.py`: `GraphStorePort`
- `app/infrastructure/graphstore/sql_adapter.py`: PostgreSQL JOIN/`WITH RECURSIVE` Adapter
- `tests/unit/ports/test_team_ports.py`: Local/A2A/Agent Card 테스트

## Controller 변경

`Controller.__init__`에 선택적 `team_executor` 주입점을 추가하고, 기본값은 `LocalTeamExecutor(registry)`로 두었다. 실행부의 기존 `entry.module.execute(task)` 직접 호출을 `self.team_executor.execute(task)` 한 곳으로만 교체했다. Case 상태 전이, timeout, retry, 결과 적용 로직은 변경하지 않았다.

## 단계별 검증

1. 구현 후 핵심 계약/Controller/API 테스트: `100 passed`
2. 신규 Port + 계약 + Controller 테스트: `55 passed`
3. 실제 PostgreSQL 임시 tenant 경로 검증: `Case(start) → Evidence(has_evidence) → Document(supports)` 반환 확인. 임시 데이터는 같은 트랜잭션에서 삭제했다.
4. 전체 테스트: 신규 테스트 포함 `116 passed, 3 failed, 0 skipped`. 실패 3건은 기존 RAG 통합 테스트가 `api.openai.com` Embeddings 호출을 시도하다 현재 실행 환경의 네트워크 차단(`WinError 10013`)으로 실패한 것이다. 신규 변경으로 발생한 실패는 확인되지 않았다.
