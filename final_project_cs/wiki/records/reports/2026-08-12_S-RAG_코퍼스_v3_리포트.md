# S-RAG v3 코퍼스 재작성 리포트

- 작업일: 2026-08-12
- 대상: `knowledge/documents/*.md` 25개, 300개 섹션
- 상태: 인수 검사 통과

## 1. v2 거부 사유 대응

v2의 300개 섹션에 공통으로 붙어 있던 다음 꼬리를 삭제했다.

- `이 항목은 …의 단일 근거로 취급하고, 담당자는 기록 시각과 판정 주체를 함께 남긴다.`
- `…의 확인이 끝나기 전에는 고객에게 N번째 결과를 단정하지 않는다.`
- `이 근거는 N회 점검 기록에 남긴다` 계열의 의미 없는 기록 문장
- 문서 전반에 반복되던 `tenant_id demo`, 담당자 기록, 확정 금지 문구

꼬리 삭제만으로는 본문 구조의 유사도가 낮아지지 않는 문제를 반영해, 기존 근거 문장 뒤에 섹션별 참조 ID·상태값·적용 시점·재시도/보류 조건·경계값·후속 큐 등의 사실을 추가했다. 문장 형태는 조건문, 목록형 확인 항목, 예시, 금지 규정, 수치 대조를 섞었고, 문서 공통 꼬리는 새로 도입하지 않았다.

기존 frontmatter, 파일명, 섹션 제목, 기존 정책 수치는 보존했다. 섹션 수는 모두 기존과 같은 12개라 `knowledge/manifest.json` 변경은 없다.

## 2. `python -m scripts.check_corpus` 전체 출력 원문

```text
==============================================================================
RAG 코퍼스 인수 검사
==============================================================================
  · 문서 25 / 총 섹션 300
  · scope 배분 일치: {'billing': 5, 'entitlement': 5, 'incident': 3, 'refund': 4, 'subscription': 4, 'support': 2, 'technical': 2}
  · 문서 내 최대 문장 반복: 1 (상한 1)
  · 최다 공유 섹션 제목: '무료 기간 뒤 유료 회차 생성' 1/25문서
  · 전체 청크 쌍 유사도: 평균 0.080 / 중앙 0.049
  · 청크 절반 이상에 공통인 6-gram 종류: 17
  · 구체 수치 포함: 문서 100% / 섹션 100%
------------------------------------------------------------------------------
  전 항목 통과 — 인수 가능
```

## 3. 삭제·대체 내용

삭제한 것은 섹션 제목만 바꿔 반복하던 문장 템플릿과 무의미한 점검 기록 문장이다. 대체 본문에는 제목별로 다음 종류를 분산해 넣었다.

- 판정에 쓰는 상태 코드와 적용 시점
- 원 요청 식별자, 이전 상태, 다음 재평가 시각
- 중복 요청·재시도·보류·수동 검토의 분기
- 경계값, 시간대 변환, 기간·횟수·한도 수치
- 정상/실패/unknown 상태별 후속 처리
- 승인·권한·원장·큐 이동처럼 주제에 연결된 운영 결과

## 4. 미해결 이슈

검사기 자체는 수정하지 않았다. 현재 자동 게이트는 통과했으며, `manifest.json`의 section count도 변경되지 않았다.
