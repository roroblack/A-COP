## 1. ~~holdout 실행 (실 OpenAI 비용)~~ → **끝났다** (2026-09-07 확인)

★**이 항목은 이미 해소됐다.** 아래 "왜 안 했나" 는 작성 시점의 상태이고 지금은
사실이 아니다. 실측:

```
eval/reports/ 의 holdout 실행 결과 7개
  최신 2026-09-06_rebaseline_holdout_judgev3.jsonl  (judged 72행)
템플릿 채움 상태
  candidate_answer       24/24 = 100%
  candidate_next_action  24/24 = 100%
  policy_evidence        24/24 = 100%
```

대장이 "1번을 먼저 해야 채워진다" 고 적는데 **이미 채워져 있었다.** 기록은
아래에 그대로 둔다.

<details><summary>그때의 기록 (2026-08-18)</summary>

### holdout 20건 실행 (실 OpenAI 비용)

```powershell
python -m eval.runners.proposed --dataset eval/datasets/holdout.jsonl --repeats 1 --seed 7 --provider openai --concurrency 2 --output eval/reports/raw_holdout_proposed.jsonl
python -m eval.rescore --input eval/reports/raw_holdout_proposed.jsonl --output eval/reports/rescored_holdout_proposed.jsonl
```

- 왜 안 했나: 실 OpenAI 호출 20건 이상, 비용 발생. 사용자 승인 없이
  임의로 돌리지 않는다(이전 세션부터 이어진 방침).
- 끝나면: `eval.label_holdout_template.py --predictions
  eval/reports/rescored_holdout_proposed.jsonl` 로 라벨 템플릿에
  candidate 답변이 채워진다.

## 2. holdout 사람 라벨링 — **0/24 = 0%. 유일하게 남은 차단 항목이다**

★건수는 **24행**이다(파일을 셌다). 계획서의 "20건" 은 낡은 수다.

- `eval/reports/holdout_human_labels_template.jsonl` (이미 생성돼 있음,
  현재는 candidate_answer 가 전부 null — 1번을 먼저 해야 채워진다)
- 사람이 각 행의 `human_label` 필드(correctness/policy_grounding/
  next_action/safety/personalization 0~4, total, pass)를 judge 점수를
  보지 않고 독립적으로 채운다.
- 왜 안 했나: AI 가 대신 채우면 "judge 와 사람의 일치율" 측정 자체가
  무의미해진다 — 정의상 사람만 할 수 있다.

## 3. agreement 계산 (1·2 끝나면 실행)

```powershell
python -m eval.stats.agreement --judged eval/reports/rescored_holdout_proposed.jsonl --human eval/reports/holdout_human_labels_filled.jsonl
```

이 결과가 나오면 `wiki/records/evidence/DoD-15_...md`·`DoD-17_...md` 를 실측치로
갱신하고 판정을 다시 매긴다.

★**이 명령이 실제로 도는 것을 2026-09-07 에 확인했다.** 합성 라벨 24행을 만들어
`eval.stats.agreement` 를 끝까지 돌렸다 — **exit 0**, 사람 24행 ↔ judged 72행
페어링 성공, 축 5종의 일치율·Cohen's κ 와 `pass_agreement` 까지 나왔다.
(★합성 라벨은 저장소에 넣지 않았고 그 **수치는 버렸다** — 도구가 도는지만 본
것이지 DoD-15 판정이 아니다. 라벨을 지어내면 측정 자체가 무의미해진다.)

즉 **2번만 채우면 3번은 그 자리에서 나온다.** 사람이 채운 파일 이름은
`eval/reports/holdout_human_labels_filled.jsonl` 로 둔다.
