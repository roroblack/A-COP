# Codex 작업 지시 — S-RAG **v5**: 문체는 그대로, 분량만 채운다

## 0. v4 는 문체가 드디어 맞았다. 지우지 마라

현재 `knowledge/documents/` 에 있는 v4 는 **네 번 만에 처음으로 글이 제대로 됐다.**

```
전체 청크 쌍 유사도: 평균 0.002 / 중앙 0.000   (v2 는 0.460)
청크 절반 이상에 공통인 6-gram: 0종            (v2 는 127종)
지표 우회 토큰: 0건                            (v3 는 300/300)
```

★**이 문체를 유지하라.** 소제목이 주제를 가리키고, 문장이 서로 다르고, 공통 꼬리가 없다.

## 1. 유일한 문제 — 분량이 1/4 이다

| 항목 | 실측 | 계약 |
|---|---:|---:|
| 청크 길이 평균 | **56자** | 200~600자 |
| 200자 미만 청크 | **300/300** | ≤ 5% |
| 문서 길이 평균 | **1,268자** | 2,500~4,000자 |

예: `## 환불 창구` 의 본문이 이게 전부다.

> 해지 뒤 발생한 청구는 승인일로부터 14일 이내에 환불을 요청할 수 있다. 요청일이 아니라
> 승인일을 기준으로 계산하며, 14일 경계의 시각은 UTC로 판단한다.

말은 맞지만 **두 문장이라 그 자체로 인용 근거가 되기 어렵다.**
RAG 청크는 검색돼서 그것만 읽혔을 때 답이 나와야 한다.

★게이트에 길이 검사를 넣었다. 이제 `python -m scripts.check_corpus` 가 이걸 본다:

```
· 청크 길이(공백 제외): 평균 ? 최소 ? 최대 ?    → 200자 미만이 5% 이하, 600자 초과 0건
```

## 2. 할 일 — **각 섹션을 200~450자로 늘린다**

★**소제목·문서·수치를 바꾸지 마라.** 지금 있는 각 섹션의 본문 뒤에
**그 주제에 관한 사실을 2~4문장 더 쓴다.**

### 무엇을 더 쓰나

그 소제목이 다루는 주제의 **다음 단계·경계조건·예외·구체 절차**다. 예 (`## 환불 창구`):

> 해지 뒤 발생한 청구는 승인일로부터 14일 이내에 환불을 요청할 수 있다. 요청일이 아니라
> 승인일을 기준으로 계산하며, 14일 경계의 시각은 UTC로 판단한다.
> **접수 채널은 고객 문의와 내부 운영자 등록 두 가지이고, 어느 쪽이든 승인일·승인번호·요청
> 사유를 함께 남긴다. 14일이 지난 요청은 자동 거절이 아니라 예외 심사로 분류하며, 심사에는
> 해지 사유와 사용량 기록이 필요하다. 심사 결과는 접수일로부터 5영업일 안에 회신하고,
> 승인되면 일반 환불과 같은 절차를 탄다. 같은 승인번호로 두 번째 요청이 들어오면 새로 접수하지
> 않고 최초 요청의 상태를 돌려준다.**

굵은 부분이 추가할 종류다 — **그 주제에서만 나올 수 있는 구체적 절차·조건·수치**.

### ★늘리면서 지켜야 할 것

1. **공통 문구를 만들지 마라.** "각 섹션을 이렇게 마무리하자"는 생각이 들면 그게 실패다.
   v1·v2·v3 가 전부 여기서 죽었다.
2. **무작위 토큰·발명 용어 금지.** `(s1-625)`, `[제목/ref-1234]`, `기준 토큰은 …` 자동 거부.
3. ★**`운영 확인은 N회 기록한다`** 가 지금 20/300 청크에 남아 있다. **전부 지워라.**
   무슨 뜻인지 알 수 없는 필러다.
4. **문장 구조를 섞어라** — 조건문 / 목록(①②③) / 표 / 예시 / 금지문.
5. 수치는 **문서 간에 일관**되게. 지금 값(14일, 10분, 5영업일, 90일, UTC 기준 등)을 바꾸지 마라.

## 4. 완료 조건

```powershell
python -m scripts.check_corpus
```

exit 0 이어야 한다. **특히 이 줄들이 동시에 만족돼야 한다:**

```
· 청크 길이: 200자 미만 ≤ 5%, 600자 초과 0건
· 전체 청크 쌍 유사도: 중앙 < 0.25        ← 늘리면서 여기가 올라가면 공통 문구가 생긴 것이다
· 청크 절반 이상에 공통인 6-gram: ≤ 20종
· 청크 30% 초과 공유 14자 문구: 0종
· 구체 수치: 문서 ≥ 90%, 섹션 ≥ 40%
```

★**길이를 늘리다가 유사도가 올라가면 되돌려라.** 둘을 동시에 만족시키는 것이 이번 과제다.
막히면 무엇이 반복되는지 직접 봐라:

```powershell
python -c "
import pathlib,re,collections
c=collections.Counter()
for p in pathlib.Path('knowledge/documents').glob('*.md'):
    for s in re.split(r'^## ',p.read_text(encoding='utf-8'),flags=re.M)[1:]:
        b=re.sub(r'\s+','',' '.join(s.split(chr(10))[1:]))
        c.update({b[i:i+14] for i in range(max(0,len(b)-13))})
for g,n in c.most_common(12): print(n,repr(g))
"
```
