## 4. ★법정 기준 — 이 숫자를 지켜라

계획서 §1 의 수정본이다. **내 초안은 4곳이 틀렸고 네가 잡았다.** 다시 틀리지 마라.

| 항목 | 기준 |
|---|---|
| 청약철회(단순변심) | 7일. 기산점은 **계약내용 서면 수령일**, 공급이 늦으면 공급일 (법 §17①1) |
| 표시·광고 상이 | 공급받은 날부터 **3개월** + 안 날부터 **30일** (단순변심과 별개) |
| 대금 환급 | **3영업일**. 반품은 **재화를 반환받은 날** 기준 (법 §18①) |
| 환급 지연이자 | ★**연 15%** (시행령 §21조의3). 법 §18② 의 40% 는 **상한**일 뿐이다 |
| 반품 배송비 | 단순변심 소비자 부담 / 판매자 귀책 시 판매자 부담 |
| 청약철회 제한 | 법 §17② **6개 범주** + §17⑥ 표시·시험사용 조치 + 시행령 §21 주문제작 요건 |
| 불리한 특약 | 무효 |

★법정 기준과 다른 사내 정책을 쓰려면 **법정 기준보다 유리하다는 것**을 문장으로 밝혀라.
불리한 쪽은 애초에 무효다. **확신 없는 조문 번호를 지어내지 마라.**

## 5. ★중복을 넘기는 방법 (네 리포트의 결론)

게이트는 **공백 제거 후 문자 6-gram** 이다. 명사만 바꿔도
종결어미·공통 업무 문구·숫자 단위의 6-gram 은 남는다. 그래서:

- 문서마다 **업무 객체·분기 조건·예외·입력값·판정 결과**를 다르게 설계한다
- 공통 안내문을 문서마다 복사하지 않는다. 각 문서는 **고유한 판단 절차와 실패 케이스**를 쓴다
- 유사도는 **seed 7 표본(최대 3,000쌍)** 이다. 같은 seed 결과만 보고 안심하지 마라 —
  여러 seed 로 따로 진단해 **우연한 통과**를 배제하라
- 14자 공통 문구 검사(30% 초과 청크)도 있다. 정형 문구를 돌려쓰지 마라

### ★금지 — 과거에 거부된 수법
- ❌ 무작위 토큰 주입으로 유사도 낮추기 (v3 거부)
- ❌ 청크를 짧게 써서 겹침 줄이기 (v4 거부, 평균 56자)
- ❌ 의미 없는 짧은 문장으로 글자 수 채우기
- ❌ 게이트를 고쳐 통과시키기
