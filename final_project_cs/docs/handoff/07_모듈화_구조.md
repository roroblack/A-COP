## 0. 왜 HTML 을 쓰나

`A-COP_구현계획서_A2A_Graph반영.md` §13 은 폴더 구조를 "권장" 수준으로만 적는다.
HTML 브리핑 §5 는 **디렉터리별 책임까지 명시한 완전한 트리**를 담고 있고,
§6 은 그것을 **4개 축**으로 묶는다. 사용자가 확인한 것도 HTML 이다.

★md 와 HTML 이 충돌하면 md 가 이긴다. **폴더 구조는 충돌이 아니라 HTML 만 가진 정보**다.

## 1. 모듈형 Basement — 4개 축 (§6)

| 축 | 구성 | 한 줄 책임 |
|---|---|---|
| **Core Runtime** | Case/Shared State · Controller/LangGraph · Team Registry · Message Bus · Concurrency | Local/A2A Team 을 **동일 Case lifecycle 안에서** 조정한다 |
| **Agent Interoperability** | REST/OpenAPI · MCP · A2A · OAuth/Scope · Agent Card | Personal AI 의 **Tool 접근**과 독립 Agent System 의 **Task 협업**을 분리한다 |
| **Context & Knowledge** | Vector RAG · **GraphStorePort(MVP: SQL Adapter)** · GraphRAG · DB State · Memory | Vector 는 **유사성**을, Graph 는 **연결 관계**를 탐색해 Context Pack 을 만든다 |
| **Agent Team Modules** | Local Team · Remote A2A Team · Own Subgraph · Own RAG/Memory Policy · Own Tools | **동일 Team Contract** 아래 내부 구성과 배포 방식은 독립적으로 설계한다 |

★이 표가 모듈화의 목적이다. 폴더는 이 4축을 물리적으로 드러내기 위한 것이다.

## 4. ★신설해야 할 것 (현재 코드에 없음 — `git grep` 실측)

| 항목 | 위치 | MVP 범위 |
|---|---|---|
| `TeamExecutorPort` | `core/case_runtime/remote_team/` | Controller 가 Team 을 **Port 로** 호출. `LOCAL`/`A2A` 교체점 |
| `LocalTeamExecutor` | 동 | 현재 동작을 그대로 감싼 기본 구현 |
| `A2ATeamExecutor` | 동 | **골격만** — Agent Card 발견 → Task 발행 → Artifact 수신 |
| A2A Task ↔ Case 상태 매핑 | 동 | Adapter 가 매핑하고 **Controller 는 Case 상태만 본다** |
| Agent Card | `presentation/a2a/` | 우리가 A2A **서버**로서 발행하는 capability 문서 |
| `GraphStorePort` | `core/case_runtime/context/graph_retrieval/` | `neighbors` / `path` / `subgraph` |
| `SqlGraphAdapter` | `infrastructure/graphstore/` | **PostgreSQL JOIN·재귀 CTE**. Neo4j/AGE 는 Phase 2 |

★**Graph 저장소 본체를 도입하지 않는다.** 신 계획서 §9-D 가 명시적으로 거부했다 —
"현재 규모에서는 JOIN 이 맞다". Port 와 SQL 어댑터까지만이 MVP 범위다.

★**완전한 A2A 서버를 만들지 않는다.** MVP 는 경로 분리와 Port 확보다.
개인 AI 는 **MCP**(구현 완료), 고객사 Agent 플랫폼은 **A2A**(골격).

## 5. 이동 규칙 — ★기존 동작을 깨지 않는다

1. **테스트가 계속 통과해야 한다.** 현재 113 passed 가 기준선이다
2. 파일을 옮기되 **기존 import 경로에 re-export 를 남긴다**
   (`app/core/contracts.py` 가 `from app.core.case_runtime.contracts import *` 를 하는 식)
   — 한 번에 모든 호출부를 고치면 되돌리기 어렵다
3. **한 계층씩** 옮기고 매번 `pytest tests -q` 를 돌린다
4. ★`transition_case()` 단일 진입점, append-only, Core 격리는 **구조가 바뀌어도 유지**된다
   `tests/contract/test_core_isolation.py` 의 검사 대상 경로를 새 구조에 맞게 갱신한다
