# 2026-08-30 — 모듈 토글 실효화

## 무엇을

`config/project.yaml` 의 모듈 토글이 화면에서 저장만 되고 동작을 안 바꾸던 것을 고쳤다.
여섯 모듈 중 `mcp` 와 `voc` 는 게이트가 아예 없었고, `graph_store` 는 관리자 화면이
조립 경계를 우회해 어댑터를 직접 만들고 있었다.

## 왜

`docs/handoff/08_모듈_컴포넌트_목록.md` §2 가 "모듈을 빼면 그것을 부르는 경로도 함께
빠져야 한다"고, §6 검증기 4번이 "꺼진 모듈을 부르는 경로가 남아 있으면 실패시켜야
한다"고 이미 못박아 뒀는데 구현이 없었다.

특히 `mcp` 가 무거웠다. 도입 기업이 개인 AI 접근을 안 열기로 하고 화면에서 꺼도
tool 3종이 그대로 동작했다. 선언과 실제가 달랐다.

## 어떤 결과로

- 여섯 모듈 전부가 선언에 따라 실제로 코드를 가른다. 선언을 바꿔 가며 확인했다
  (`python -m scripts.verify_module_toggles`).
- 계약 테스트 9건 신규. 전체 415 → 424 통과, 회귀 0건.
- 관리자 화면을 실제 브라우저로 열어 `graph_store` 를 껐다 켜며 확인했다.
- **`voc` 는 끄면 앱이 기동하지 않는다.** 인라인 분류가 Case 생성 경로에 붙어 있고
  `CLAUDE.md` §1 이 그것을 선택 기능이 아니라고 못박았기 때문이다. 계약 문서 쪽이
  사실과 달랐던 경우라 `docs/handoff/08` 을 정정했다.
