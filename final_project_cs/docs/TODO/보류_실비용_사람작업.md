# 보류 — 실비용(API) 또는 사람 판단이 필요해서 미룬 작업

★이 목록은 `docs/vision/TODO_VISION.md`(규모 확장 시 도입 검토, 트리거
기반)와 다르다. 여기는 **지금 당장 할 수 있는데 리소스(돈) 또는 사람
손이 없어서** 못 하는 것만 적는다. 사람이 조건을 채워주면 그 즉시 실행
가능한 상태로 도구는 이미 준비돼 있다(2026-08-18 기준).

## 1. holdout 20건 실행 (실 OpenAI 비용)

```powershell
python -m eval.runners.proposed --dataset eval/datasets/holdout.jsonl --repeats 1 --seed 7 --provider openai --concurrency 2 --output eval/reports/raw_holdout_proposed.jsonl
python -m eval.rescore --input eval/reports/raw_holdout_proposed.jsonl --output eval/reports/rescored_holdout_proposed.jsonl
```

- 왜 안 했나: 실 OpenAI 호출 20건 이상, 비용 발생. 사용자 승인 없이
  임의로 돌리지 않는다(이전 세션부터 이어진 방침).
- 끝나면: `eval.label_holdout_template.py --predictions
  eval/reports/rescored_holdout_proposed.jsonl` 로 라벨 템플릿에
  candidate 답변이 채워진다.

## 2. holdout 20건 사람 라벨링

- `eval/reports/holdout_human_labels_template.jsonl` (이미 생성돼 있음,
  현재는 candidate_answer 가 전부 null — 1번을 먼저 해야 채워진다)
- 사람이 각 행의 `human_label` 필드(correctness/policy_grounding/
  next_action/safety/personalization 0~4, total, pass)를 judge 점수를
  보지 않고 독립적으로 채운다.
- 왜 안 했나: AI 가 대신 채우면 "judge 와 사람의 일치율" 측정 자체가
  무의미해진다 — 정의상 사람만 할 수 있다.

## 3. agreement 계산 (1·2 끝나면 실행)

```powershell
python -m eval.stats.agreement --judged eval/reports/rescored_holdout_proposed.jsonl --human eval/reports/holdout_human_labels_filled.jsonl
```

이 결과가 나오면 `docs/evidence/DoD-15_...md`·`DoD-17_...md` 를 실측치로
갱신하고 판정을 다시 매긴다.
