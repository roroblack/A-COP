## 곁들여 — §8-D 「쓰기 계약」 표는 이제 코드와 맞는다

같은 절의 마지막 행이 이렇게 적는다:

> revision — 내용 해시. 저장(desired)과 실행 중(active)을 구분하고, 바뀐 선언은
> `/admin/reload`로 재기동 없이 반영한다

**이 문장을 쓸 때 cs 에는 `/admin/reload` 가 없었다**(계약 1.0, 그 경로는 404).
계획이 앞서 있었고 구현이 따라오지 않은 자리였다. 2026-09-06 에 sample 에서
이식해 지금은 맞는다 — 계약 **1.1**, scope `ops:reload`.

살아 있는 프로세스 실측:

```
[1] 시작       active=6cca23ee13b8 desired=6cca23ee13b8 state=active 계약=1.1
[2] 토글       200 · a2a_executor False → True
[3] 토글 직후  active=6cca23ee13b8 desired=2b89b5f40370 state=stale   ← 전에는 여기서 active 라고 답했다
[4] reload     200 {active: 2b89b5f40370, state: active}
[5] reload 후  active=2b89b5f40370 state=active · a2a_executor 실제로 True
```

즉 §8-D 는 **두 문장 중 하나만 고치면** 코드와 완전히 일치한다.
