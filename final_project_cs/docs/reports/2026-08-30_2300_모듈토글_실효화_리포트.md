### 위험도

`mcp` 가 제일 무겁다. 계약이 "끄면 사라진다"고 적은 표면은 **개인 AI 의 read-only
접근**이다. 도입 기업이 MCP 를 안 열기로 하고 화면에서 껐는데 실제로는 열려 있었다.
선언과 실제가 다른 상태에서 운영자가 선언을 믿고 판단하게 된다.

`graph_store` 는 표시 결함이다. 꺼도 관리자 화면이 `SqlGraphAdapter` 라고 적었다.
사람이 화면을 보고 "그래프가 켜져 있구나" 라고 잘못 읽는다.

`voc` 는 아래 §4 에서 따로 다룬다.

## 4. `voc` 를 끄면 앱이 기동하지 않는다

이번 변경의 유일하게 껄끄러운 결과라 따로 적는다. 실측 출력이다.

```
===== VOC 끔 — 기동 자체가 거부된다   (voc: false)
기동 -> ProjectConfigError | module 'voc' is disabled; cannot assemble inline classifier
```

계약 §2 는 `voc` 를 "선택 가능" 목록에 넣어 뒀지만, `CLAUDE.md` §1 은
**"인라인 분류는 선택 기능이 아니다"** 라고 못박았다. 둘이 어긋난다.

`CLAUDE.md` 를 따랐다. 분류를 조용히 건너뛰면 `intent` 와 `sentiment` 가 빈 채로
Case 가 만들어지고 그 빈 값이 근거 조합을 거쳐 고객 답변까지 간다. 그래서 조용히
넘어가는 대신 그 자리에서 실패시켰다.

**계약 문서를 코드에 맞춰 고쳤다**(`RULE.md` §3.5 는 계약을 먼저 고치라고 하는데,
이번엔 계약이 사실과 달랐던 경우라 계약 쪽을 정정했다). `docs/handoff/08` §2 의
VOC 행에 "★끌 수 없다" 를 붙이고 이유를 적었다.

정말로 끄고 싶으면 Case 생성 경로에서 분류를 떼어내는 별도 작업이 먼저 필요하다.
그건 이 계획의 범위가 아니다.

### 실제 브라우저

`CLAUDE.md` §4 를 따라 화면을 열었다. `graph_store` 를 껐다 켜며 관리자 화면의
Ports 표가 `SqlGraphAdapter` ↔ `모듈 꺼짐 (graph_store)` 로 바뀌는 것을 확인했다.
읽은 값 원문은 evidence 문서 §4 에 있다.

`--reload` 없이 띄웠다. 모듈 조립은 기동 때 한 번만 일어나 선언을 바꾸면 재기동해야
하고, 이전 세션에서 reload 자식 프로세스가 남아 옛 코드를 서빙한 적이 있다.

## 6. 이번에 내가 틀렸던 것

★대화 중 사용자에게 **"graph_store 어댑터가 응대 흐름에 안 붙어 있는 것이 결함"**
이라고 먼저 보고했다. 틀렸다. 계약 `docs/handoff/08` §2 는 GraphStore 의 표면을
"관리자 화면의 Graph 섹션" 으로 지정해 뒀고, Context Broker 연결을 요구한 적이 없다.
계약 문서를 읽기 전에 코드 호출처만 세고 판단한 것이 원인이다. 확인 후 정정했다.

★테스트를 처음 쓸 때 게이트 스캔 정규식을 `[a-z_]+` 로 짰다. 모듈 이름에 숫자가
들어가는 `a2a_executor` 를 못 잡아 "게이트가 없다" 고 잘못 붉어졌다. 코드가 아니라
검사기 쪽 결함이었다. `[a-z0-9_]+` 로 고쳤고, 주석에 남겼다 — **검사기가 검사 대상을
못 보는 쪽이 검사 대상이 틀린 것보다 위험하다.**

## 7. 미해결 이슈 · 다음 작업 제안

1. **`app/presentation/ui/routes.py::_legacy_page` 는 죽은 코드다.** 아무도 부르지
   않는데 VOC 링크가 하드코딩돼 있다. 이번 범위가 아니라 손대지 않았다. 지울 것.
2. **`voc` 를 정말 끌 수 있게 만들지는 결정이 필요하다.** 지금은 못 끈다. 끄려면
   Case 생성 경로에서 분류를 떼고, 분류 없이 만들어진 Case 를 어떻게 다룰지
   (`escalated` 로 보낼지) 먼저 정해야 한다.
3. **`final_project_sample` 에는 같은 수정이 안 들어갔다.** 참고 구현체도 `mcp` 와
   `voc` 게이트가 없다(같은 방법으로 확인). 이식 대상이다.
4. **`mcp` 모듈은 지금 아무 데서도 서빙되지 않는다.** `FastMCP` 객체가 만들어질 뿐
   실행하는 코드가 없다. 게이트는 달았지만, 실제로 MCP 를 열 때 그 진입점에도
   같은 게이트가 필요하다.
