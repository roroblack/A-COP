# 밤샘 작업 요약 2026-08-20

## 한눈에

밤새 확인·작성된 보고서는 9건이고, 다이어그램 관련 파일은 17개다. 다이어그램은 8종의 `.puml`·`.svg` 쌍과 8종을 한 번에 보여주는 HTML 모음 1개로 구성돼 있다. 이번 요약문은 이 결과를 한 문서로 묶는다.

가장 중요한 발견은 다음 세 가지다.

1. **Composer v3 설계와 실제 구현이 불일치한다.** 설계가 요구한 `POST /composer/toggle` 토글 전용 계약 대신, 구현은 전체 `ProjectConfig`를 검증·교체하는 v2형 `/composer/validate`·`/composer/apply`를 사용한다. 패키지 경계와 `acop_basement`의 Composer 결합도 설계와 다르다.
2. **DoD는 핵심 런타임 골격은 있으나 운영·평가 단계가 비어 있다.** 29개 중 정적 코드·테스트 기준으로 구현됨 18개, 부분 구현 9개, 미구현 1개, 판정 불가 1개다. 스케줄러, outbox replay 검증, holdout harness, 통계 report·CI gate 등이 대표적인 공백이다.
3. **문서 정합성 문제는 실행을 즉시 막는 수준보다 기준선 관리 문제에 가깝다.** 깨진 참조·병합된 원본 파일명·누락된 색인이 있고, Composer v3와 최근 브리핑 문서가 기준선 목록에 충분히 반영되지 않았다. 상태도 라벨 오류와 배포 다이어그램 가독성 문제는 조치됐다.

## 발견된 문제

심각도가 높은 순서로 추리면 다음과 같다.

1. **Composer v3 핵심 계약 미구현.** `/composer/toggle`와 토글 입력 shape가 없고 전체 config를 받는 `/composer/apply`가 동작한다. Composer가 Core 모델·설정·router wiring에 결합돼 있으며 선택 설치 패키지와 고객 build 제외도 증명되지 않는다. 상세는 `program/research/_컴포저_설계대비_구현대조.md`를 본다.
2. **평가 실행 경로 부재.** A/B/Proposed 60건·holdout 20건 harness와 paired 결과 report가 없다. bootstrap CI·McNemar 함수와 단위 테스트는 있으나 DoD 15 결과를 report·CI gate로 잇는 경로가 없다. 방어 지표도 단위 검증은 있으나 실제 두 모델 비교 결과와 CI 기록이 없다. 상세는 `program/research/_DoD_구현갭_분석.md`와 `program/plan/A-COP_DoD_잔여작업_계획.md`를 본다.
3. **운영 경로와 통합 검증 부족.** migration·Contract Freeze CI gate, graph projection replay, outbox worker failure injection, 모든 consumer의 중복 처리 검증, 일일 VOC scheduler, trace·approval·VOC 단일 E2E가 부족하다.
4. **실행 데이터·경계 계약의 잔여 갭.** 정책·FAQ 25문서와 306 chunk ingest 코드·검증 테스트는 확인됐다. Team의 직접 Tool 호출 금지는 정적·runtime으로 막지 않는다. DoD 1 원본 v4 hash는 비교 대상과 기준값이 없어 판정할 수 없다.
5. **문서 기준선의 판단 필요.** A 묶음의 병합 원본명·죽은 HTML 참조·절 색인 문제는 수정됐다. 최근 Composer v3·briefing 문서군을 기준선 목록에 넣을지는 별도 판단으로 남아 있다. 상세는 `program/research/_정합성_수정제안.md`를 본다.

정합성 점검에서 계획서의 `§숫자` 참조와 §27 DoD 번호 자체는 무결했다. Team 기준선도 계획서 주요 절에서는 일치했다. 문제는 주로 브리핑의 한 카드 표기, 병합 이력 파일명, 색인·기준선 갱신에 있다.

## 검증 상태와 한계

다이어그램 8종은 전부 SVG 렌더링에 성공했다. 그중 상태도·ERD·배포도는 사람이 실제 이미지를 눈으로 확인했다. 배포 다이어그램은 선 교차가 많다는 지적을 받아 공유 인프라를 한 묶음으로 모으고 포트 라벨을 note로 빼는 방식으로 배치를 개선한 뒤 재렌더링했다.

상태 다이어그램의 라벨 오류도 수정됐다. §19 표의 “진입” 열은 해당 상태로 들어오는 조건인데, 이를 나가는 전이의 라벨로 잘못 붙였던 문제였다. 현재 범례에는 영문 라벨은 §19 mermaid 초안에서 왔고 한글 라벨은 설명용으로 추가했다는 점이 적혀 있다.

DoD 갭 분석과 cs 구현 현황은 정적 코드 읽기만 했다. 테스트는 실행하지 않았다. 따라서 “구현됨”은 보고서의 코드·테스트 연결 확인을 뜻하며, 이번 밤에 테스트 실행까지 끝났다는 뜻은 아니다.

Composer 대조는 커밋 `033ebc2`와 당시 미커밋 상태를 기준으로 한 스냅샷이다. 다른 세션이 해당 저장소에서 작업 중일 수 있으므로 현재 상태와 달라졌을 가능성이 있다.

밤샘 작업 중 `A-COP_구현계획서_v8.md`, `A-COP_Composer_v3_설계_토글전용_UI이관.md`, `CLAUDE.md`는 수정되지 않았다. 파일 수정 시각으로 확인했다. `A-COP_구현계획서_v8.md`가 git에서 변경 상태로 보이는 것은 2026-08-19에 사람이 archive를 가리키던 깨진 참조 문장을 삭제한 수정이 아직 커밋되지 않았기 때문이며, 밤샘 작업과 무관하다.
