## 남은 판단 항목

| 항목 | 현재 결정 | 남은 확인 |
|---|---|---|
| A2A Remote Agent | 더미 Remote Agent 1개를 MVP에 포함 | 실제 외부 조직과의 상호운용은 후속 과제 |
| 인증 | Registry에 `auth_scheme`를 보관 | Signed Agent Card 검증 방식은 후속 결정 |
| 상태 정책 | Adapter가 Case 상태로 매핑하고 미확인 결과는 `unknown`으로 보존 | 실제 deadline·재시도 횟수의 운영값 확정 |
| Graph Adapter | `SqlGraphAdapter`를 MVP로 사용 | AGE/Neo4j 비교는 8~9주차 여유 시 수행 |
| 개인 AI 연결 | 개인 AI는 MCP, 고객사 Agent 플랫폼 위임은 A2A | 제품별 지원 범위가 변하면 공식 문서 재확인 |
