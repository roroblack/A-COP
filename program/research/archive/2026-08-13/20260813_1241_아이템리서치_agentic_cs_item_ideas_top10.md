# SKN FINAL 141개와 중복 제거 후 아이템 Top 10
2026-08-13. 50개 후보 전체를 SKN FINAL 141개 저장소(README 원문 기준)와 대조.

## 필터링 방법
각 아이템의 핵심 키워드를 141개 저장소의 README+설명 전문에서 단어 경계 매칭으로 검색하고,
매칭된 부분의 앞뒤 문맥(스니펫)을 직접 대조해 "진짜 같은 기능"과 "우연히 같은 단어가
쓰인 것"을 구분했습니다. (예: "RFI"는 영어 "verify"의 일부로도 매칭되는 오탐이 있어서
단어 경계 정규식으로 재검사했습니다.)

## 우연한 키워드 매칭 — 실제 겹침 아님 (제외하지 않음)
문맥을 확인한 결과 아래는 실제 기능 겹침이 아니라 단어만 우연히 등장한 경우입니다.
- "수출입 화물 통관서류" → SKN20-2(FTOGuard)는 특허침해 벌칙 설명 중 "수출입 차단"을 언급한 것뿐, 통관서류 검증 기능 없음
- "ESG·탄소배출" → SKN14-4에서 "탄소배출권"이 부수적으로만 언급됨 (핵심 기능 아님, 확신도 낮아 보류 표시)
- "여행 예약 변경" → MediPaw의 "예약 변경"은 동물병원 예약 얘기, 여행과 무관
- "고령자 웨어러블" → SKN30-5의 "웨어러블"은 안티패턴 설명 예시로 언급된 것
- "OTT 해지방어 리텐션" → Triver(SKN21-2), SKN24-4의 "리텐션"은 일반적인 지표 용어로만 쓰임

## 주의: 도메인은 겹치지만 핵심 기능은 다른 2개 (제외하지 않되 차별화 필요)
- **병원 진료 전 증상 정리**: MediPaw(SKN25-1)가 "AI 문진"을 이미 다루지만 **반려동물 병원**이 대상입니다. 사람 병원 대상으로 하면 도메인은 겹쳐 보여도 실제 규제·데이터가 완전히 다릅니다.
- **전세·월세 계약 위험 분석**: GoZip(SKN18-1)이 부동산 매물 **추천**을 다루지만 계약서 **위험조항 진단**은 안 합니다. Bizi(SKN20-6)도 "상가임대차"를 컨설팅 항목 중 하나로만 언급합니다.

## Top 10 (중복 제거 + 자료 보강)

### 1. IT 헬프데스크 티켓 자동 분류·해결
- **실현 가능성**: 쉬움
- **실제 사례**: Getronics가 OneReach.ai로 연 100만 건 이상 IT 티켓을 자동 처리 중 ([OneReach.ai](https://onereach.ai))
- **데이터**: Kaggle에 IT Service Desk 티켓 공개 데이터셋 존재 (분류 라벨 포함)
- **왜 좋은가**: "문의 접수→감정/긴급도 분류→전문 에이전트 라우팅→맞춤 해결책" 구조가 원래 주제와 정확히 일치

### 2. 카드 이상거래 문의·1차 사기조사
- **실현 가능성**: 보통 (민감정보 취급 주의 필요)
- **데이터**: Kaggle "Credit Card Fraud Detection" — 실거래 284,807건, 사기 492건 라벨링된 공개 데이터셋 (2013년 유럽 카드사 실데이터 기반, 익명화됨)
- **왜 좋은가**: "분석" 파트(이상거래 탐지 모델)가 실데이터로 탄탄하게 검증 가능한 몇 안 되는 아이템

### 3. 현장서비스(보일러/에어컨) AS 접수·진단 자동화
- **실현 가능성**: 보통
- **실제 사례**: 배관업체 전화응대 AI 스타트업 Avoca가 2026-04-27 1,250억원(1억2,500만 달러) 투자 유치, 밸류 1조원대
- **데이터**: 실사례 없으면 제품 매뉴얼 RAG + 합성 AS 시나리오로 대체
- **왜 좋은가**: 고객 설명의 "감정(짜증/불안)+긴급도"를 다루는 게 자연스러워서 멀티에이전트 정당화가 쉬움

### 4. 자동차 사고 후 보험·정비·렌터카 접수조정
- **실현 가능성**: 보통 (보험금 확정은 사람 승인 단계로 제한 필요)
- **데이터**: 공개 차량 손상 이미지 데이터셋 + 정비 표준공임 자료, 합성 사고보고서
- **왜 좋은가**: 사진+텍스트 멀티모달 입력, "사고분류/서류안내/정비견적/대차일정" 4개 전문 에이전트로 자연스럽게 분리됨

### 5. 아파트 관리비 이상탐지·민원 자동 처리
- **실현 가능성**: 쉬움
- **데이터**: **K-apt(공동주택관리정보시스템)**가 국토교통부 근거로 전국 의무관리대상 공동주택의 월별 관리비(공용관리비·개별사용료·장기수선충당금)를 실제로 공개 중이며, [공공데이터포털](https://www.data.go.kr/data/15058453/openapi.do)에서 오픈API로 다운로드 가능 — 실제 존재가 확인된 데이터
- **왜 좋은가**: 국내 공공데이터로 실데이터 기반 이상탐지가 가능한 몇 안 되는 아이템, 외부 시스템 연동 불필요

### 6. 항공편 결항·지연 시 대체여정·환불 자동 처리
- **실현 가능성**: 쉬움 (Codex도 동일하게 평가)
- **데이터**: 항공사 환불 규정(공개), 공공 항공 운항정보, 합성 결항 시나리오
- **왜 좋은가**: 정책 문서 근거 기반 응대 구조가 명확해서 RAG+가드레일 패턴을 보여주기 좋음

### 7. OTT/멤버십 해지방어(리텐션) 자동 협상
- **실현 가능성**: 쉬움~보통
- **데이터**: 합성 구독데이터 + 해지사유 텍스트는 공개 리뷰 데이터로 대체 가능
- **왜 좋은가**: "이탈사유 감정분석→개인화 오퍼 생성"이 원래 주제("피드백 분석+맞춤 응대")와 가장 직접적으로 일치하는 아이템

### 8. 택배 배송지연·파손 보상 자동 처리
- **실현 가능성**: 쉬움
- **데이터**: 공공 물류데이터 일부 + 합성 배송이력
- **왜 좋은가**: 가장 흔한 실생활 CS 시나리오라 심사자 공감을 얻기 쉽고, "원인분석→보상기준 매칭→환불처리" 구조가 단순 명확

### 9. 중고거래 플랫폼 분쟁조정 자동화
- **실현 가능성**: 보통
- **데이터**: **한국소비자원**이 "품목별 피해구제 사례" 데이터셋을 [공공데이터포털](https://www.data.go.kr/data/15090382/fileData.do)에 공개 중(질문/답변 포함), 분쟁조정결정사례도 [kca.go.kr](https://www.kca.go.kr/odr/bj/br/osBjDecisionExamW.do)에서 열람 가능
- **왜 좋은가**: "사기의심/미배송" 분쟁에서 양측 감정과 증거를 다루는 구조가 멀티에이전트 판정 시나리오로 설득력 있음

### 10. 임대차 계약서 위험조항 진단 상담
- **실현 가능성**: 보통
- **실제 사례**: 법률 전문 에이전트 Harvey AI가 2026년 기준 밸류 5조원 이상으로 평가받는 실제 카테고리
- **데이터**: 국가법령정보센터·법제처 공개 판례/표준계약서
- **왜 좋은가**: "문서분석 상담"에 가깝긴 하지만, 원래 주제의 "고객 문의→분석→맞춤 답변" 골격은 그대로 유지됨
