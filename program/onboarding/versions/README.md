## v3 (지금)

- 낱장을 HTML 로 그린다. 글자를 긁고 검색할 수 있다.
- 낱장 오른쪽에 누적 패킷 칸을 붙였다.
- 열두 칸 지도는 진행바의 단추를 눌러야 덮어 뜬다.
- 낱장마다 `이 흐름이 만드는 파일 / 읽는 파일 / 파일이 생기는 다른 경로` 를 적는다.
- 낱장 내용은 그림을 그리는 `trace/steps.py` 에서 그대로 가져온다.
  옮겨 적지 않으므로 그림과 화면이 어긋날 수 없다.
- 파일이 4.6MB 에서 2.0MB 로 줄었다. 낱장 PNG 열두 장을 안 넣기 때문이다.
  그 PNG 는 `trace/images/` 에 그대로 있고 영상이 쓴다.
