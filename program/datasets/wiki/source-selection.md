# 소스를 왜 이걸로 골랐나

`[실측]` 2026-08-20. 원본 셋을 합쳤다.

```
_codex_independent_research_2026-08-20.md    독립 조사
_완결성점검_codex_2026-08-20.md               빠진 게 없나
PLAN.md                                      선택 근거
```

**`REPORT.md` 는 "무엇을 찾았나"만 적고 "왜 이걸 골랐나"가 없었다.** 그 자리를 메운다.

## 결론 — 더 찾을 게 아니라 정리할 때다

> **대규모 공개 원문 학습데이터 확보라는 기준에서는 현재 목록이 실질적으로 충분하다.**

**다만 "완결"을 한정해서 말한다.**

| 축 | 근거 |
|---|---|
| **양** | 쇼핑 리뷰 **45만 건 이상**, 민원·상담 QA/라벨링 **수백만 건** |
| 과업 커버리지 | 리뷰 감성 · 속성/BIO · 의도·개체명 · 상담 QA · 소비자 피해·분쟁 · FAQ |
| 도메인 다양성 | 쇼핑 리뷰 + 홈쇼핑/e-commerce 콜센터 + 금융·통신·공공 민원 |
| 한국어성 | 핵심은 한국어. **영어·KR3·KOTE 는 보조·검증으로 분리** |
| 공개성 | AI Hub·공공데이터는 출처·이용조건 추적 가능 |

**세 번째가 중요하다.** 도메인이 갈려 있어야 **분포 이동과 hard negative** 를 만들 수 있다.

### 그래서 지금 할 일은 셋이다

```
① 30716·위해위험의 쇼핑몰 분리
② 데이터 계보·중복·라이선스 관리
③ 실제 A-COP 상담 로그로의 도메인 적응
```

**신규 수집이 아니다.**

## 목록 밖에서 확인한 후보

`[실측]` 독립 점검이 다섯을 찾았다.

| 후보 | 판정 |
|---|---|
| **전자거래분쟁조정위원회(ECMC/KISA) 사례집** | **추가 권고** |
| 개인정보보호위원회 분쟁조정 사례집 | 보조 권고 |
| 지자체 120/민원 데이터 | **대부분 원문 대화가 아니다** |
| 국가법령정보센터 판례·재결 | 보조 평가·규정 근거 |
| 2026년 NIA/과기정통부 신규 공고 | **모니터링 대상.** 신규 확보로 치지 않는다 |

`[실측]` **첫 번째 권고가 실제로 반영됐다.** `datasets/voc/ecmc_dispute_casebook_2024/` 폴더가 그 결과다.

**점검이 빈 자리를 짚었고 그게 데이터가 됐다.**
