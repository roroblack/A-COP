# 단위경제

환율은 1 USD = 1,400원으로 고정한다. `[추정]`

## 모델 조직

[../product/personas.md](../product/personas.md)의 정미라 조직을 기준으로 쓴다.

```
상담원 12명 · 연 126,000건
```

## 1. 상담원 1인 실비

급여만 보면 안 된다. 사업주 부담을 전부 쌓는다.

| 항목 | 근거 | 연간 |
|---|---|---|
| 급여 | `[외부:S2]` 평균 연봉 | 28,760,000원 |
| 4대보험 사업주 부담 | `[외부:S3]` 10.67% | 3,068,692원 |
| 퇴직금 | 8.33% (1/12) | 2,395,708원 |
| **인건비 소계** | | **34,224,400원** |
| 좌석 (사무실·PC·헤드셋·회선) | `[추정]` 월 30만원 | 3,560,000원 |
| 채용·교육 | `[추정]` 이직률 40% × 1인 200만원 | 800,000원 |
| 관리자 오버헤드 | `[추정]` 팀장 1인이 12명 관리 | 4,460,000원 |
| **총계** | | **43,044,400원 / 인·년** |

`[외부:S3]` 사업주 부담 10.67%의 내역.

```
국민연금 4.75 + 건강보험 3.595 + 장기요양 0.4724
+ 고용보험(실업급여) 0.9 + 고용안정·직능개발 0.25 + 산재(사무직) 0.7
= 10.67%
```

**급여는 전체의 67%뿐이다.** 나머지 3분의 1이 보험·퇴직금·좌석·이직·관리다.

`[외부:S4]` 이직률이 만만치 않다. 컨택센터 연평균 **30~45%**이고 국내 일부 현장은 더 높다는 보도도 있다. 위 표는 40%로 보수적으로 잡았다.

```
건당 = 43,044,400원 ÷ 10,500건 = 4,100원
```

**두 방법이 서로 맞는다.** [market.md](market.md)의 산업 매출 역산은 4,846원, 여기 직접 고용 적산은 4,100원이다. 아웃소싱이 더 비싼 건 벤더 마진이라 앞뒤가 맞는다.

**건당 사람 비용은 4,100~4,846원 구간으로 본다.**

## 2. A-COP은 사람을 얼마나 덜 쓰게 하는가

**정직해야 한다. A-COP은 상담원을 대체하지 않는다.**

`[실측:S5]` 골든셋 후속 동작 분포가 그렇게 말한다.

| 후속 동작 | 비율 | 사람이 하는 일 | 건당 소요 `[추정]` |
|---|---|---|---|
| respond | 56% | 초안 검토 | 2분 |
| wait_for_approval | 21% | 승인 판단 | 3분 |
| wait_for_input | 18% | 거의 없음 | 1분 |
| escalate + handoff | 5% | 처음부터 사람이 처리 | 8.6분 |

```
사람만    : 실가동 6시간 ÷ CPH 7 = 8.57분 / 건
A-COP 병행: 0.56×2 + 0.21×3 + 0.18×1 + 0.05×8.57 = 2.36분 / 건
             ─────────────────────────────────
             건당 사람 시간 72% 감소, 처리 능력 3.6배
```

## 3. 건당 총비용

| | 사람 시간 | 인건비 | LLM·인프라 | **건당 총계** |
|---|---|---|---|---|
| **A. 상담원만** | 8.57분 | 4,100원 | 0원 | **4,100원** |
| **B. A-COP + 상담원** | 2.36분 | 1,129원 | 3.03원 `[실측:S1]` | **1,132원** |
| B'. 온프레미스 자체호스팅 | 2.36분 | 1,129원 | 10.9원 | 1,140원 |
| C. 완전 자동화 (이론상) | 0분 | 0원 | 3.03원 | 3원 |

```
A → B 절감  : 건당 2,967원 (72%)
모델 조직 연간: 126,000건 × 2,967원 = 3억 7,384만원
```

**C는 도달 불가능하다.** 최소 5%(escalate·handoff)는 구조적으로 사람이고, 21%는 승인 경계가 **일부러** 사람에게 보내는 것이다. C를 사업 계획에 넣으면 안 된다.

## 4. ★ 이 표를 읽을 때의 함정

**72% 절감이 인원 72% 감축을 뜻하지 않는다.** 세 가지 이유다.

**첫째, 인력은 계단식으로만 줄어든다.** 12명이 3.3명이 되지 않는다. 조직 개편 없이는 12명이 그대로 있고 처리량이 늘 뿐이다.

**둘째, 실제 도입에서는 감축보다 처리량 증가로 흡수된다.** 같은 12명이 45만 건을 처리하게 되는 쪽이 현실적이다. 그러면 절감액이 아니라 **매출 대응 능력**이 결과물이 된다.

**셋째, 2.36분이 전부 `[추정]`이다.** 네 줄의 소요 시간을 아무도 안 쟀다.

| 검토 시간 가정 | 절감률 |
|---|---|
| 2.36분 (현재 가정) | 72% |
| 3.5분 | 59% |
| 5분 | 42% |

**여기가 이 문서에서 가장 약한 부분이다.** 그래서 이 표는 상한선으로만 제시하고, 사업 논거는 §5의 오류 비용으로 세운다.

## 5. 오류 비용 — 주력 논거

```
연간 오류 비용 = 연 처리량 × 오류율 × 오류 1건당 손실
```

| 입력 | 값 | 상태 |
|---|---|---|
| 연 처리량 | 126,000건 | 파생 |
| 오류율 (도입 전) | 1.0% | `[추정]` |
| 오류율 (도입 후) | 0.3% | `[추정]` |
| 오류 1건당 손실 | 30,000원 | `[추정]` |

```
도입 전 : 126,000 × 1.0% × 30,000 = 3,780만원 / 년
도입 후 : 126,000 × 0.3% × 30,000 = 1,134만원 / 년
차이    :                            2,646만원 / 년
```

**LLM 비용 38만원을 써서 2,646만원을 아낀다.** 약 69배다.

세 입력이 전부 `[추정]`이지만 **구조는 옳고, 셋 중 둘은 채울 수 있다.**

| 입력 | 어떻게 채우나 |
|---|---|
| 오류율 (도입 후) | **우리가 이미 잰다.** `근거 정합률`·`근거 초과율` |
| 오류 1건당 손실 | `datasets/voc/ecmc_dispute_casebook_2024` 실제 분쟁 금액 |
| 오류율 (도입 전) | `[미확보]` 도입 기업 사내 데이터 필요 |

### 오류 1건이 3만원인 근거

`[추정]` 세 겹으로 쌓인다.

| 겹 | 예시 | 크기 |
|---|---|---|
| 직접 손실 | 환불 금액 오차 | 수천 원 |
| 재처리 | 재문의 → 확인 → 정정 → 사과. 최초 응대의 3~5배 | 약 2만원 |
| 신뢰 손실 | 이탈, 리뷰, 분쟁 | `[미확보]` |

**직접 손실만 보면 작다. 재처리가 대부분이다.** "금액을 조금 틀렸을 뿐"이 아니라 **한 건이 네 번의 접촉으로 불어나는 것**이 비용의 실체다.

실제 사례는 [../product/problem.md](../product/problem.md)의 환불 계산식 결함.

## 6. 세 줄 요약

1. 사람이 1건 처리에 **4,100~4,846원**. 급여는 그중 67%뿐.
2. A-COP 병행 시 **1,132원**. 그중 LLM은 **3.03원**, 0.27%.
3. **비용의 99.7%가 여전히 사람이다.** LLM 단가 최적화는 의미 없고, 사람 시간과 오류만 의미 있다.
