# 인프라 원가

## 0. ★ 2026-09-01 정정 — 옛 도메인 수치를 걷어냈다

초판은 `eval/reports/raw_proposed.jsonl`·`raw_baseline_a.jsonl`·`raw_baseline_b.jsonl`을 인용했다. **셋 다 2026-08-13 측정이고 `case_id`가 `g-billing-*`인 옛 구독 도메인 데이터다.**

`final_project_cs/CLAUDE.md`가 2026-08-17에 이 측정을 **무효**로 선언했다. 코퍼스와 golden/holdout이 쇼핑몰 도메인으로 교체됐기 때문이다.

| 초판 (무효) | 정정 |
|---|---|
| 건당 4.06원 | **3.03~3.41원** |
| p50 33.9초 | **17.7~20.0초** |
| p95 50.6초 | **32.2~37.3초** |
| Baseline A 0.35원 / B 0.92원 | **새 도메인 재측정본 없음** |

**결론의 방향은 바뀌지 않았다.** LLM 비용은 여전히 사람 대비 무시할 수준이고, 지연은 여전히 실시간 채팅에 부적합하다. 다만 **비교 배수는 더 이상 주장할 수 없다.**

## 3. ★ 우리 장비는 RTX 4070 SUPER 12GB다

일반 시세로 4090을 가정하면 안 된다. 팀 최고 사양은 x600 머신의 **RTX 4070 SUPER 12GB(Windows)**이고, 이 제약이 이미 여러 번 막았다.

`[실측:S2]`

| 시도 | 설정 | 결과 |
|---|---|---|
| v4 | `max_length=11264` | **CUDA OOM** — 배치=1에서도 안 들어감 |
| v5 | `max_length=2560` | **여전히 OOM.** 25분 걸려 실패 — Windows WDDM이 초과분을 shared memory로 넘겨 느리게 끌다 죽음 |
| v6 | `max_length=1024` + evidence 400자 | 겨우 완주 (스텝당 7초) |

```
프로덕션 입력 중앙값 : 10,670 토큰
12GB에서 학습 가능   :  1,024 토큰
                       약 10배 부족
```

**자체호스팅 차별점이 지금 팀 장비에서 학습 기준으로는 성립하지 않는다.**

Windows WDDM의 "느린 실패"도 문제다. Linux는 즉시 OOM인데 Windows는 25분을 끈다. **자체호스팅 제품이면 Linux를 전제해야 한다.**

### 추론은 되는가 `[추정]`

위는 전부 **학습**이다. 추론은 활성값·옵티마이저가 없어 훨씬 가볍다.

```
Qwen2.5-3B (36층, KV헤드 2, head_dim 128, bf16)
KV 캐시 = 2 × 36 × 2 × 128 × 2바이트 = 36 KB / 토큰

건당 10,334 토큰 → 372 MB / 시퀀스
가중치 bf16 6.18 GB + WDDM 예약 1 GB

12 − 6.18 − 1 − 0.5 ≈ 4.3 GB → 동시 약 10 시퀀스
4-bit 양자화 시 → 동시 약 20 시퀀스
```

**계산상 된다. 하지만 측정이 아니다.** §6 참조.

### 온프레미스 `[추정]`

| 항목 | 계산 | 월 |
|---|---|---|
| 하드웨어 상각 | 4070 SUPER 시스템 160만원 ÷ 36개월 | 44,444원 |
| 전력 (산업용) | 평균 150W × 720h = 108kWh × 179원 `[외부:S4]` | 19,332원 |
| 회선 | 기업용 대칭 | 50,000원 |
| **합계** | | **약 114,000원** |

**주택용 전기로 돌리면 계산이 깨진다.** 주택용에만 누진제가 있다. `[외부]`

```
산업용 179원   → 108kWh × 179   = 19,332원
주택 3단계     → 108kWh × 307.3 = 33,188원  (+72%)
주택 최고구간  → 108kWh × 736.2 = 79,510원  (+311%)
```

**사업자 전기 계약이 전제**라고 명시해야 한다.

`[외부]` 2026-04-16부터 산업용이 개편돼 낮(11~15시) kWh당 최대 16.9원 인하, 밤 5.1원 인상이다. **야간 배치가 관행인데 개편은 반대 방향이다.**

## 5. 손익분기

```
손익분기 월 건수 = 월 인프라 비용 ÷ API 건당 3.03원
```

| 경로 | 월 비용 | 손익분기 | 환산 상담원 |
|---|---|---|---|
| **온프레미스 4070 SUPER** | 114,000원 | **37,600건** | **약 43명** |
| RunPod 4090 | 347,200원 | 114,600건 | 약 131명 |
| RunPod A40 | 449,400원 | 148,300건 | 약 169명 |
| AWS g5.xlarge | 1,027,600원 | 339,000건 | 약 387명 |

모델 조직(12명, 월 10,500건) 기준 건당 비교.

| | 월 비용 | 건당 | API 대비 |
|---|---|---|---|
| API (gpt-4o-mini) | 31,825원 | 3.03원 | 1.0배 |
| **온프레미스** | 114,000원 | **10.9원** | **3.6배** |
| RunPod A40 임대 | 449,400원 | 42.8원 | 14.1배 |

**결론이 경로마다 갈린다.**

- **클라우드 GPU 임대는 답이 아니다.** 손익분기가 상담원 131~387명이다
- **온프레미스는 상대적으로 가깝다.** 손익분기 약 43명

**[정정] 초판은 손익분기를 32명으로 적었다.** 건당 비용이 4.06원(옛 도메인)에서 3.03원으로 내려가면서 손익분기는 **올라갔다.** API가 싸질수록 자체호스팅이 불리해진다.

그래도 **원가 절감으로 팔면 안 된다.** 43명 미만에서는 API가 싸고, 무엇보다 §3의 12GB 제약이 아직 안 풀렸다. → [../decisions/D-004-self-hosting-rationale.md](../decisions/D-004-self-hosting-rationale.md)

## 6. 네트워크 트래픽 — 반올림 오차다

| 항목 | 값 |
|---|---|
| 건당 토큰 | 10,334 `[실측:S1]` |
| 건당 바이트 | 약 50KB `[추정]` |
| 모델 조직 연간 | 126,000 × 50KB = **6.3 GB/년** |
| AWS egress ($0.09/GB, 첫 100GB 무료) | **연 800원 미만** `[외부]` |

**100배 규모로 키워도 630GB, 연 8만원이다.** 의사결정에 영향을 주지 않는다.

**단, 음성이 들어오면 완전히 달라진다.** `[실측]` 골든셋에 phone 9건(12.5%)이 있다. 음성은 분당 약 1MB에 STT·TTS가 별도다. **텍스트 결론을 음성으로 연장하면 안 된다.**

## 7. 아직 안 잰 것

| 항목 | 왜 필요한가 | 방법 |
|---|---|---|
| **4070 SUPER 추론 가능 여부** | §3의 배치 10은 계산이지 측정이 아니다. 학습은 이미 막혔다 | `eval/finetune/serve.py` 부하 측정 |
| **4-bit 양자화 정확도 손실** | 12GB를 푸는 가장 값싼 수단인데 대가를 모른다 | AWQ/GPTQ 후 골든셋 72건 재평가 |
| 처리량 (tok/s, 배치) | 손익분기표가 GPU 소화를 가정한다 | 동 |
| 자체호스팅 지연 | API가 이미 p50 17.7~20.0초다 | 동 |

**첫 줄이 전부를 막고 있다.** 학습이 12GB에서 안 돌았다는 건 실측이고, 추론이 된다는 건 아직 산수다.

**둘째 줄이 그다음이다.** 4-bit로 가중치를 1.9GB까지 줄이면 배치가 두 배가 되고 손익분기가 절반으로 내려간다. 대신 정확도가 떨어지면 오류 비용 절감이 깎인다. **원가와 정확도가 같은 손잡이에 달려 있다.**

## 8. 결론 네 줄

1. **12GB VRAM 천장이 원가보다 먼저 걸린다.** 이게 안 풀리면 아래 셋은 의미가 없다
2. **클라우드 GPU 임대는 답이 아니다.** API보다 14배 비싸다
3. **온프레미스는 손익분기가 상담원 약 43명이다.** 사업자 전기 계약과 Linux가 전제
4. **트래픽은 무시해도 되고, GPU 유휴 시간이 진짜 비용이다.** API는 쓴 만큼 내지만 GPU는 놀아도 낸다
