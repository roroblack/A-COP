# D-004 자체호스팅은 규제 논거다

## 맥락

포지셔닝에서 자체호스팅을 차별점으로 내세웠는데, **그 경제성을 아무도 안 쟀다.** 원가 절감으로 팔 수 있는지 확인이 필요했다.

## 결정

> **자체호스팅은 원가 제품이 아니라 규제·보안 제품이다.**

데이터 반출 금지가 1차 논거다. 원가는 상담원 43명 이상에서만 보조 논거로 쓴다.

## 근거 — 원가로는 불리하다

`[실측:S1]`·`[외부:S2]` 모델 조직(상담원 12명, 월 10,500건) 기준.

| | 월 비용 | 건당 | API 대비 |
|---|---|---|---|
| API (gpt-4o-mini) | 31,825원 | 3.03원 | 1.0배 |
| 온프레미스 4070 SUPER | 114,000원 | 10.9원 | **3.6배** |
| RunPod A40 임대 | 449,400원 | 42.8원 | **14.1배** |

손익분기.

| 경로 | 손익분기 월 건수 | 환산 상담원 |
|---|---|---|
| 온프레미스 | 37,600건 | 약 43명 |
| RunPod 4090 | 114,600건 | 약 131명 |
| AWS g5.xlarge | 339,000건 | 약 387명 |

**API는 쓴 만큼 내지만 GPU는 놀아도 낸다.** 이게 차이의 원인이다.

## 선택지와 이유

| 안 | 채택 | 이유 |
|---|---|---|
| 원가 절감으로 판다 | ❌ | 32명 미만에서 거짓이다. 계산할 줄 아는 상대에게 반박당한다 |
| **규제·보안으로 판다** | ✅ | 32명 미만에서도 참이고, 우리 차별점과 일치 |
| 자체호스팅을 접는다 | ❌ | 규제 요건 고객을 통째로 잃는다 |
| 클라우드 GPU 임대를 권한다 | ❌ | 손익분기 131~387명. 온프레미스보다 항상 불리 |

## 결과

**가격 구간을 나눈다.**

| 구간 | 배치 |
|---|---|
| 일반 (32명 미만) | API 경유. 우리가 대행 |
| 규제·보안 요건 | 자체호스팅 (온프레미스) |
| 대규모 (32명+) | 자체호스팅 (온프레미스) |

**클라우드 GPU 임대는 어느 구간에도 안 넣는다.**

## 못 하게 되는 것

- "자체호스팅하면 비용이 절감됩니다"라고 말할 수 없다
- 소규모 고객에게 자체호스팅을 권할 근거가 없다 (규제 요건이 없다면)

## ★ 이 결정을 무효화할 수 있는 것

`[실측:S3]` **12GB VRAM 천장이 아직 안 풀렸다.**

```
프로덕션 입력 중앙값 : 10,670 토큰
12GB에서 학습 가능   :  1,024 토큰
```

팀 최고 사양 RTX 4070 SUPER에서 학습이 3번 막혔다. 추론은 계산상 가능하지만 **측정 안 됐다.**

**원가가 맞아도 장비가 워크로드를 못 받으면 이 결정 전체가 무의미하다.**

| 확인할 것 | 방법 | 시간 |
|---|---|---|
| 4070 SUPER 추론 가능 여부 | `eval/finetune/serve.py` 부하 측정 | 반나절 |
| 4-bit 양자화 정확도 손실 | AWQ/GPTQ 후 골든셋 72건 재평가 | 하루 |

**4-bit가 되면 손익분기가 절반으로 내려간다.** 대신 정확도가 떨어지면 오류 비용 절감이 깎인다. 원가와 정확도가 같은 손잡이에 달려 있다.
