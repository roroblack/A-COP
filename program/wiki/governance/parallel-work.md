# 두 스트림이 같은 파일을 쓰지 않는다

`[실측]` `docs/handoff/05_분업_규칙.md` 에서 이관. **`final_project_cs` 와 `final_project_sample` 양쪽에 같은 파일이 있다** — [work-loop.md](work-loop.md) 의 `RULE.md` 중복과 같은 상태다.

## 무엇을 막나

> 두 작업 스트림이 같은 파일을 쓰면 **마지막에 끝난 쪽이 조용히 이긴다.**
>
> **테스트도 통과하고 diff 도 깨끗한데 다른 스트림의 기능만 사라진다.**

**그래서 인원이 아니라 디렉터리로 경계를 긋는다.**

> **자기 소유 밖의 파일을 만들거나 고치지 않는다.** 필요하면 소유자에게 요청한다.

→ [../delivery/roles.md](../delivery/roles.md) 의 소유 디렉터리 표

## 넘기기 전에 순서대로

| # | |
|---|---|
| 1 | **계약을 먼저 확정한다.** `docs/handoff/` 에 인터페이스가 없으면 돌리지 않는다 |
| 2 | **프롬프트는 계약을 인용한다.** 내용을 복사하지 않는다 — **복사하면 두 벌이 어긋난다** |
| 3 | **한 번에 한 스트림.** 같은 디렉터리를 두 세션이 잡지 않게 |

**2번이 이 wiki 를 만들면서도 계속 걸린 문제다.** 사본을 만들면 어느 쪽이 정본인지 흐려진다.

## ★ codex 샌드박스는 외부 네트워크를 못 쓴다

`[실측]` 2026-08-12 측정. `codex exec -s workspace-write` 로 띄운 프로세스에서 **외부 HTTP 가 전부 막힌다.**

| 관측 | 결과 |
|---|---|
| Claude 셸에서 OpenAI 호출 | **OK** — latency 2,940ms |
| codex 실행 중 OpenAI 호출 | `APIConnectionError` **× 540건 전부** |
| codex 실행 중 tiktoken BPE 다운로드 | `WinError 10013` |

> **LLM·임베딩·외부 API 가 필요한 작업은 codex 에 넘기지 않는다.**

`[실측]` **이 wiki 작업에서도 그대로 적용됐다.** codex 에는 **읽고 정리하는 일**만 맡겼다 — 조사 문서 이관, 반영률 대조, 판정. **실행이 필요한 것은 직접 했다.**

## ★ 받은 뒤 반드시 검사하는 네 가지

> **산출물을 그대로 커밋하지 않는다.**

**넷 다 실제로 나왔던 실패다.**

| # | 검사 | 실제 사례 |
|---|---|---|
| 1 | **계약 위반** | 필드 누락 · 타입 불일치 · `extra='forbid'` 우회 |
| 2 | **범위 임의 삭감** | **MCP·pgvector 를 통째로 삭감했다** |
| 3 | **잘못된 근거** | 12,000 토큰 예산을 **"context window 초과"로 설명** — 실제 근거는 비용·lost-in-the-middle·재현성 |
| 4 | 수치 불일치 · 문법 오류 | 문서 간 숫자 대조 · Mermaid/JSON 파싱 |

**3번이 가장 잡기 어렵다.** 결과가 맞으면 이유가 틀려도 안 드러난다.

> **검수 결과를 리포트에 남긴다. 조용히 고치면 다음에 또 나온다.**

### 이 wiki 작업에서 실제로 걸린 것

`[실측]` 2026-09-03. **3번에 해당하는 것을 두 번 잡았다.**

| 무엇 | |
|---|---|
| codex 가 "테스트 10개를 실행했다"고 적었다 | **로그에 실행 흔적이 없었다.** 직접 돌려 실제 결과로 바꿨다 |
| codex 가 "Controller 가 outbox 를 안 만든다"고 판정했다 | **`controller.py:168` 에서 넘긴다** |

**둘 다 결론은 그럴듯했고 근거가 틀렸다.**

## ★ 넘길 수 있는 일과 없는 일

`[실측]` 2026-08-17. **`final_project_sample` 쪽 §5 에만 있는 절이다** — cs 판에는 없다.

### 한글 주석이 깨진다

**codex 가 PowerShell 로 파일을 읽으면 한글 주석이 mojibake 로 들어온다.**

```
"?꾩닔 ?섍꼍蹂?섍? ?녾굅???섎せ?먮떎. .env.example 瑜?.env 濡?蹂듭궗?댁꽌..."
```

**이 저장소는 주석이 거의 전부 한글이다.** 읽을 파일이 많을수록 **컨텍스트가 깨진 글자로 찬다.**

| 결과 | 발주 | 읽을 파일 |
|---|---|---|
| 성공 | IA 검토 · 콘솔 화면 · Composer 배선 | **적음** — 지시서 + 한두 파일 |
| **두 번 연속 무산** | introspection + 코드 이동 + 패키징 | **많음** — 교차 작업 |

### 규칙 넷

| # | |
|---|---|
| 1 | **읽을 파일을 지시서에 명시한다.** "알아서 파악하라"는 이 환경에서 실패한다 |
| 2 | **넓게 읽어야 하는 교차 작업은 넘기지 않는다** — 리팩터링·패키징·구조 이동 |
| 3 | **로그를 저장소 안에 쓰지 않는다.** 1차 실패는 codex 가 `docs/reports/` 에 쌓인 **자기 로그를 읽는 순환**이었다 |
| 4 | 빌드 검사용 임시 폴더도 저장소 밖에 | 실제로 `.wheelhouse-*` 6개 + `build/` 가 루트에 쌓였다 |

**3번이 특이하다.** 산출물이 다음 입력이 되는 순환을 만든다.

### 넘기기 좋은 일

```
검토·반박    우리 안을 주고 틀린 곳을 짚게 한다
화면 하나    읽을 파일이 명확한 것
테스트 추가  대상 모듈이 지정된 것
```

`[실측]` **실제로 IA 초안이 이 방식으로 뒤집혔다.**

### 산출물을 그대로 믿지 않는다

`[실측]` 2026-08-17 에 나온 것들.

```
항상 참인 단언 · 껍데기 분리(shim 4줄 / 실제 코드 390줄) · 설치할 수 없는 설치 대상
```

**"검사하는 척하는 검사"** 라는 이름이 붙었다.

### 이 wiki 작업이 이 규칙을 지켰나

`[실측]` 2026-09-03 자평.

| 규칙 | 지켰나 |
|---|---|
| 1. 읽을 파일 명시 | **지켰다.** 프롬프트마다 파일 목록을 박았다 |
| 2. 교차 작업 안 넘김 | **지켰다.** 읽고 정리하는 일만 맡겼다 |
| 3. 로그를 저장소 밖에 | **어겼다.** `program/scripts/_codex_out/` 에 썼다 |
| 4. 임시 폴더 밖에 | 해당 없음 |

`[실측]` **3번을 어겼는데 순환은 안 났다.** codex 프롬프트가 읽을 파일을 명시해서(규칙 1) 자기 로그를 안 읽었다. **규칙 1이 3번을 막아 준 것이고, 3번을 안 지켜도 된다는 뜻이 아니다.**

지금 상태.

```
program/scripts/_codex_out/   5.1MB · 34개 (git 에 22개)
  PROMPT_*.md    지시서 — 방법의 기록이라 남길 값이 있다
  *_raw.md       산출물 — wiki 로 이미 옮겼다
```

`[미확보]` **산출물을 저장소에서 뺄지 안 정했다.** 다음에 codex 를 돌릴 때는 **`%TEMP%` 로 뺀다.**
