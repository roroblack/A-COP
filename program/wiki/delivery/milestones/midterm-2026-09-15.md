# 중간발표 2026-09-15

`[실측]` 2026-09-01 기준 **D-14**

## 목표

> **동작한다**

구조가 서 있고 흐름이 도는 걸 보여준다. **"믿을 수 있다"를 주장하면 안 된다.** 아직 근거가 없다.

## 보여줄 것

| 항목 | 무엇을 |
|---|---|
| Case 흐름 | 문의 → Case → Team → 제안 → 승인 → 실행 |
| Team 교체 | Registry 등록만으로 Team이 붙는 것 |
| 승인 경계 | 고위험 Action이 사람에게 가는 것 |
| 근거 대조 | 근거 없는 제안이 걸리는 것 |
| 평가 하네스 | A/B/Proposed가 실제로 돌아가는 것 |

## 그전에 끝낼 것

| 항목 | 소요 | 왜 |
|---|---|---|
| 4070 SUPER 추론 실측 | 반나절 | 자체호스팅을 말하려면 필요 |
| 검토·승인 소요시간 실측 | 반나절 | 사업성 숫자의 근거 |
| 오류 1건당 손실 집계 | 하루 | 가격 논거 |

**합쳐서 이틀이다.** 안 하면 발표에서 "그거 추정 아닌가요"에 답할 수 없다.

## 말하지 말 것

| 안 됨 | 대신 |
|---|---|
| "자동화율 X%" | "잘못 자동화하지 않는 지점" |
| "인원 X명 감축" | "같은 인원으로 X배 처리" |
| "자체호스팅으로 원가 절감" | "데이터를 밖으로 안 내보낸다" |
| "LLM 비용을 아낍니다" | "비용의 99.7%는 여전히 사람" |

**세 번째가 특히 위험하다.** 계산할 줄 아는 심사자에게 바로 반박당한다. 자체호스팅은 API보다 3.6~14배 비싸다. → [../../decisions/D-004-self-hosting-rationale.md](../../decisions/D-004-self-hosting-rationale.md)

## 예상 질문과 답

| 질문 | 답 |
|---|---|
| 그냥 GPT 부르면 되는데 왜 이렇게 복잡한가 | **아직 답할 근거가 없다.** Baseline 재측정 필요 |
| 왜 Team으로 나누는가 | 업무 권한·지식·재처리 경계를 독립시켜 교체를 가능하게 |
| Graph DB 쓰는가 | 아니다. SqlGraphAdapter가 MVP, 채택 게이트 통과 시에만 |
| 통계적으로 믿을 수 있는가 | 60+20, 3회 반복, paired bootstrap CI, McNemar와 한계를 함께 보고 |
| **지연이 p95 32~37초인데 실시간으로 쓸 수 있나** | **못 쓴다. 상담원 보조가 제품 형태다** |

**마지막 질문에 정직하게 답한다.** 숨기면 나중에 더 크게 터진다.
