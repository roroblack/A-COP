## 두 발표의 성격 차이

| | 중간발표 | 최종발표 |
|---|---|---|
| 보여줄 것 | **동작한다** | **믿을 수 있다** |
| 중심 | 구조와 흐름 | 수치와 증거 |
| 지표 | 일부 실측 | 전체 + 통계 처리 |
| 위험 | 범위가 안 좁혀짐 | 지표가 안 나옴 |

**중간발표에서 "믿을 수 있다"를 주장하면 안 된다.** 아직 근거가 없다. 구조가 서 있고 흐름이 도는 걸 보여주는 게 맞다.

## 발표에서 말하지 말 것

[../../product/positioning.md](../../product/positioning.md)의 원칙이 발표에도 적용된다.

| 말하지 않는다 | 대신 |
|---|---|
| "자동화율 X%" | "잘못 자동화하지 않는 지점" |
| "인원 X명 감축" | "같은 인원으로 X배 처리" |
| "LLM 비용 절감" | "비용의 99.7%는 여전히 사람" |
| "자체호스팅으로 원가 절감" | "데이터를 밖으로 안 내보낸다" |
