# 페르소나

3인이다. **장식이 아니라 골든셋과 평가 지표에 연결한다.** 연결되지 않는 페르소나는 만들지 않는다.

## 박선영 — 문의하는 고객

| | |
|---|---|
| 상황 | 온라인으로 산 물건에 문제가 생겨 문의한다 |
| 하려는 것 | 내 건이 어떻게 처리되는지, 돈이 얼마나 돌아오는지 알고 싶다 |
| 막히는 것 | 답변이 맞는지 검증할 방법이 없다 |
| 감정 | 화났다기보다 **불안하고 혼란스럽다** `[실측:S1]` 불안 29% + 혼란 21% |
| 성공 기준 | 한 번 물어서 끝난다. 다시 안 물어도 된다 |

**대표 문장.** "환불 얼마나 받는지, 언제 들어오는지만 알고 싶어요."

박선영은 A-COP을 직접 쓰지 않는다. 쇼핑몰 화면이나 자기 개인 AI를 통해 간접적으로 만난다.

## 김도현 — 상담원

| | |
|---|---|
| 상황 | 하루에 수십 건을 처리한다 |
| 하려는 것 | 정확하게, 빨리 답한다 |
| 막히는 것 | **답 쓰는 시간보다 근거 찾는 시간이 길다.** 주문·배송·규정이 다른 화면에 있다 |
| 두려운 것 | 틀리면 책임이 본인에게 온다 |
| 성공 기준 | 확신을 갖고 답한다. 상급자에게 안 넘겨도 된다 |

**대표 문장.** "이 건 환불 되는 건지 규정을 다시 봐야 하는데 어디 있더라."

김도현은 A-COP의 **직접 사용자**다. 초안을 받아 검토하고 승인한다.

## 정미라 — 운영 책임자 ★ 구매 결정자

| | |
|---|---|
| 상황 | 상담원 12명 규모의 CS 조직을 책임진다 |
| 하려는 것 | 자동화를 늘리되 사고를 안 낸다 |
| 막히는 것 | **어디까지 자동화해도 안전한지 판단할 근거가 없다** |
| 두려운 것 | 잘못 자동화해서 금액을 틀리게 안내하는 것. 그리고 그걸 늦게 아는 것 |
| 성공 기준 | 자동화 범위를 넓히면서 그게 안전하다는 걸 숫자로 보여준다 |

**대표 문장.** "이걸 켜면 뭐가 좋아지는지 숫자로 가져오세요. 그리고 사고 나면 어떻게 막는지도."

**정미라가 돈을 낸다.** 제품 메시지는 이 사람에게 맞춘다. 박선영·김도현의 개선은 정미라를 설득하는 증거로 쓴다.

정미라의 조직이 [../business/unit-economics.md](../business/unit-economics.md)의 모델 조직이다 — 상담원 12명, 연 126,000건.

## 페르소나 ↔ 평가 연결

**이게 이 문서의 핵심이다.** 페르소나마다 어떤 지표가 그 사람의 개선을 증명하는지 정해 둔다.

| 페르소나 | 페인 | 증명 지표 | 골든셋 |
|---|---|---|---|
| 박선영 | 답을 검증할 수 없다 | `groundedness`, `근거 정합률` | 금액 관련 30건 (42%) `[실측:S1]` |
| 김도현 | 근거 찾는 시간이 길다 | `p95 latency`, `intervention` | 전체 72건 |
| 정미라 | 안전 경계를 모른다 | `적절한 기권율`, `과잉 기권율`, `근거 초과율` | 승인·기권 대상 18건 (25%) `[실측:S1]` |

지표 정의는 [../evaluation/metrics.md](../evaluation/metrics.md).

**연결이 끊긴 페르소나는 지운다.** 골든셋에 대응 케이스가 없으면 그 페르소나는 우리가 증명할 수 없는 대상이다.

## 안 만든 페르소나

| 후보 | 왜 뺐나 |
|---|---|
| 개발자 (Team을 추가하는 사람) | 사용자가 아니라 구축자다. [../architecture/core-vs-team.md](../architecture/core-vs-team.md)가 그 대상 |
| 법무·컴플라이언스 | 10주 범위에서 만날 일이 없다. 자체호스팅 논거에만 등장 |
| 개인 AI 사용자 | 박선영과 겹친다. 경로만 다르다(MCP) |
