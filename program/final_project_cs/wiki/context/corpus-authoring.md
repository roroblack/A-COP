# RAG 코퍼스를 쓸 때 지키는 것

`[실측]` `docs/plans/2026-08-17_코퍼스_25문서_배분안.md` 에서 이관.

## 왜 게이트가 있나

**같은 말을 여러 문서에 흩어 두면 검색이 아무거나 집어 온다.** 그래서 중복을 막는다.

## 어휘층을 scope 마다 분리한다

`[실측]` **같은 말을 다른 자리에서 쓰지 않는다.**

| scope | 주어·목적어 | 시간 단위 | 행위 동사 |
|---|---|---|---|
| `order` | 주문번호 · 품목 · 결제수단 | 마감시각 · 분 | 접수 · 변경 · 취소 |
| `shipping` | 운송장 · 물류센터 · 기사 | 영업일 · 경유지 | 스캔 · 출고 · 회수 |
| `return` | 반품접수번호 · 수량 · 사유코드 | 수령일 기준 일 | 회수 · 검수 · 판정 |
| `exchange` | 교환건 · 대체상품 · 재고 | 재출고 일정 | 대체 · 소진 · 전환 |
| `refund` | 승인번호 · 지급요청 · 잔액 | 카드사 영업일 | 산정 · 지급 · 대조 |
| `support` | 티켓 · 채널 · 담당자 | 응답 목표시간 | 배정 · 승급 |
| `incident` | 장애구간 · 공지 · 영향범위 | 복구 시각 | 탐지 · 공지 · 집계 |

## ★ 게이트를 우회하는 네 가지 — 이미 거부됐다

`[실측]` **sample 에서 실제로 거부된 수법들이다.**

| 수법 | 결과 |
|---|---|
| 무작위 토큰을 섞어 유사도를 낮춘다 | **v3 거부 사유** |
| 청크를 짧게 써서 겹치는 6-gram 을 줄인다 | **v4 거부 사유.** 평균 56자 |
| 섹션 끝에 의미 없는 문장을 붙여 글자 수만 채운다 | 거부 |
| **게이트를 느슨하게 고쳐 통과시킨다** | 거부 |

**네 번째가 가장 위험하다.** 통과는 하는데 아무것도 안 막게 된다.

## ★ 어휘 분리만으로는 부족하다

`[실측]` 교차검증에서 나온 반박이 옳았다.

> 게이트는 **공백을 제거한 뒤 문자 6-gram** 을 만든다. `주문/배송/반품` 같은 **명사만 바꿔도 종결어미와 공통 업무 문구의 6-gram 은 그대로 남는다.**

```
~할 수 있다 · ~확인한다 · 숫자+단위 표현
```

**이것들이 구조적으로 겹친다.** 그래서 **길이·공통 6-gram·14자 공통 문구·시나리오 probe 를 함께** 확인한다.

## ★ 한 개를 먼저 써 보고 25개를 쓴다

`[실측]` `doc_01` 초안이 **13섹션 전부 200자 미달**이었다. 평균 150자.

| 검사 | 초안 | 수정 후 |
|---|---|---|
| 섹션 수 | 13 | 13 |
| **길이 위반** | **13/13** | 3/13 |
| 평균 길이 | 150자 | **216자** |
| 문장 반복 | 0 | 0 |

> **한 개를 먼저 검증한 덕에 25개를 잘못 쓰지 않았다.**

**이게 이 문서에서 가장 값진 한 줄이다.** 25개를 다 쓰고 나서 알았으면 전부 다시 써야 했다.
