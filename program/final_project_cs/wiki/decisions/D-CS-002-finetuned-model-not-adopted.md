# D-CS-002 파인튜닝 모델을 채택하지 않는다

`[실측]` `docs/plans/2026-08-30_DoD28-FT-RAG통합_설계.md` (579줄)에서 결정 부분만 분리.

**실행 이력과 실측 기록은 원본에 있다.** 이 문서는 **무엇을 정했고 왜인가**만 담는다.

## 맥락

DoD-28에서 파인튜닝 모델(`Proposed+FT`)이 golden·holdout 양쪽에서 **0% pass**였다. **"배선만 바꾸면 되는가"**가 질문이었다.

## 결정

> **배선은 성공했지만 지금 모델은 채택하지 않는다.**
>
> **하이퍼파라미터를 더 미는 것은 근본 해결이 아니다. 필요한 건 더 많은 실제 데이터뿐이다.**

## 왜 배선만으로는 안 되나

`[실측]` **학습 입력과 실제 호출 입력의 모양이 다르다.**

| | 무엇이 들어가나 |
|---|---|
| **학습 데이터** | 고객 메시지 텍스트 **하나** |
| **실제 Team 호출** | `evidence` 리스트 + `context` + `retry_count` + `tone_profile` 이 든 **dict** |

**"이 dict에서 `evidence_id`를 뽑아 인용해야 한다"를 가르친 적이 없다.**

그래서 그 입력으로 그냥 불러도 **여전히 근거 없이 답한다.**

```
RAG 통합 = 배선 + 재학습    둘 다 필요하다
```

## 선택지와 이유

| 안 | 채택 | 이유 |
|---|---|---|
| 하이퍼파라미터 튜닝 | ❌ | **9건짜리 학습 결과를 더 밀어붙이는 건 근본 해결이 아니다** |
| 배선만 바꿔 채택 | ❌ | 출력 스키마를 배운 적이 없다 |
| **채택 보류 + 데이터 확충** | ✅ | 데이터가 유일한 병목 |

`[실측]` 근거가 프로젝트 원칙에서 나왔다.

> `CLAUDE.md` §4 **"표본이 작으면 작다고 말한다"** 원칙 그대로.

## 데이터를 늘리는 두 경로

| | 방법 | 대가 |
|---|---|---|
| (a) | `response_review.enabled: true`로 켜서 **실 운영 transcript**가 쌓이길 기다린다 | 시간 |
| (b) | 합성-실측 혼합을 **더 큰 case 집합**에 돌린다 | 품질 |

**(b)를 시도했고 결과가 나왔다.** → 아래

## 결과 — 이후 실측

`[실측]` 원본 §5~§7의 결론만.

| 시점 | 데이터 | 결과 |
|---|---|---|
| 2026-08-30 | 9건 | 0% pass |
| 2026-08-30 (b) | 12건 | 재검증 미완료 |
| 2026-08-31 | **84건** (실주문 68건 추가) | **v6에서 첫 유효 출력.** 그러나 시나리오 획일성 |
| 2026-08-31 (2) | +실 민원 93건 | **고유 draft가 여전히 2개뿐** |
| — | stage3-v7 | **채택 불가로 확정** |

**데이터를 9 → 177건으로 늘려도 고유 출력이 2개였다.** 양이 문제가 아니었다.

`[실측]` 원인이 특정됐다 — **draft 동질성의 진짜 원인**은 데이터 양이 아니라 시나리오 다양성이었다.

## 부수적으로 발견한 것

**이 작업이 아니었으면 못 찾았을 결함 셋.**

| # | 무엇 |
|---|---|
| 1 | **`response.generate`가 production에 등록된 적이 없었다.** 그 경로가 매번 죽고 있었다 |
| 2 | **`golden.jsonl`이 이 Team을 단 한 건도 안 거친다.** 평가 데이터 재설계 필요 |
| 3 | 12GB VRAM OOM 3회 + Windows WDDM 느린 실패 |

**1번이 가장 컸다.** → [../teams/response-review.md](../teams/response-review.md)

## 못 하게 되는 것

- 자체호스팅 모델로 `Proposed+FT`를 주장할 수 없다
- DoD-28이 **부분통과**로 남는다
- [자체호스팅 원가](../../../wiki/business/infrastructure-cost.md) 논의가 **정확도 근거 없이** 진행된다

## 다시 열 조건

```
실 운영 transcript 축적  또는  시나리오 다양성 확보
```

**둘 중 하나가 되면 재측정한다.** 하이퍼파라미터로는 안 연다.
