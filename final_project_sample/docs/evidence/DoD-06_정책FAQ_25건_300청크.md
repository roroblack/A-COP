## ★잔여 결함 (인수하되 기록한다)

각 섹션 끝에 **200자 하한을 채우려는 짧은 필러 문장 2개**가 남아 있다.

```
"… 문서 번호를 연결한다. 문서 연결을 확인한다."
"… 잔액을 확인한다. 잔액을 대조한다."
```

- 청크당 약 30~40자 = **전체의 약 15%**
- 같은 뜻을 두 번 말하는 경우가 있다 (`확인한다` / `대조한다`)
- 잔여 정형 문구: `한다. 후속 확인 시각을 남긴다.` 11/300

**인수 판단 근거**: 게이트 전 항목을 통과하고(중앙 유사도 0.002, 공유 6-gram 1종),
본문의 85%는 주제별 구체 절차·수치다. 6회차를 더 도는 것보다
**groundedness 평가(P9)에서 실제 영향이 관측되면 그때 다듬는 것**이 낫다고 판단했다.
P9 에서 policy groundedness 가 기대보다 낮으면 **이 필러를 첫 번째 용의자로 본다.**

## ★검색이 한 번도 동작하지 않았던 기간이 있었다

적재 직후 `search_policy()` 는 **100% 실패**하고 있었다.
질의 벡터가 tuple → `(...)`, 이어서 list → `double precision[]` 로 렌더링돼
`operator does not exist: vector <=> double precision[]` 로 죽었다.
`%s::vector` 캐스트로 해결. 상세와 정정:
`docs/reports/debugs/2026-08-12_2010_RAG검색이_한번도_동작한적이_없다.md`
