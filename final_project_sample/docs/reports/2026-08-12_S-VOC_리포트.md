# S-VOC 인라인 분류·일일 Feedback Analytics 리포트

## 1. 목표

인라인 분류에서 네 필드(`sentiment`, `intent`, `issue_code`, `severity`)를 모두 요구하고, 실패를 `ClassificationFailed`로 명시했다. tenant별 일일/직전 7일 집계와 §4 급증 alert를 리포트와 outbox에 저장했다.

## 2. 변경 파일

- `app/modules/customer_ops/feedback.py`
- `app/application/feedback_job.py`
- `scripts/run_daily_feedback.py`
- `tests/unit/voc/test_feedback.py`

## 3. issue_code 집합

`post_cancel_charge`, `payment_failed`, `billing_other`, `entitlement_mismatch`, `login_issue`, `service_unavailable`, `technical_other`, `other`.

## 4. 실제 출력 원문

실행 명령:

```powershell
python -m scripts.run_daily_feedback --date 2026-08-12
```

실제 stdout:

```text
{"alerts": [], "metrics": {"intent_issue_count": {"prior_7_days": {}, "today": {}}, "negative_ratio": {"prior_7_days": 0.0, "today": 0.0}, "totals": {"prior_7_days": 0, "today": 0}, "unresolved_ratio": {"prior_7_days": 0.0, "today": 0.0}}, "period_end": "2026-08-12", "period_start": "2026-08-05", "tenant_id": "demo"}
```

DB 확인 원문:

```text
reports=1
tenants=1
```

## 5. 급증 판정과 테스트

문서 §4의 식을 그대로 적용했다.

`today >= max(5, 1.5 * avg7) AND today - avg7 >= 3`

경계 테스트 결과:

- `today=5, avg7=4`: alert 없음 (비율 조건만 만족, 절대차 1)
- `today=6, avg7=4.1`: alert 없음 (절대차 조건만 만족, 비율 조건 불만족)
- `today=7, avg7=4`: alert 있음 (두 조건 경계 충족)
- `today=8, avg7=4`: alert 있음

## 6. 검증 결과

- `python -m pytest tests/unit/voc -q`: **7 passed, 0 skipped**
- `python -m pytest tests -q`: **89개 중 86 passed, 3 failed, 0 skipped**
- 실패한 3건은 기존 RAG 통합 테스트의 OpenAI embedding 호출이며, 실행 환경의 `api.openai.com` 네트워크 차단(`WinError 10013`)으로 실패했다. S-VOC 테스트는 모두 통과했다.

## 7. 후속

전체 테스트를 완전 통과시키려면 RAG 통합 테스트 실행 환경에서 OpenAI embedding 네트워크 또는 fixture가 필요하다. S-VOC 구현에는 분류 기본값/폴백, z-score, clustering, topic modeling을 추가하지 않았다.
