# S-RAG 코퍼스 25건 v2 리포트

## 1. 작업 목표

실행계획서 v5 P3의 정책/FAQ RAG 코퍼스 산출물로 Nimbus 가상 정책 문서 25건을 작성했다. v1의 거부 사유였던 공통 섹션 제목, 문서 내 반복 문장, 숫자 없는 근거, 시나리오 근거 부족을 v2 작성 기준에 반영했다. 실제 회사·제품·약관 및 PII는 사용하지 않았다.

## 2. 만든 파일 목록

`knowledge/documents/` 아래 다음 25개 파일을 만들었다.

- `01_billing_monthly-cycle.md`, `02_billing_annual-renewal.md`, `03_billing_retry-failure.md`, `04_billing_tax-invoice.md`, `05_billing_invoice-delivery.md`
- `06_refund_refund-after-cancel.md`, `07_refund_refund-window.md`, `08_refund_partial-proration.md`, `09_refund_processing-exception.md`
- `10_subscription_cancel.md`, `11_subscription_plan-change.md`, `12_subscription_auto-renew.md`, `13_subscription_trial.md`
- `14_entitlement_plan-matrix.md`, `15_entitlement_sync-delay.md`, `16_entitlement_plan-transition.md`, `17_entitlement_limit-overage.md`, `18_entitlement_diagnosis.md`
- `19_incident_severity.md`, `20_incident_entitlement-outage.md`, `21_incident_compensation.md`
- `22_technical_login-diagnosis.md`, `23_technical_api-errors.md`
- `24_support_intake-escalation.md`, `25_support_approval-actions.md`

`knowledge/manifest.json`에는 25개 document_id와 실측 section_count 12를 기록했다.

## 3. 검증

실행 명령: `python -m scripts.check_corpus`

실제 출력 원문:

```text
==============================================================================
RAG 코퍼스 인수 검사
==============================================================================
  · 문서 25 / 총 섹션 300
  · scope 배분 일치: {'billing': 5, 'entitlement': 5, 'incident': 3, 'refund': 4, 'subscription': 4, 'support': 2, 'technical': 2}
  · 문서 내 최대 문장 반복: 1 (상한 1)
  · 최다 공유 섹션 제목: '31일이 없는 달의 날짜 보정' 1/25문서
  · 구체 수치 포함: 문서 100% / 섹션 100%
------------------------------------------------------------------------------
  전 항목 통과 — 인수 가능
```

추가 실측: 300개 섹션의 본문 길이는 200~343자이며, 200자 미만 0개·600자 초과 0개였다.

## 4. 미리 정한 수치 상수

- 문서/섹션: 25건, 문서당 12개, 총 300개
- 환불: 결제일로부터 14일 이내 접수, 승인 후 5영업일 이내 안내, 은행 지연 최대 3영업일
- 권한: 정상 동기화 60초, 지연 상한 15분
- 플랜 한도: Free 멤버 3명·저장공간 2GB, Pro 멤버 25명·저장공간 100GB, Business 멤버 200명·저장공간 1TB
- 결제/운영: 청구 큐 10분, 제공자 timeout 20초, unknown 확인 30분, 멱등 키 24시간, 감사 보존 90일
- 구독: 체험판 7일, 연간 계약 12개월, 자동갱신 알림 30일·3일 전
- 장애/지원: P1 15분, P2 1시간, P3 4시간 대응 기준

## 5. 미해결 이슈

코퍼스 인수 검사 기준은 통과했다. 실제 pgvector 적재·임베딩·retrieval top-k 품질은 이번 범위가 원문 작성까지이므로 수행하지 않았다. 운영 적용 전에는 ingest count와 retrieval integration test에서 문서별 metadata filter 및 `tenant_id=demo`를 확인해야 한다.
