## 3. 원인 — re-export 시 순환

§2 는 "기존 경로에 re-export 를 남긴다" 고 지시했다:

```python
# app/core/contracts.py
from app.core.case_runtime.contracts import *
```

이 방식은 **새 모듈이 옛 경로를 다시 import 하면 순환**이 된다.
`app/domain/events.py` 가 shim 이 되고, 새 위치의 모듈이 `app.domain.events` 를 참조하면
부분 초기화 상태에서 이름을 찾지 못한다.

★**내 계약의 결함이다.** re-export 를 지시하면서 **방향(새 → 옛 참조 금지)을 명시하지 않았다.**
다음 지시에는 이렇게 넣어야 한다:

> re-export shim 은 **옛 경로 → 새 경로 단방향**이다.
> 새 위치의 코드가 옛 경로를 import 하면 순환이 된다. 새 코드는 **새 경로만** 쓴다.
