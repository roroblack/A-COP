# S-JSONFIX 리포트

## 선택한 방식

`response_format={"type":"json_object"}`를 유지하고, OpenAI에 전달하는 Team 프롬프트에 `json` 출력 지시와 TeamResult 필드 스키마를 명시했다. 따라서 응답 파싱과 기존 malformed JSON repair 정책은 변경하지 않았다.

## 프롬프트 버전

기존 `.v1.md` 파일은 보존하고, JSON 출력 지시를 포함한 `.v2.md` 파일을 billing 3개와 technical 3개에 추가했다. 프롬프트 등록 로더가 버전과 SHA-256을 파일별로 등록하므로 기존 버전의 내용을 덮어쓰지 않는다.

## 검증

요청된 `python -m pytest tests -q`를 실행한 결과는 `120 passed, 3 failed, 1 deselected`였다. 실패한 3건은 변경 영역과 무관한 RAG integration 테스트의 OpenAI embeddings 외부 네트워크 호출 차단(`WinError 10013`)이다. 해당 테스트를 제외한 검증은 `119 passed, 1 deselected`였다. 외부 네트워크가 차단된 환경이므로 OpenAI 실호출 검증은 수행하지 않았으며, mock/fake 실행을 실호출 성공으로 보고하지 않는다.
