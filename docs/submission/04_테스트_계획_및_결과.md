## 결함을 발견하고 고친 기록

| 결함 | 발견 | 조치와 현재 기록 |
|---|---|---|
| RAG 검색 100% 실패 | vector 파라미터가 tuple/list로 전달되어 `vector <=> double precision[]` 오류 | SQL `::vector` 캐스트를 추가했다. 이후 78/78 passed, skipped 0과 두 질의의 top-8을 확인했다. |
| API 전 요청 500 | 인증 계층의 환경변수 접근 오류 | 설정 경로와 예외 handler를 고쳐 401/403/404/409/422를 실제 status로 반환하도록 했다. |
| PII 평문 저장 | DoD gap test가 원문 API key·payment 식별자를 DB/audit payload에서 검출 | `2026-08-13_S-FIX3_리포트`는 masking·DB/audit 검증 통과를 기록한다. 이전 결함 리포트의 미수정 판정은 수정 전 상태로 명시 보존한다. |
