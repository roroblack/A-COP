# 11 — 외부 콘솔이 읽는 파일·DB 형식 계약 v1

★2026-08-17: 이 문서가 처음 쓰였을 때는 "개발 콘솔"이 이 저장소 안(`app/console`)에
있었다. 그 뒤 결정이 바뀌었다 — **별도 프로그램 `final_project_ui`가 read-only 로
붙는다.** `app/console` 패키지는 지웠다. 이 문서는 **그 외부 프로그램이 기대하는
형식**으로 다시 읽는다. 문서 원안(파일 형식 표)은 여전히 유효하다 — 소비자만 바뀌었다.

이 문서는 외부 콘솔이 실제로 읽는 입력 필드만 고정한다. 스키마 이름의
`v1`은 필드 삭제·이름 변경을 호환 변경으로 취급하지 않는다는 뜻이다.

| 입력 | 콘솔이 읽는 필드 |
|---|---|
| `config/project.yaml` | `modules.<module>.enabled`; `ports.team_executor`, `ports.message_broker`, `ports.graph_store`; `teams[].team_id`, `teams[].active`, `teams[].implementation_ref`; 계산된 `revision` |
| `docs/evidence/DoD-*.md` | 파일명 `DoD-<id>_...md`; 제목 stem; `판정:` 값; fenced code block 존재 여부; fenced block의 `실제 출력`/`실측 결과`/`actual output` 표식 |
| `eval/reports/*.jsonl` | 첫 레코드의 `config.provider`, `config.arm`, `config.dataset`, `config.ablations`, `config.prompt_snapshot`, `config.holdout`; 레코드의 `arm`, `provider`, `cost_usd`, `input_tokens`, `output_tokens`, `latency_ms`, `run_id` |
| DB `agent_runs` | `run_id`, `case_id`, `graph_revision`, `status`, `started_at`, `finished_at` |
| DB `team_tasks` | `run_id`, `task_id`, `team_id`, `contract_version`, `status`, `created_at` |
| DB `llm_calls` | `run_id`, `call_id`, `prompt_id`, `provider`, `model`, `input_tokens`, `output_tokens`, `latency_ms`, `cost_microusd`, `created_at` |
| DB `case_events` | `case_id`, `event_id`, `aggregate_version`, `event_type`, `actor_type`, `created_at` |
| **`GET /introspection`** (인스턴스가 떠 있을 때) | `contract_version`, `config_revision`, `modules`, `ports`, `team_manifests[]`, `teams[]`, `port_implementations`, `guardrails`, `llm.{provider,model,api_key}` — `docs/handoff/12_introspection_계약.md` |

DB 계약은 migration 파일이 아니라 실행 중인 PostgreSQL의
`information_schema.columns`를 검사한다. 파일·JSONL 계약은 저장소의 실제
파일을 읽고, 각 계약 테스트(`tests/contracts/test_console_read_contracts.py`)는
필드를 지우거나 이름을 바꾼 negative fixture 로 **실제로 깨지는지** 확인한다.

## ★더 이상 유효하지 않은 것

- `app.console` 패키지, 두 wheel 빌드(`FINAL_PROJECT_INCLUDE_CONSOLE`) —
  전부 지웠다. `pip install .` 하나면 된다
- `/ui/admin` 이 `build_registry()` 를 직접 부르던 경로 — 지웠다.
  대신 `GET /introspection` 이 **HTTP 로** 같은 정보를 낸다(scope `ops:introspect`)
