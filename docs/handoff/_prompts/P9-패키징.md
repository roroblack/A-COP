버전은 위 목록을 그대로 옮겨 적기만 하면 된다.

### 3-2. `README.md`

다음을 담는다 — 코드에서 실제로 확인 가능한 내용만 적어라(지어내지 마라):

- 이게 무엇인가: 여러 프로젝트를 가리키는 **읽기 전용** 개발 콘솔. 대상의 코드를
  가져오지 않는다(`config/project.yaml`·`docs/evidence/`·`eval/reports/`·
  introspection HTTP·DB를 **데이터로만** 읽는다).
- 실행 방법: `python -m console.web` (`PORT` 환경변수로 포트 지정, 기본 8060)
- 프로젝트 연결 방법:
  - `/` 에서 `root` 쿼리로 부모 폴더를 주면 형제 프로젝트를 자동 탐지한다
    (판별 기준: `config/project.yaml` 존재 여부) — `console/discovery.py` 참고
  - `/project?path=<프로젝트 경로>` 로 특정 프로젝트를 직접 연다
- 라이브 연결 환경변수(전부 선택, 없으면 "연결 안 함"으로 정직하게 표시):
  - `CONSOLE_DATABASE_URL` — 대상 PostgreSQL (`postgresql://` 만 지원)
  - `CONSOLE_INTROSPECTION_URL` — 대상 `GET /introspection`
  - `CONSOLE_INTROSPECTION_TOKEN` — 위 엔드포인트가 scope 인증을 요구하면 필요
    (없이 붙이면 `인증 실패`로 뜬다 — `docs/reports/2026-08-17_P8_실연결_검증.md` 참고)
  - `CONSOLE_CONTRACT_VERSIONS` — 콤마 구분, 이 콘솔이 아는 introspection 계약 버전
- 테스트: `python -m pytest tests -q`
- ★비밀값(토큰·DB 비밀번호)은 절대 파일에 저장하지 않는다 — 매번 환경변수로 준다는
  원칙을 한 줄 명시해라(`console/profiles.py` 상단 docstring이 근거다)
