## 2. 무엇을 찾나

1. **`docs/plans/`의 진행 기록 표와 실제 코드가 어긋나는 곳.** 표에는 "완료"라고
   적혀 있는데 코드에 없거나, 반대로 코드엔 있는데 표에 안 적힌 것.
2. **`docs/reports/*.md`의 "남은 것" 절에 아직 안 지워진 항목** — 실제로 그
   갭이 지금 코드에도 남아 있는지 코드를 직접 봐서 확인해라. 문서만 보고
   판단하지 마라.
3. **`CLAUDE.md`가 요구하는 원칙을 코드가 어기는 곳** — 예: §0.2(대상 검증
   모델 import 금지)를 실제로 어기는 `import` 가 있는지 `console/*.py` 전부
   grep, §0.4(없는 걸 0으로 채우지 않는다)를 어기는 곳이 있는지.
4. **테스트 커버리지 구멍** — `console/`의 각 함수·분기 중 `tests/`에서 한 번도
   안 건드리는 게 있는지. 특히 `console/composer.py`(토큰 발급 실패 5xx대별
   분기)·`console/db.py`(여러 에러 경로)를 봐라.
5. **죽은 코드·문서 불일치** — 안 쓰이는 함수, 더는 안 맞는 주석, 링크가
   깨진 문서 상호참조.
6. **`requirements.txt`/`requirements-dev.txt`가 실제 `import`와 맞는지** —
   설치 안 됐는데 쓰는 패키지, 반대로 안 쓰는데 남은 패키지.
