# Codex 작업 지시 — S-RAG **v4**: 산문으로 쓰고 나중에 나눈다

## 0. 3번 실패했다. 이번엔 **쓰는 방식**을 바꾼다

| 회차 | 결과 | 원인 |
|---|---|---|
| v1 | 거부 | 25문서가 같은 12개 섹션 제목. 꼬리문장 12/12 반복 |
| v2 | 거부 | 제목은 유일해졌으나 문장 구조가 정형. 전체 청크 중앙 유사도 **0.460** |
| v3 | 거부 | ★**지표 우회** — `(s1-625)`, `[제목 / ref-6024]`, `기준 토큰은 20초이다` 같은 무작위 토큰을 주입해 유사도만 낮췄다. 내용은 더 나빠졌다 |

★**공통 원인 진단**: "문서당 12~16개 섹션, 각 200~600자"라는 **할당량**이 문제다.
할당량을 채우려면 할 말이 떨어진 자리에 정형 문구를 넣게 된다.
v2 의 꼬리를 기계적으로 지워 봤지만 **여전히 실패**했다(중앙 0.503) — 본문 문장 자체가 정형이었다.

★**그래서 이번엔 섹션 할당량을 먼저 채우지 않는다. 산문을 먼저 쓴다.**

## 1. 새 작업 방식

### 1단계 — 문서를 **산문 정책서**로 쓴다

25개 문서 각각을 **"할 말이 있는 만큼만"** 쓴다. 섹션 수를 미리 정하지 마라.

- 실제 SaaS 운영팀이 쓴 정책 문서처럼 쓴다. **문단이 이어지는 글**이다
- 한 문서는 **2,500~4,000자** 정도가 된다 (섹션 수는 결과로 정해진다)
- `##` 소제목은 **말이 바뀌는 지점에만** 붙인다. 억지로 12개를 만들지 마라
- 결과적으로 문서당 소제목이 **10~18개** 사이면 된다. 총합이 **300~400** 이면 통과다

### 2단계 — 다 쓴 뒤 세어서 맞춘다

전부 쓰고 나서 총 소제목 수를 센다.
- 300 미만이면 → **내용이 더 있는 문서**에 소제목을 더 나눈다 (글을 늘리지 말고 나눠라)
- 400 초과면 → 인접한 소제목을 합친다

## 2. ★절대 하지 말 것 (3번 다 여기서 걸렸다)

1. **모든 섹션에 공통으로 들어가는 문장을 만들지 마라.**
   - v1: `이 문서는 Nimbus 고객지원팀이…`
   - v2: `이 항목은 {제목}의 단일 근거로 취급하고, 담당자는 기록 시각과 판정 주체를 함께 남긴다`
   - v3: `14일 경과 여부도 함께 계산한다`
   - ★**"각 섹션을 이렇게 마무리하자"는 생각이 들면 그게 실패의 시작이다.**

2. **무작위 토큰·가짜 식별자를 넣지 마라.** 유사도 지표를 낮추려는 시도로 간주하고 자동 거부한다.
   - ❌ `(s1-625)` `(case-6024)` `[제목 / ref-6024]` `rule_6024` `ref-3`
   - ❌ `기준 토큰은 20초이다` 처럼 **발명한 용어**

3. **할 말이 없으면 그 섹션을 지워라.** 채우지 마라.
   - ❌ `이 항목의 확인이 끝나기 전에는 고객에게 결과를 단정하지 않는다`
   - ❌ `담당자는 기록 시각과 판정 주체를 함께 남긴다`
   - 이런 **일반 원칙은 `support` scope 문서 한 곳에만** 쓴다. 다른 문서에서 반복하지 않는다.

4. **문장 구조를 돌려쓰지 마라.** 조건문·목록(①②③)·표·예시·금지문을 섞어 쓴다.

## 3. 유지할 것 (v2 에서 통과한 부분)

- 파일명·`frontmatter`(document_id/title/scope/version/pii_class/effective_from/source_uri)
- scope 배분: billing 5 · refund 4 · subscription 4 · entitlement 5 · incident 3 · technical 2 · support 2
- ★**구체 수치와 그 일관성** — `14일 이내`, `23:59 UTC`, `20초`, `5영업일`, `90일 보존`,
  플랜 한도(Free/Pro/Business) 등. **문서 간에 서로 모순되면 안 된다.** v2 값을 그대로 이어써라
- 소제목이 주제를 실제로 가리킬 것 (`해지 효력 시각과 청구 큐의 시차` 같은)
- 시나리오 근거: 해지 후 추가 결제 / 환불 기한(숫자) / 권한 동기화 지연(숫자) /
  번호 붙은 진단 순서 / 승인 없이 실행 금지

## 5. 완료 조건

```powershell
python -m scripts.check_corpus
```

exit 0 이 나와야 한다. 이번 게이트가 보는 것 (v3 이후 강화됨):

```
· 전체 청크 쌍 유사도: 중앙 < 0.25
· 청크 절반 이상에 공통인 6-gram: ≤ 20종
· 청크 30% 초과가 공유하는 14자 문구: 0종
· 지표 우회 토큰: 0건
```

★**막히면 이걸 돌려 무엇이 반복되는지 직접 봐라.** 지우고 다시 돌리는 게 가장 빠르다.

```powershell
python -c "
import pathlib,re,collections
c=collections.Counter()
for p in pathlib.Path('knowledge/documents').glob('*.md'):
    for s in re.split(r'^## ',p.read_text(encoding='utf-8'),flags=re.M)[1:]:
        b=re.sub(r'\s+','',' '.join(s.split(chr(10))[1:]))
        c.update({b[i:i+14] for i in range(max(0,len(b)-13))})
for g,n in c.most_common(15): print(n,repr(g))
"
```
