## 3. 만들 것 — 대상 프로필

지금은 **경로만** 안다. 실제로 붙으려면 더 필요하다.

### 3-1. `console/profiles.py` — 대상 하나를 어떻게 부를지

프로필에 담길 것:

| 필드 | 왜 |
|---|---|
| `name` · `path` | 어느 프로젝트인가 |
| `database_url` (선택) | 실행 이력을 읽으려면 필요 |
| `introspection_url` (선택) | 대상이 떠 있을 때 조립 실측 |
| `contract_versions` | ★이 콘솔이 이해하는 계약 버전 범위 |

★**자격증명을 프로필 파일에 적지 않는다.** 환경변수 이름을 가리키게 하고,
값은 환경에서 읽는다. 파일에 비밀번호가 들어가면 그 파일이 유출 지점이 된다.

★프로필이 없어도 **화면은 떠야 한다.** 경로만으로 볼 수 있는 것(선언·판정·평가)은
그대로 보이고, DB·HTTP 가 필요한 칸만 "연결 안 함" 으로 남는다.

### 3-2. `console/live.py` — introspection HTTP 읽기

대상이 떠 있으면 `GET {introspection_url}` 로 조립 실측을 가져온다.

★**`contract_version` 을 먼저 본다.** 모르는 버전이면 **모른다고 말한다** —
추측해서 그리면 화면이 거짓말을 한다.

★연결 실패·타임아웃·404 를 **각각 다르게** 보고한다.
"연결 안 함"·"대상이 응답하지 않음"·"그 경로가 없음" 은 서로 다른 사건이다.
하나로 뭉치면 사용자가 무엇을 고쳐야 할지 모른다.

### 3-3. `console/db.py` — 실행 이력 읽기 (read-only)

`database_url` 이 있을 때만. 읽을 것:

```
agent_runs   run_id · graph_revision · status · started_at · finished_at
```

★**SELECT 만 한다.** 이 프로그램은 대상을 쓰지 않는다.
★드라이버가 없거나 연결이 안 되면 **예외로 죽지 말고** "연결 안 함" 으로 보고한다.

### 3-4. 화면에 반영

프로젝트 상세에 "연결" 칸을 만든다. 각 출처마다 상태를 적는다:


| 규칙 | 이유 |
|---|---|
| **대상의 코드를 가져오지 마라** | 이건 UI 만이다. 검증 모델·계약 모델·theme 복사 금지 |
