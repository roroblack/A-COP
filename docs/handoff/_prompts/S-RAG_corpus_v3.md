# Codex 작업 지시 — S-RAG **v3**: 문장 템플릿 제거

## 0. 상황

v2 산출물이 `knowledge/documents/` 에 있다. **버리지 마라. 고쳐 쓴다.**

**v2 에서 잘한 것 (그대로 유지):**
- 섹션 제목이 문서마다 유일하고 주제를 실제로 가리킨다
- 구체 수치가 진짜다 (`14일 이내`, `23:59 UTC`, `20초`, `5영업일`, `90일`) — 문서 간 일관
- 각 섹션 **첫 1~2문장**은 인용 가능한 진짜 근거다

**거부 사유 (실측):**

```
전체 청크 쌍 유사도 중앙값 0.460  (기준 < 0.25)
청크 절반 이상이 공유하는 6-gram 127종  (기준 ≤ 20)
```

원인은 **문장 단위 템플릿**이다. 300개 섹션 **전부**가 이 두 문장으로 끝난다:

```
이 항목은 {섹션제목}의 단일 근거로 취급하고, 담당자는 기록 시각과 판정 주체를 함께 남긴다.
{섹션제목}의 확인이 끝나기 전에는 고객에게 {N}번째 결과를 단정하지 않는다.
```

211자 청크 중 **93자(44%)**가 이것이다. 제목을 끼워 넣어 "같은 문장 반복" 검사를 빠져나갔다.

★그리고 **이 꼬리만 지우면 되는 게 아니다.** 잘라내고 재보니 중앙 유사도가 **0.503 으로 오른다.**
본문 문장 구조 자체가 정형이다 — `~는 ~에 ~한다`, `tenant_id demo를 함께 기록하며`,
`확정하지 않고 ~로 넘긴다` 가 거의 모든 청크에 반복된다.

상세: `docs/reports/debugs/2026-08-12_1720_RAG코퍼스_v2_문장템플릿과_게이트_구멍.md`

## 1. 이번에 할 일

`knowledge/documents/*.md` 25개를 **본문만** 다시 쓴다.
frontmatter·파일명·섹션 제목·수치는 **그대로 둔다**(그건 통과했다).

각 섹션 본문을 이렇게 바꾼다:

1. ★**꼬리 두 문장을 전부 삭제**한다 (`이 항목은 …`, `… 확인이 끝나기 전에는 …`)
2. ★**`이 근거는 N회 점검 기록에 남긴다`** 같은 무의미한 문장도 삭제한다
3. 남은 1~2문장(진짜 내용)에 **그 섹션에만 해당하는 사실 2~3개를 더 쓴다** — 200~600자로 채운다

### 무엇을 더 쓰나

그 섹션 제목이 다루는 주제의 **구체적인 사실**이다. 예시 (`## 결제 제공자 응답 지연`):

> 환불 제공자가 20초 안에 응답하지 않으면 성공으로 추정하지 않고 unknown 으로 남긴다.
> unknown 은 자동 재실행하지 않으며 30분 뒤 제공자 상태와 원장 금액을 사람이 확인한다.
> **제공자 조회 API 는 refund_id 로만 조회하며 invoice 번호로는 조회되지 않는다.
> 조회 결과가 `pending` 이면 최대 3회까지 1시간 간격으로 재조회하고, 3회 후에도 pending 이면
> 지원 큐 P2 로 올린다. 제공자가 `failed` 를 반환한 경우에만 재환불 제안을 새로 만들 수 있고,
> 이때도 원 요청의 refund_id 를 참조로 남긴다.**

굵게 표시한 부분이 추가해야 할 종류다 — **그 주제에서만 나올 수 있는 구체적 절차·조건·수치**.

## 2. ★문장을 다양하게 써라

같은 문장 구조를 반복하지 마라. 아래를 섞어 쓴다.

- 조건문: `~인 경우에는 ~한다` / `~가 아니면 ~하지 않는다`
- 목록형: `확인 항목은 ①… ②… ③… 이다`
- 수치 대조: `Free 는 5명, Pro 는 25명, Business 는 200명이다`
- 예시: `예를 들어 3월 31일에 시작한 월간 구독은 4월 30일이 갱신일이다`
- 금지 규정: `~는 하지 않는다`
- 표를 써도 된다 (markdown 표)

★**모든 섹션에 공통으로 들어가는 문구를 만들지 마라.** 그게 v1·v2 가 실패한 이유다.
"tenant_id demo", "담당자는 기록한다", "확정하지 않는다" 같은 말을 **매 섹션에 넣지 마라.**
그런 원칙은 `support` scope 문서 **한 곳**에만 쓰고, 다른 문서에서는 반복하지 않는다.

## 4. 완료 조건

```powershell
python -m scripts.check_corpus
```

**exit 0 이 나올 때까지 고쳐라.** 특히 이 두 줄을 보라:

```
· 전체 청크 쌍 유사도: 평균 ? / 중앙 ?      → 중앙 < 0.25 여야 한다
· 청크 절반 이상에 공통인 6-gram 종류: ?     → ≤ 20 이어야 한다
```

한 번에 안 되면 **가장 흔한 공통 문구를 찾아 지우고 다시 돌려라.** 아래로 확인할 수 있다:

```powershell
python -c "
import pathlib,re,collections
c=collections.Counter()
for p in pathlib.Path('knowledge/documents').glob('*.md'):
    for s in re.split(r'^## ',p.read_text(encoding='utf-8'),flags=re.M)[1:]:
        b=re.sub(r'\s+','',' '.join(s.split(chr(10))[1:]))
        c.update({b[i:i+12] for i in range(max(0,len(b)-11))})
for g,n in c.most_common(20): print(n,repr(g))
"
```
