## 0. 이 문서가 막으려는 것

두 작업 스트림이 같은 파일을 쓰면 **마지막에 끝난 쪽이 조용히 이긴다.**
테스트도 통과하고 diff 도 깨끗한데 다른 스트림의 기능만 사라진다.
그래서 **인원이 아니라 디렉터리로** 경계를 긋는다.

## 2. 넘기기 전에 순서대로 한다 (Claude 측 책임)

1. **계약을 먼저 확정한다.** `docs/handoff/` 에 인터페이스가 없으면 Codex 를 돌리지 않는다.
2. **프롬프트는 계약을 인용한다.** 내용을 복사하지 않는다 — 복사하면 두 벌이 어긋난다.
3. **한 번에 한 스트림.** 같은 디렉터리를 두 세션이 잡지 않게 한다.

```powershell
Get-Content docs\handoff\_prompts\<스트림>.md | codex exec -s workspace-write -C <저장소루트> -
```

## 2-1. ★Codex 샌드박스는 외부 네트워크를 쓸 수 없다 (2026-08-12 실측)

`codex exec -s workspace-write` 로 띄운 프로세스에서 **외부 HTTP 호출이 전부 막힌다.**

| 관측 | 결과 |
|---|---|
| Claude 셸에서 OpenAI 호출 | **OK** — latency 2,940ms, 정상 응답 |
| Codex 실행 중 OpenAI 호출 | `APIConnectionError: Connection error.` **× 540건 전부** |
| Codex 실행 중 tiktoken BPE 다운로드 | `WinError 10013` (접근 차단) |

★**따라서 LLM·임베딩·외부 API 가 필요한 작업은 Codex 에 넘기지 않는다.**

| 작업 | 누가 |
|---|---|
| 코드·테스트·문서 생성, 로컬 DB 작업 | **Codex** |
| ★**LLM 호출이 실제로 일어나야 하는 실행** (평가 전량 실행, 임베딩 적재, 실 분류) | **Claude 가 직접 실행** |

Codex 에는 **코드까지만** 맡기고, 실행은 Claude 가 한다.
Codex 프롬프트에 "실제로 돌려라"고 써도 **돌릴 수 없다** — 지시의 문제가 아니라 환경의 문제다.

★이 사실을 모르고 평가 전량 실행을 두 번 넘겼다.
1차는 mock 으로 돌아왔고(정직하게 `"provider": "mock"` 이라고 표기했다),
2차는 `provider=openai` 로 540건을 돌렸으나 **전 건 `APIConnectionError`** 였다.
두 번 다 Codex 는 결과를 조작하지 않았다 — `success 0/180` 을 그대로 기록했다.

## 3. 받은 뒤 반드시 검사하는 4종 (Claude 측 책임)

산출물을 **그대로 커밋하지 않는다.** 다음 4가지는 실제로 나왔던 실패다.

| # | 검사 | 어떻게 |
|---|---|---|
| 1 | **계약 위반** | 필드 누락·타입 불일치·`extra='forbid'` 우회. `pytest tests/contract -q` |
| 2 | **범위 임의 삭감** | v5 §3 의 `In` 항목이 빠졌는지 대조. (실제 사례: MCP·pgvector 를 통째로 삭감) |
| 3 | **잘못된 근거** | 주석/문서가 틀린 이유를 대는지. (실제 사례: 12,000 토큰 예산을 "context window 초과" 로 설명 — 실제 근거는 비용·lost-in-the-middle·재현성) |
| 4 | **수치 불일치 · 문법 오류** | 문서 간 숫자 대조, Mermaid/JSON 파싱 |

★**검수 결과를 리포트에 남긴다.** 조용히 고치면 다음에 또 나온다.

## 4. Codex 스트림이 공통으로 지키는 것

- **하드코딩 금지** — 가드레일 수치는 `config/guardrails.yaml` 에서 읽는다(`06`).
- **폴백 금지** — 키·파일·DB 부재는 예외를 던진다. "실패하면 빈 값 반환" 금지.
  단 `ContextPack.degraded=true` + `omissions` 를 남기는 축소는 폴백이 아니다.
- **YAGNI** — v5 `Out`/`Phase 2` 항목을 구현하지 않는다. Port 인터페이스까지만 허용.
- **조용한 스킵 금지** — `except: continue` 는 실패 건수를 세어 보고한다.
- **테스트에 실측 로그를 남긴다** — 통과 주장에는 재현 명령과 출력이 따라온다.
- 자기 스트림 종료 시 `docs/reports/` 리포트 + `docs/history/` 추가.

## 5. ★이 환경에서 Codex 에 넘길 수 있는 일 / 없는 일 (2026-08-17 실측)

Codex 가 **파일을 PowerShell 로 읽으면 한글 주석이 mojibake 로 들어온다.**

```
"?꾩닔 ?섍꼍蹂?섍? ?녾굅???섎せ?먮떎. .env.example 瑜?.env 濡?蹂듭궗?댁꽌..."
```

이 저장소는 주석이 거의 전부 한글이라, **읽을 파일이 많을수록 컨텍스트가 깨진 글자로 찬다.**

| 결과 | 발주 | 읽어야 할 파일 |
|---|---|---|
| 성공 | IA 검토 · 콘솔 P4~P6 · Composer 배선 | 적음 (지시서 + 한두 파일) |
| ★**두 번 연속 무산** | introspection + 코드 이동 + 패키징 | 많음 (교차 작업) |

### 규칙

1. ★**읽을 파일을 지시서에 명시한다.** "알아서 파악하라" 는 이 환경에서 실패한다
2. ★**넓게 읽어야 하는 교차 작업은 넘기지 않는다** — 리팩터링·패키징·구조 이동
3. **로그를 저장소 안에 쓰지 않는다.** 1차 실패는 Codex 가 `docs/reports/` 에 쌓인
   **자기 로그를 읽는 순환**이었다. 로그는 `%TEMP%` 로 뺀다
4. **빌드 검사용 임시 폴더도 저장소 밖에** 만들게 한다
   (실제로 `.wheelhouse-*` 6개 + `build/` 가 저장소 루트에 쌓였다)

### 넘기기 좋은 일

- **검토·반박** — 우리 안을 주고 틀린 곳을 짚게 한다. 실제로 IA 초안이 이 방식으로 뒤집혔다
- **화면 하나 추가** — 읽을 파일이 명확한 것
- **테스트 추가** — 대상 모듈이 지정된 것
