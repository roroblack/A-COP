# 배포 계약 v1

`final_project_sample`은 로컬 프로세스, 로컬 컨테이너, 향후 AWS 중 어느 배포
타깃에서도 애플리케이션 코드에 배포 방식의 가정을 강요하지 않는다.

## 계약

- 설정은 환경변수로만 주입한다. 비밀 값은 이미지에 굽지 않는다.
- `app/**`는 특정 클라우드 SDK를 직접 import하지 않는다.
- 로컬 conda 환경 `pgv`와 Docker Compose는 병행 선택지다. Compose가 기존 conda
  안내를 대체하지 않는다.

## 현재 컨테이너 전제

- 애플리케이션은 `python:3.12-slim` 이미지에서 실행된다.
- ASGI 진입점은 `app.presentation.api.app:app`이며 컨테이너 내부 포트는 `8000`이다.
- 호스트 앱 포트는 `ACOP_APP_PORT`로, 호스트 DB 포트는 `ACOP_DB_PORT`로 정한다.
  미지정 시 각각 `8000`, `5433`을 사용한다.
- Compose의 DB는 `pgvector/pgvector:pg16`이며 `vector`와 `pgcrypto` 확장을
  시작 시 활성화한다.
- 애플리케이션 런타임 환경변수는 `.env.example`의 전체 목록을 따른다:
  `ACOP_DATABASE_URL`, `ACOP_LLM_PROVIDER`, `ACOP_OPENAI_API_KEY`,
  `ACOP_LLM_MODEL`, `ACOP_EMBEDDING_MODEL`, `ACOP_LLM_TEMPERATURE`,
  `ACOP_LLM_SEED`, `ACOP_ENV`, `ACOP_TENANT_ID`, `ACOP_SECRET_KEY`,
  `ACOP_GUARDRAILS_PATH`.
