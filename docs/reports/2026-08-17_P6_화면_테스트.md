## 겪은 것

- `tests/test_web.py` 의 fixture `project.yaml` 에 `team_executor: 8123` 처럼
  실제 계약과 안 맞는 값이 있다. **이 테스트는 화면 렌더링만 보므로 문제 없다** —
  `console/readers.py` 는 값을 검증하지 않고 그대로 보여주기 때문이다.
  다만 다른 목적의 테스트에서 이 fixture 를 재사용하면 오해할 수 있어 공유하지 않는다.

## 한계

- 화면 테스트는 **fixture 프로젝트**로만 확인했다. 실제 대상(`final_project_sample` 등)의
  화면 렌더링은 이전 세션에서 수동으로 확인한 것이 마지막이다
- DB·introspection 이 **연결된 상태**의 화면은 fixture 로 재현하지 않았다
  (진짜 서버를 띄워야 한다) — 이전 세션에서 실제 PostgreSQL 로 확인한 바 있다
