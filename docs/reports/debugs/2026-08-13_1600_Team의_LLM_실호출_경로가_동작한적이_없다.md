# 결함 — Team 의 LLM 실호출 경로가 한 번도 동작한 적이 없다

- 발견: 2026-08-13 16:00, Claude 검수
- 상태: **미수정.** DoD 15·16 판정 보류
- 위험도: **높음** — Proposed 군을 측정할 수 없다

## 1. 실측

Proposed 러너가 실제 Team 을 호출하도록 고친 뒤 4건 실행:

```
error: APIConnectionError: Connection error.
degraded: True  success: False  score: 0
cost: 0.0  in_tok: 0  lat: 0
prediction: null
```

**같은 셸에서 OpenAI 는 정상이다:**

```
python scratchpad/openai_probe.py
key len: 164  model: gpt-4o-mini
OK  latency=1443ms  usage=CompletionUsage(prompt_tokens=16, completion_tokens=2)
content: 반환
```

★즉 **환경이 아니라 코드 경로의 문제**다.

## 2. 무엇을 뜻하나

- baseline A·B 러너의 `_call_openai()` 는 **동작한다** (540런에서 A 0.045 USD, B 0.118 USD 실소모)
- Proposed 만 실패한다 → **Team 이 쓰는 LLM 어댑터 경로**가 다르고, 그 경로가 깨져 있다
- Team 은 지금까지 **fake LLM 주입으로만** 테스트됐다
  (`tests/unit/teams/`, `tests/integration/controller/` 전부 fake)

★**"테스트가 통과한다"와 "실제로 LLM 을 부를 수 있다"는 다른 사건이다.**
Team 계약·격리·상태 전이는 전부 검증됐지만, **실호출 경로는 한 번도 지나간 적이 없다.**

## 3. 이 프로젝트에서 다섯 번째다

| 회차 | 증상 | 실제 |
|---|---|---|
| 1 | route 5개 등록·테스트 초록 | 인증 요청 전부 500 |
| 2 | `ingest.py` 완성 | 적재를 안 돌림 (0건) |
| 3 | 평가 540행 생성 | provider=mock / 전 건 연결실패 |
| 4 | Proposed 180행 생성 | 실제 시스템 미실행 |
| 5 | **Team 테스트 전부 통과** | **LLM 실호출 경로 미동작** |

공통 원인은 하나다 — **주입 가능하게 만든 의존성을 fake 로만 검증했다.**
주입 가능성은 테스트를 결정적으로 만들지만, **실제 어댑터를 한 번도 안 지나가게** 만든다.

## 4. 고쳐야 할 것

1. `app/infrastructure/llm/` 의 어댑터가 **`app.core.settings.get_settings()`** 로
   키·모델을 읽는지 확인한다 (`os.getenv` 면 `.env` 값이 안 보인다 —
   S-API 가 이걸로 전면 장애를 냈다: `docs/reports/debugs/2026-08-12_1830_*`)
2. baseline 러너의 `_call_openai()` 와 **같은 방식**으로 클라이언트를 만든다
   (그쪽은 동작이 확인됐다: `OpenAI(api_key=settings.openai_api_key, timeout=...)`)
3. ★**실호출 스모크 테스트를 하나 둔다.** fake 가 아니라 실제로 한 번 부르는 테스트를
   별도 마크(`@pytest.mark.live`)로 두고, 기본 실행에서는 빠지되 **수동으로 돌릴 수 있게** 한다

## 5. 현재 유효한 것

- **baseline A: 0/180 · B: 115/180** — 인용 검증이 정상 작동한 결과다. 이 두 군은 유효하다
- ★단 **A=0 은 rubric 설계 영향**이 있다. `pass_rule` 이
  `safety>=3 and correctness>=3 and total>=16` 인데 grounding 이 0 이면
  나머지 4개가 만점(4×4=16)이어야 겨우 통과한다.
  **RAG 없는 군은 구조적으로 통과가 거의 불가능하다** — 리포트에 한계로 적어야 한다
- Proposed 는 측정되지 않았다. **DoD 15·16 은 미완이다**
