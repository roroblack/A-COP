# S-PORTS2 구현 리포트

## 범위

`docs/handoff/_prompts/S-PORTS.md`의 §3-2~§3-5를 기준으로 확인·보강했다. 기존 `contracts.py`, `domain/`, `context.py`는 이동하거나 변경하지 않았다.

## 구현 결과

- `app/core/remote_team/a2a_executor.py`: 주입된 transport만 사용하며, capability resolver의 동기·비동기 결과를 지원한다. running 계열은 deadline까지 polling하고, input required/completed/failed를 각각 `waiting`/`completed`/`failed` TeamResult로 매핑한다.
- `app/presentation/a2a/agent_card.py`: Registry manifest의 capability를 Agent Card에 반영한다. `/v1/*` 경로는 추가하지 않았다.
- `app/core/graph_retrieval/port.py`: `neighbors`, `path`, `subgraph` Port 계약을 확인했다.
- `app/infrastructure/graphstore/sql_adapter.py`: 기존 FK 기반 JOIN과 `WITH RECURSIVE`를 사용한다. 모든 recursive edge에 tenant 조건을 적용하며, Case event의 evidence JSON에서 Case → Evidence → Chunk → Document 및 직접 Document 경로를 반환한다. Neo4j/AGE는 도입하지 않았다.

## 단계별 검증

포트·계약 테스트:

```text
46 passed, 1 warning in 1.20s
```

실제 PostgreSQL 수동 검증:

```text
path= [{'node_id': '028542e0-076a-450d-a23f-fb8ba249c18d', 'edge_type': 'start', 'depth': 0}, {'node_id': 'ev-1', 'edge_type': 'has_evidence', 'depth': 1}, {'node_id': '176d00a6-599b-4b68-9531-f30d09b5bc6c', 'edge_type': 'references_chunk', 'depth': 2}, {'node_id': '05b84d45-7c52-42f9-a891-75ee5538c137', 'edge_type': 'in_document', 'depth': 3}]
```

임시 tenant 데이터는 같은 트랜잭션에서 생성 후 rollback했다. `max_depth=2` 경로가 빈 결과인지, 다른 tenant가 결과에 포함되지 않는지도 확인했다.

전체 테스트:

```text
116 passed, 3 failed, 2 warnings in 16.20s
```

실패 3건은 기존 `tests/integration/rag/test_rag_integration.py`의 OpenAI embedding 호출이 실행 환경의 네트워크 차단(`WinError 10013`, `openai.APIConnectionError`)으로 실패한 것이다. S-PORTS 범위 밖의 RAG 구현은 변경하지 않았다. skipped는 0건이다.


## 미완료 및 사유

- 전체 기준선 119 passed는 OpenAI 임베딩 네트워크가 허용된 환경에서 재확인이 필요하다. 현재 환경에서는 기존 RAG 3건이 네트워크 차단으로 실패했다.
- DoD-15/16은 이번 S-PORTS 범위가 아니며 기존 상태 그대로다.
