# S-PROPOSED2 구현 리포트

작성일: 2026-08-13

## 변경 파일

- `eval/runners/common.py`
  - Context Broker가 만든 `ContextPack`을 포함한 `TeamTask` 생성 경로는 유지했다.
  - `BillingSubscriptionTeam` 또는 `TechnicalEntitlementTeam`에 `_OpenAITeamLLM`을 `llm` 인자로 주입한다.
  - `TeamRegistry`와 `app.core.remote_team.executor.LocalTeamExecutor`를 통해 실제 Team을 실행한다.
  - Proposed prediction의 `answer`와 `next_action`은 각각 `TeamResult.answer`, `TeamResult.next_action`을 그대로 반영한다.
  - Team 결과가 `escalated`/`failed`, `failure_code`, `warnings` 또는 degraded 상태이면 judge가 통과시켜도 `success=False`로 기록한다.
  - 원본 `team_result`도 결과 행에 기록한다.
- `docs/reports/2026-08-13_S-PROPOSED2_리포트.md`
  - 본 리포트.

`app/**`는 수정하지 않았으며, 기존 baseline raw 결과도 삭제하지 않았다.

## Proposed 호출 모듈과 LLM 주입

Proposed는 intent에 따라 다음 Team 중 하나를 생성한다.

- `app.modules.customer_ops.billing.BillingSubscriptionTeam`
- `app.modules.customer_ops.technical.TechnicalEntitlementTeam`

생성 시 `ReadToolbox(get_connection)`과 함께 `_OpenAITeamLLM()`을 `llm` 인자로 전달한다. `_OpenAITeamLLM.complete()`은 설정의 `openai_api_key`, `llm_model`, `llm_temperature`, `llm_seed`를 사용해 OpenAI Chat Completions를 호출한다. 생성된 Team은 `TeamRegistry`에 등록되고 `LocalTeamExecutor.execute(task)`를 통해 실행된다.

Team 실행 결과의 customer-facing answer를 러너가 새 문자열로 만들거나 보정하지 않는다.

## 자체 검증

실행 명령:

```powershell
python -m eval.runners.proposed --dataset eval/datasets/golden.jsonl --repeats 1 --seed 7 --provider openai --limit 4 --concurrency 4 --output eval/reports/chk_p.jsonl
```

실행 결과:

```text
rows_written: 4
```

검증 출력:

```text
행수 4 | 고유 answer 1
  - None
  - None
  - None
  - None
```

4행 모두 다음 오류로 종료됐다.

```text
APIConnectionError: Connection error.
```

네트워크 오류가 Context Broker의 정책 검색 단계에서 발생했기 때문에 이번 실행에서는 TeamResult와 citations가 생성되지 않았다. 따라서 이번 환경에서는 `고유 answer == 행수` 및 유효 citations 조건을 실측 통과했다고 보고할 수 없다. `eval/reports/chk_p.jsonl`에 네트워크 실패를 그대로 기록했으며, fake LLM으로 대체하지 않았다.
