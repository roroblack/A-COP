## 만들지 않기로 한 것

- 대상의 검증 모델·계약 모델·theme·파이썬 코드는 복사하지 않았다. 이 콘솔은 UI와 read-only 어댑터만 소유한다.
- 프로필 파일에 자격증명을 저장하지 않았다. 연결 URL은 환경변수에서 읽는다.
- DB 쓰기, migration, seed, 평가 실행 기능은 만들지 않았다. 실행 이력은 `SELECT`만 수행한다.
- 없는 연결 정보를 `0`으로 채우지 않았다.

## 발견한 결함

- 기존 테스트 실행은 환경의 기존 `%TEMP%\\pytest-of-playdata2` 권한 문제로 setup 단계에서 실패했다. 저장소 밖의 새 `%TEMP%` 경로를 `--basetemp`로 지정해 재실행했고 24개가 통과했다.
- `console.web`의 `reload=True` 실행은 검증 중 자식 프로세스가 남을 수 있어, HTTP 원문 확인은 reload 없는 uvicorn 실행으로 마무리했다.
