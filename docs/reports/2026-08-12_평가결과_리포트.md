## 6. 한계

이번 결과는 네트워크 연결 장애로 실제 LLM 판단이 반환되지 않아 S-EVAL의 정확도나 우월성을 평가하지 못한다. 설령 정상 실행되더라도 60건×3회는 방향성과 불확실성만 말한다. 모집단 일반화, 장기 drift, 실제 손실률, 모든 도메인에서의 우월성, 운영 SLA를 증명하지 않는다.

## 7. 차단 사유

설정은 `get_settings()`로 읽혔고 모델은 `gpt-4o-mini`, API key 존재, DB DSN 존재를 확인했다. 그러나 5건 smoke와 전량 실행에서 모두 API 연결 오류가 반복되어 DoD 기대치(`cost_usd>0`, `latency_ms>100`, `input_tokens>0`)를 충족하지 못했다. 따라서 이 실행은 완료 평가가 아니라 네트워크 차단 상태의 부분 실행이다.
