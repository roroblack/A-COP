# VISION-06. 지식·메모리 확장

| 항목 | 내용 |
|---|---|
| 상태 | 보류 |
| MVP 포함 | 아니오 |
| 최종 갱신 | 2026-08-13 |

## 1. 무엇인가

pgvector top-k 검색을 BM25+Vector 하이브리드 검색과 rerank로 확장하고, 유사 Case를 재사용하는 Episodic Memory와 VOC 임베딩 클러스터링·토픽 모델링을 추가한다. 현재는 메타데이터 필터가 있는 pgvector top-k 8, 정책문서 25건·청크 300개다.

## 2. 지금 하지 않는 이유

- 현재 코퍼스 규모와 top-k 경로의 기준선이 아직 작고, 검색 실패 유형을 먼저 분류해야 추가 검색 계층의 효과를 판단할 수 있다.
- Episodic Memory는 잘못된 과거 Case 재사용과 tenant 격리 위험을 추가한다.
- VOC 클러스터링·토픽 모델링은 현재 일일 급증 집계 범위를 넘어서는 별도 분석 기능이다.

## 3. 도입 트리거 (이 조건이 만족되면 재검토한다)

- 정책·지식 문서가 200건 이상이 되면 hybrid 검색을 검토한다.
- 100건 평가 질의에서 검색 실패(정답 문서가 top-k에 없음 또는 근거 미포함)가 10%를 초과하면 BM25/rerank를 검토한다.
- 최근 4주 Case 중 유사 Case 재사용 요구가 20%를 초과하면 Episodic Memory를 검토한다.
- 4주 동안 VOC issue 종류가 15개 이상이고 수동 분류 미확정 비율이 10%를 초과하면 임베딩 클러스터링·토픽 모델링을 검토한다.

## 5. 선행 조건 (이게 먼저 있어야 도입 가능)

- 100건 이상 질의의 검색 성공·실패 유형과 분모 기록
- 문서·청크·임베딩 버전 및 재색인 절차
- 유사 Case의 tenant/customer 범위와 PII masking 규칙
- 현재 top-k 8 경로와 새 경로를 비교하는 holdout 평가

## 6. 폐기 조건 (이 조건이면 이 비전을 버린다)

- 문서 200건 미만 상태가 12개월 지속되고 검색 실패율이 5% 이하이면 hybrid 검색을 폐기한다.
- 3회 평가에서 rerank가 검색 성공률을 2%p 이상 높이지 못하고 p95 지연을 30% 이상 늘리면 폐기한다.
- 6개월 동안 유사 Case 재사용 요구가 5% 이하이면 Episodic Memory를 폐기한다.
