# VISION-02. 전용 Graph Store 도입

| 항목 | 내용 |
|---|---|
| 상태 | 보류 |
| MVP 포함 | 아니오 |
| 최종 갱신 | 2026-08-13 |

## 1. 무엇인가

현재 `GraphStorePort`와 `SqlGraphAdapter`(PostgreSQL JOIN/재귀 CTE)로 처리하는 관계 질의를 전용 Graph Store로 확장한다. 후보는 Apache AGE(PostgreSQL 확장)와 Neo4j(별도 저장소)다. 먼저 Apache AGE를 검토한다. PostgreSQL 안에서 동작하는 후보라 Neo4j처럼 별도 Projection 동기화가 필요하지 않은 방향이기 때문이다.

## 2. 지금 하지 않는 이유

- 현재 관계 깊이가 1~2라 PostgreSQL JOIN/재귀 CTE로 처리할 수 있다.
- Neo4j 같은 별도 Store를 추가하면 Projection 동기화 설계·구현·장애 복구가 비용의 대부분을 차지한다. §4의 실소요 일수 산정에서 이를 반영한다.
- 현재 문제를 Graph Store로 바꾸기 전에 SQL 경로의 근거 포함률과 질의 지연을 먼저 측정해야 한다.

## 3. 도입 트리거 (이 조건이 만족되면 재검토한다)

- A2A 위임의 최대 깊이가 3 이상인 Case가 월 20건 이상 발생하면 검토한다.
- 정책 계층 상속이 3단계 이상으로 채택되면 검토한다.
- multi-hop 질의가 전체 Graph 질의의 15%를 4주 연속 초과하면 검토한다.
- 최근 100건의 SQL 경로에서 관계 근거가 Context Pack에 포함되는 비율이 95% 미만이면 검토한다.

## 4. 도입 시 예상 비용

전제: 6인 팀이 AI 코딩 도구를 상시 사용한다. 아래는 인·일이 아니라 실소요 일수(wall-clock)다.
단축률은 이 저장소 실측(2026-08-12, 2시간 21분에 18,390줄·테스트 107건)에 근거한 추정이며 정밀한 값이 아니다.

### Apache AGE 선택

| 구분 | 내용 | 실소요 | AI 단축 정도 |
|---|---|---:|---|
| 생성 | `GraphStorePort` 어댑터, AGE 쿼리, 마이그레이션·운영 설정과 테스트 생성. 병목은 없다. | 0.5~1일 | 큼 |
| 검증·통합 | SQL 기준선과 Projection 결과 일치, 깊이별 지연·근거 포함률, 백업·복구를 검증. 병목은 Projection 일치 판단과 성능 비교다. | 2~3일 | 작음 — 사람이 판단한다 |
| 대기 | 없음. 병목은 없다. | 없음 | 없음 |
| **합계** | | **3~4일** | |

### Neo4j 별도 저장소 선택

| 구분 | 내용 | 실소요 | AI 단축 정도 |
|---|---|---:|---|
| 생성 | Neo4j 어댑터, 이벤트 기반 Projection, 동기화·재생성 도구와 테스트 생성. 병목은 초기 배선이다. | 1~1.5일 | 큼 |
| 검증·통합 | PostgreSQL 기준선과 Neo4j 결과 일치, 지연·재처리·장애 복구·백업을 검증. 병목은 동기화 누락과 재생성 결과의 사람 판정이다. | 4.5~6일 | 작음 — 사람이 판단한다 |
| 대기 | 인프라 프로비저닝과 운영 접근 승인을 기다린다. 병목은 외부 인프라 일정이다. | 1~1.5일 | 없음 |
| **합계** | | **7~9일** | |

병목: AGE는 Projection 일치·성능 검증, Neo4j는 별도 저장소 동기화 검증과 운영 인프라 대기가 지배적이다.

## 5. 선행 조건 (이게 먼저 있어야 도입 가능)

- `GraphStorePort` 계약과 SQL 기준선의 동일 결과 비교 테스트
- 100건 이상 관계 질의의 깊이·지연·근거 포함률 계측
- append-only 이벤트에서 Projection을 재생성하는 절차
- AGE 먼저, Neo4j 다음 순서의 비교 기준과 롤백 계획

## 6. 폐기 조건 (이 조건이면 이 비전을 버린다)

- 6개월 동안 최대 관계 깊이가 2 이하이고 multi-hop 비중이 5% 이하이면 전용 Store 도입을 폐기한다.
- SQL 경로의 근거 포함률이 99% 이상이고 p95 지연이 합의된 Case 처리 예산 안에 있으면 폐기한다.
- AGE 실증이 SQL 대비 100건 평가에서 정답·근거 개선 2%p 미만이고 운영비가 월 20% 이상 늘면 폐기한다.

## 7. 참고

- `GraphStorePort`와 `SqlGraphAdapter`의 실제 위치·계약은 구현 시점에 확인한다.
- Apache AGE·Neo4j는 외부 리서치 인용 후보이며, 도입 전 공식 문서와 설치 가능 버전을 확인한다.
