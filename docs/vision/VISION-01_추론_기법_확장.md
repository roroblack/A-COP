# VISION-01. 추론 기법 확장

| 항목 | 내용 |
|---|---|
| 상태 | 보류 |
| MVP 포함 | 아니오 |
| 최종 갱신 | 2026-08-13 |

## 1. 무엇인가

Tree of Thoughts(ToT), Reflexion/자기비판 루프, self-consistency 반복을 Agent Team 실행 경로에 선택적으로 도입한다. 탐색·검토·다중 후보 생성을 통해 복합 질의와 자동화율을 높이는 확장안이다.

현재는 Billing/Subscription과 Technical Entitlement 2개 Team, 라우팅 깊이 1~2, 규칙 기반 replan, 고위험 환불·권한변경의 self-consistency N=2만 사용한다.

## 2. 지금 하지 않는 이유

- 현재 Team 수가 2개이고 라우팅 깊이가 1~2라 후보를 늘려도 탐색공간보다 추가 LLM 호출·판정·추적 복잡도가 커진다.
- replan은 규칙 기반으로 처리하고 있어 Reflexion 루프가 해결할 실패 유형이 분리되어 있지 않다.
- self-consistency를 전 경로로 확대하면 현재 고위험 2종에 한정한 N=2 비교 조건과 평가 비용 통제가 깨진다.

## 3. 도입 트리거 (이 조건이 만족되면 재검토한다)

- 활성 Team이 4개 이상이 되고, 100건 이상의 Case에서 라우팅 후보가 평균 3개 이상인 상태가 4주 지속될 때 ToT를 검토한다.
- 최근 100건에서 규칙 기반 replan 후 재실패율이 5%를 초과할 때 Reflexion을 검토한다.
- 자동 완료율 목표가 80% 이상으로 합의되고, 100건 평가에서 현재 경로가 목표보다 5%p 이상 낮을 때 전 경로 self-consistency를 검토한다.
- 고위험 외 Case에서 동일 질의의 답 불일치율이 10%를 초과할 때 self-consistency 확대를 검토한다.

## 5. 선행 조건 (이게 먼저 있어야 도입 가능)

- 후보별 prompt/model/seed/cost/latency를 분리 기록하는 평가 하네스
- Team·라우팅 후보별 성공·재실패·replan 이력의 관측 로그
- 자동 완료율, escalation율, 고위험 오판율의 기준선
- 호출 상한과 일일 비용 상한을 지키는 설정·차단 경로

## 6. 폐기 조건 (이 조건이면 이 비전을 버린다)

- 6개월 동안 활성 Team이 4개 미만이고, 100건 기준 라우팅 후보 평균이 3개 미만이면 ToT 항목을 폐기한다.
- 6개월 동안 replan 후 재실패율이 2% 이하이고 자기비판 적용군의 개선이 100건 평가에서 1%p 미만이면 Reflexion 항목을 폐기한다.
- 3회 연속 평가에서 self-consistency 확대가 비용을 30% 이상 늘리면서 pass rate 개선이 2%p 미만이면 확대안을 폐기한다.
