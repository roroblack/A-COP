# 2026-08-31 — 모듈 토글 실효화 설계 (cs 에서 이식)

## 왜 하나

`final_project_cs` 에서 2026-08-30 에 고친 결함이 이 저장소에도 그대로 있다.
선언에서 모듈을 꺼도 아무 일이 일어나지 않는다.

이 저장소는 cs 가 가져다 쓰는 **참고 구현체**다(루트 `CLAUDE.md`). 코드가
sample → cs 방향으로 흐르므로, 여기를 안 고치면 다음 이식 때 cs 의 수정이
덮일 수 있다.

## 실측 — 지금 상태

★`graph_store` 는 cs 와 다르다. **여기서는 우회가 실제로 일어나지 않는다.**
`acop_basement/presentation/ui/routes.py:13` 이 `SqlGraphAdapter` 를 import 하고
있지만 **쓰는 곳이 없다.** 관리자 화면이 `final_project_ui` 로 나가면서 남은
죽은 import 다(실측: 파일 전체에서 `SqlGraphAdapter` 출현 1회, import 줄뿐).

계획을 세우면서 cs 와 같을 것이라 짐작하고 "화면이 직접 만든다" 라고 적었다가
실제로 세어 보고 고쳤다. **짐작으로 결함을 적으면 없는 결함을 고치게 된다.**

그래서 이 저장소에서 고칠 것은 두 건 반이다 — `mcp`, `voc`, 그리고 죽은 import 제거.

## cs 와 다른 점 — 게이트 다는 자리가 다르다

이 저장소는 계층 경계가 하나 더 있다.

> `acop_basement` 는 Core/Team 만 갖는, cs 가 항상 설치하는 pip 패키지다.
> `app.composition`(조립 루트)도 이 패키지를 설치하는 product 쪽이 갖는 것이라
> **지연 import** 한다. — `acop_basement/presentation/api/app.py` 주석

그래서 **basement 안의 게이트는 `app` 을 import 할 수 없다.**
cs 는 운영 화면이 `composition.build_graph_store()` 를 거치게 고쳤지만 여기서는
그 방법을 쓸 수 없다. 그래서 basement 안의 게이트는 basement 자신의 로더
(`acop_basement/application/config_source.load_active_config`)로 묻는다.

### 범위 밖

- Graph 질의를 Context Broker 에 붙이지 않는다. 계약이 요구한 적 없다.
- AGE·Neo4j 어댑터를 만들지 않는다. Phase 2 다.
- 모듈을 새로 추가하지 않는다. 여섯 개 그대로다.
- 중앙 설정 저장소 동작은 건드리지 않는다. 게이트는 `load_active_config` 를
  그대로 쓰므로 파일 모드와 중앙 모드 둘 다 자동으로 따라간다.

## `voc` 를 끄면 앱이 기동하지 않는다 — 이 저장소에서도 같다

cs 에서 내린 판단이 여기서도 유효한지 따로 확인했다. 유효하다.

이 저장소의 `CLAUDE.md` §1 에도 같은 문장이 있다.

> ★**분류 실패는 조용히 넘기지 않는다.** Case 생성 경로에서 감성·의도·이슈 분류가
> 실패하면 `classification_failed` 를 남기고 `escalated` 로 전환한다.
> **인라인 분류는 선택 기능이 아니다.**

그리고 `create_app()` 이 classifier 를 주입받지 않으면 `build_classifier()` 를
부른다(`acop_basement/presentation/api/app.py:29`). 따라서 `voc: false` 로는
기본 경로로 앱이 뜨지 않는다.

★단, 이 저장소는 **classifier 를 주입할 수 있다.** `create_app(classifier=...)` 로
넘기면 `build_classifier()` 를 거치지 않는다. 도메인을 갈아 끼우는 저장소라
그 구멍이 의도적으로 열려 있다. 그러니 정확히는 "기본 조립으로는 못 끈다"이고,
자기 분류기를 주입하는 product 는 여전히 끌 수 있다. 이 차이를 계약 문서에 적는다.

## 완료 기준

1. 여섯 모듈 각각, 끈 상태로 해당 경로를 부르면 `ProjectConfigError` 가 난다.
2. 켠 상태의 동작은 지금과 같다. 기존 테스트가 그대로 통과한다.
3. `/ops/voc` 는 `voc` 가 꺼져 있으면 404 다. 상단 메뉴에서도 사라진다.
4. `routes.py` 에 `SqlGraphAdapter` 를 쓰지 않는 import 가 남아 있지 않다.
5. `acop_basement` 가 `app` 을 import 하지 않는 것이 유지된다 —
   기존 아키텍처 테스트가 이를 검사한다.
6. 새 테스트가 1~5 를 덮고, 재현 명령과 출력을 `docs/evidence/` 에 남긴다.
