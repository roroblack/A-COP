# 2026-08-12 S-RAG v5 이력

v4의 소제목과 문체를 유지한 채 `knowledge/documents/`의 25개 문서, 300개 섹션 본문을 확장했다. 각 섹션에는 기존 주제에 맞는 다음 단계, 경계조건, 예외, 구체 절차를 추가했고 기존 수치와 frontmatter는 보존했다.

v4의 청크 평균은 56자였고 200자 미만이 300/300이었다. v5에서는 평균 241자, 최소 200자, 최대 314자로 조정되어 짧은 청크가 0/300이 되었다. 확장 과정에서 `운영 확인은 N회 기록한다.` 필러 20건도 삭제했다.

최종 `python -m scripts.check_corpus`는 exit 0이다. 문서/섹션 수는 25/300, 전체 청크 쌍 유사도는 평균 0.008·중앙 0.002, 공통 6-gram은 1종, 구체 수치 포함률은 문서 100%·섹션 67%였다.
