# 2026-08-18 Composer v2 콘솔 전환

`console/composer.py`가 동작별 최소 scope로 `/auth/token`을 매번 호출하고, 발급된
단명 JWT로 Composer API를 호출하도록 전환했다. 프로필 키는
`CONSOLE_COMPOSER_ISSUER_SECRET`로 명확히 이름을 바꿨다.

토큰 발급 실패(401/403/422·네트워크)와 실제 Composer 인증 실패를 서로 다른
`ComposerResult.status`로 표현한다. 실제 대상에 apply를 보내지 않고 테스트용 HTTP
서버로 계약을 검증했다.
