## 3. ★이전이 덜 됐다 — 5가지

`final_project_sample` 의 개발 콘솔에 있었는데 아직 이 저장소에 없는 것들이다.
**대상의 코드를 복사하지 마라.** 같은 정보를 **파일·DB 에서 읽어** 여기서 새로 그린다.

### 3-1. guardrails 수치
대상의 `config/guardrails.yaml` 을 읽어 평평한 표로 보여준다.
(예: `context.token_budget = 12000`). ★없으면 "없음" 이라고 적는다.

### 3-2. 상태 분포
`database_url` 이 있을 때만. `customer_cases` 와 `outbox` 의 status 별 건수.
★`outbox` 의 `unknown`·`dead_letter` 는 **사람이 봐야 하는 상태**다 — 눈에 띄게 하라.
★연결이 없으면 `0` 이 아니라 **"연결 안 함"** 이다.

### 3-3. DoD 전체 목록
지금은 **막힌 것만** 보여준다. 통과한 항목도 볼 수 있어야 한다.
★단 **기본은 막힌 것**이다. 전체는 접어 두고 펼치게 하라 —
28칸 초록 카드를 먼저 보여주면 "다 됐다" 로 읽힌다.

### 3-4. 평가 상세 — ablation · holdout
`readers.read_eval_runs` 가 이미 `ablations` 를 읽는다. 화면에 **어느 ablation 인지** 보이게 하고,
`dataset` 경로에 `holdout` 이 들어가면 **표시**하라 (holdout 은 보존 대상이다).

### 3-5. 최소 trace
지금 `db.py` 는 `agent_runs` 만 읽는다. 한 run 을 따라갈 수 있어야 한다:

```
agent_runs(run_id) → team_tasks(run_id) → llm_calls → case_events(case_id)
```

★**SELECT 만 한다.** 만들지 마라: span 검색·실시간 tail·세션 분석.
★테이블이 없거나 컬럼이 다르면 **"읽지 못했다"** 로 보고한다. 빈 목록으로 바꾸지 마라.
