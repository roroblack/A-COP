# P13 상단 메뉴 내비게이션

## 변경 내용

`console/web.py`의 `page()`에 콘솔 전용 sticky 상단 메뉴를 추가했다.

- 프로젝트 목록(`/`), 조립(`/project?path=...`), Composer(`/composer?path=...`)를 표시한다.
- 프로젝트 경로가 없으면 조립과 Composer를 `href` 없는 비활성 텍스트로 렌더링한다.
- 현재 라우트의 메뉴 항목에만 `aria-current='page'`를 붙이고 `--accent` 계열로 강조한다.
- `/run`은 메뉴 탭에 추가하지 않고 프로젝트의 실행 이력 링크를 유지한다.

## 렌더링된 HTML 발췌

`/project?path=X` 응답의 실제 `nav` 부분:

```html
<div class='topbar__in'><span class='brand'>개발 콘솔</span><nav aria-label='주 메뉴'>
<a href='/'>프로젝트 목록</a>
<a href='/project?path=X' aria-current='page'>조립</a>
<a href='/composer?path=X'>Composer</a>
</nav>
```

경로가 없는 `/` 응답에서는 다음처럼 프로젝트별 링크가 비활성화된다.

```html
<span class='nav-disabled' aria-disabled='true'>조립</span>
<span class='nav-disabled' aria-disabled='true'>Composer</span>
```
