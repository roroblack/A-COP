# P7 trace 연결 보고서

## 변경 사항

- `console/web.py`에서 `read_trace`를 연결했다.
- 실행 이력의 각 `run_id`를 `/run?path=...&run_id=...` 링크로 표시한다.
- `/run` 화면에서 `agent_runs`, `team_tasks`, `llm_calls`, `case_events` 단계를 구분해 표시한다.
- `run_id` 누락, database URL 누락, 존재하지 않는 실행, 단계 조회 오류를 500 대신 안내 문구로 표시한다.
- 빈 단계는 0으로 채우지 않고 기록 없음으로 표시한다.
