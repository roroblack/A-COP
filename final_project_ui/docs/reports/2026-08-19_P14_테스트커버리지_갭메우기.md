# P14 테스트 커버리지 갭 메우기

## 처리 결과

1. `console/composer.py` 토큰 발급 실패: 메움. 실제 HTTP 서버로 500 응답, `access_token` 누락, malformed JSON 응답을 추가했고 모두 실제 상태와 detail을 단언한다.
2. `console/composer.py` 기타 Composer HTTP 오류: 메움. `/composer/current`의 500·503이 실제 코드의 일반 무응답 상태로 분류되는지 확인했다.
3. `console/db.py`: 부분 메움. tenant 필터, limit 전달, `_state_counts`의 개별 조회 실패 시 `__error__`, 유효 UUID의 연결 실패 `read_trace`를 PostgreSQL 없이 검증했다. 실제 SQL 성공/실패 결과를 확인하는 테스트는 로컬 PostgreSQL이 필요하므로 추가하지 않았다.
4. `console/readers.py`: 메움. guardrails 정상/누락/YAML 오류, evidence 경로 오류, malformed eval JSONL 행을 추가했다. malformed 행은 비용 합계에서 제외되지만 `rows` 전체 행 수에는 남는 것을 확인했다.
5. CI 토큰 주입 문서화: 메움. README에 GitHub Actions repository secrets를 `env`로 주입하는 방법과 현재는 수동 실행이라는 범위를 추가했다. CI workflow 파일은 만들지 않았다.

## 검증

요구된 명령은 다음과 같다.

```powershell
cd C:\Users\playdata2\Documents\final_workspace\final_project_ui
python -m pytest tests -q
```

이 환경에서는 기본 pytest 임시 디렉터리(`C:\Users\playdata2\AppData\Local\Temp\pytest-of-playdata2`)를 열 수 없어 위 명령이 `PermissionError: [WinError 5] 액세스가 거부되었습니다`로 중단됐다. 저장소 내부 임시 경로를 지정한 동일 전체 테스트 실행의 출력 원문은 다음과 같다.

```text
python -m pytest tests -q --basetemp=.pytest-tmp
............................ [ 77%]
.....................                                                    [100%]
93 passed, 1 warning in 22.93s
```

기존 81개에서 93개로 12개 증가했다. DB 관련 PostgreSQL 필수 갭은 1개 범주로 스킵했으며, DB 없이 실행 가능한 3개 검증은 추가했다.
