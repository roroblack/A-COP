## ★고친 결함 5건 (전부 실측으로 재현 후 수정)

### 1. `.gitignore` 가 인수인계 브랜치에 아예 없었다
`final_project_ui` 는 상위 워크스페이스의 `.gitignore` 에 의존하고 있었는데,
`project-final_project_ui` 브랜치는 이 폴더만 떼어낸 것이라 **그게 안 따라온다.**
클론한 팀원은 `.gitignore` 가 하나도 없는 저장소를 받는다 → `__pycache__`·
`.pytest_cache` 가 그대로 커밋될 판이었다.
→ `final_project_ui/.gitignore` 를 만들었다(양쪽 모두에서 동작한다).

### 2. 대상이 이상한 응답을 주면 콘솔이 **500 으로 죽었다**
대상이 `config: null`·배열·문자열을 주면 `.get()`/`.items()` 에서 터졌다.
이 프로젝트의 존재 이유("대상이 없거나 이상해도 콘솔은 뜬다", `CLAUDE.md` §1)를
정면으로 어기는 결함이었다. 게다가 500 화면은 **어느 대상이 뭘 잘못 줬는지도**
안 알려준다.
→ 형태를 검사해서 "대상이 준 config 를 읽지 못했습니다 — 객체가 아니라 X 입니다"
로 적는다. `console/web.py` 두 곳(화면 렌더·POST 핸들러).

### 3. 조작된 POST 가 500 을 만들었다
`remove_team=abc` → `int()` 에서 예외 → 500. (음수·범위초과는 이미 방어돼 있었다)
→ 숫자가 아니면 아무 행도 지우지 않고 화면만 다시 그린다.

### 4. 경로에 `&`·`#` 가 있으면 **링크가 엉뚱한 곳을 가리켰다**
`esc()` 는 HTML 이스케이프일 뿐 URL 인코딩이 아니다. 폴더 이름 `a&b#c`(둘 다
파일명으로 합법) 는 `path=...\a` 로 잘리고 `#c` 는 서버에 오지도 않았다.
→ `qs()` 헬퍼 추가(URL 인코딩 → HTML 이스케이프 순서), 링크 생성 7곳 전부 적용.

### 5. `/project` 만 파라미터 없으면 **raw JSON 422** 를 냈다
주소창에 `/project` 만 치거나 쿼리 없는 북마크로 들어오면 화면이 아니라 JSON이
떴다. 다른 라우트(`/`·`/run`·`/composer`)는 전부 안내 화면을 낸다.
→ 안내 화면으로 통일.

## ★넘기는 팀원이 판단해야 할 것 — 고치지 않고 남긴 설계 사안 3건

임의로 바꾸지 않았다. 셋 다 **설계 결정**이지 단순 버그가 아니다.

### A. Composer POST 에 CSRF 방어가 없다 ← 셋 중 가장 중요
콘솔이 켜져 있는 동안 개발자가 **악성 웹페이지를 열면**, 그 페이지가
`127.0.0.1:<port>/composer` 로 form POST 를 보낼 수 있다. 폼 POST 는 CORS
preflight 대상이 아니라서 브라우저가 막지 않는다. 응답은 못 읽지만 **부작용
(대상 config `apply`)은 일어난다** — 서버 환경변수의 issuer secret 으로.

지금 이걸 막는 것은 "콘솔은 로컬에서만 켠다"는 관행뿐이다.
→ 선택지: CSRF 토큰 추가 / `Origin` 헤더 검사 / apply 를 CLI 전용으로 분리.

### B. 임의 경로를 읽을 수 있다
`/project?path=<아무 경로>` 로 저장소 밖 어디든 열 수 있고, 그 안의
`config/project.yaml`·문서·평가 결과를 읽는다.
★이건 **의도된 기능**이다 — "프로젝트 경로만 주면 그 프로젝트에 붙는다"가
이 프로그램의 존재 이유다(`CLAUDE.md` 첫 줄). `127.0.0.1` 바인딩이라
지금은 로컬 사용자만 쓸 수 있다.
→ 다만 **이걸 localhost 밖으로 노출하면 파일 읽기 도구가 된다.** 배포·공유
계획이 생기면 허용 루트 제한을 먼저 넣어야 한다.

### C. async 핸들러 안에서 blocking HTTP 호출
`/composer` POST 는 `async` 인데 안에서 동기 `urlopen()` 을 부른다. 대상이
느리면 이벤트 루프가 막힌다. 1인용 로컬 콘솔이라 지금은 체감되지 않지만,
여러 명이 붙는다면 `httpx.AsyncClient` 로 바꿔야 한다.
